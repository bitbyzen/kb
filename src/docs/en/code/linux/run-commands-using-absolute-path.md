# Running Commands Using an Absolute Path

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Commands that start with `~/` or `/` use an **absolute path** — they target a specific location regardless of where you currently are in the terminal.

You do not need to `cd` to the target directory first.

---

## Example

Delete a directory from anywhere:

```bash
rm -rf ~/projects/docker/python/mkdocs
```

Even if your current working directory is somewhere else, such as:

```
(.venv) user@host:~/projects/python/mkdocs$
```

The command will still delete the correct folder because `~/` always resolves to your home directory.

---

## How Paths Work

| Prefix | Type | Resolves to |
|--------|------|-------------|
| `~/` | Absolute (home) | `/home/<your-username>/` |
| `/` | Absolute (root) | The root of the file system |
| `./` or no prefix | Relative | The current working directory |

---

> **Warning:** `rm -rf` deletes permanently with no confirmation. Always double-check the path before running it.
