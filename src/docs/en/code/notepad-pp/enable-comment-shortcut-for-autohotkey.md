# Enabling Comment Shortcut for AutoHotkey

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Enable line commenting (`;`) using `Ctrl+Q` for AutoHotkey scripts in Notepad++.

---

## Prerequisites

- [Notepad++](https://notepad-plus-plus.org/) installed
- [AutoHotkey](https://www.autohotkey.com/) installed

---

## Step 1: Download the AutoHotkey UDL

Download the **User Defined Language (UDL)** file for AutoHotkey from:

- Repository: [jNizM/ahk_notepad-plus-plus](https://github.com/jNizM/ahk_notepad-plus-plus)
- File to download: `userDefineLang_AHK.xml`

---

## Step 2: Import the UDL into Notepad++

1. Open **Notepad++**.
2. Go to **Language** → **User Defined Language** → **Define your language…**
3. Click **Import**.
4. Select the downloaded `userDefineLang_AHK.xml` file.
5. Restart Notepad++.

---

## Step 3: Enable the AutoHotkey Language

After restarting Notepad++:

1. Go to **Language** → **User Defined Language**.
2. Select **AutoHotkey**.

Syntax highlighting should now be applied to `.ahk` files.

---

## Step 4: Use the Comment Shortcut

1. Select one or more lines in your AutoHotkey script.
2. Press `Ctrl+Q` to toggle comments.

This inserts or removes `;` at the start of each selected line.

---

## Troubleshoot: Shortcut Not Working

If `Ctrl+Q` does not work, verify the shortcut mapping:

1. Go to **Settings** → **Shortcut Mapper**.
2. Search for `comment`.
3. Confirm that **Toggle Line Comment** is assigned to `Ctrl+Q`.
   If not, double-click the entry to reassign it.

---

## Alternative: Comment Without UDL

If you prefer not to install the UDL, you can comment lines manually by adding `;` at the start:

```ahk
; F9::
; {
;     Send "docker run ..."
; }
```

Or use **multi-cursor editing** to comment multiple lines at once:

1. Hold `Alt+Shift`.
2. Press `↓` to extend the cursor across multiple lines.
3. Type `;` to insert it on each line simultaneously.
