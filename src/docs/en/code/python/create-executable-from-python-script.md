# Creating an Executable from a Python Script

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Recommended Tool: Nuitka

[Nuitka](https://nuitka.net/) compiles Python source code into a native C-based executable. The resulting binary runs without requiring Python to be installed on the target machine.

> **Note:** PyInstaller is a popular alternative, but executables it produces are frequently flagged as malware by antivirus engines. Nuitka compiles Python directly and produces cleaner binaries.

## Prerequisites

- Python installed
- A C compiler (on Windows, Nuitka will prompt to install the [MinGW-w64](https://www.mingw-w64.org/) compiler automatically if none is found)

## Steps

1. Install Nuitka.

    ```
    pip install nuitka
    ```

2. Compile the script into a standalone executable.

    ```
    python -m nuitka --standalone --onefile your_script.py
    ```

    | Option | Description |
    |---|---|
    | `--standalone` | Includes all dependencies so the executable runs on machines without Python |
    | `--onefile` | Packages everything into a single `.exe` file |

3. Find the output executable in the current directory (e.g., `your_script.exe` on Windows).

## Notes

- The first build takes longer than PyInstaller because Nuitka compiles Python to C and then compiles the C code.
- For GUI apps, add `--disable-console` to suppress the terminal window.
- To package the resulting executable into a Windows installer, see [Create an Installer for a Python App](create-installer-for-python-app.md).
