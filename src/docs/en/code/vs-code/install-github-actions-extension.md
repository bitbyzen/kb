# Installing the GitHub Actions Extension

1. Click **Install**.

    ![Screenshot](img/install-github-actions-extension-01.webp)

1. Click **Sign in to GitHub**.

    ![Screenshot](img/install-github-actions-extension-02.webp)

1. Click **Allow**.

    ![Screenshot](img/install-github-actions-extension-03.webp)

1. Click **Continue**.

    ![Screenshot](img/install-github-actions-extension-04.webp)

1. Click **Open Visual Studio Code**.

    ![Screenshot](img/install-github-actions-extension-05.webp)

1. The installation is complete.

    ![Screenshot](img/install-github-actions-extension-06.webp)
