# Chatting with Gemini from the Address Bar

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Get help from Gemini with creative and complex tasks — like planning a trip or learning more about a new topic — directly from the Chrome address bar.

1. Type `@` in the address bar and select **Chat with Gemini**.
2. Write your prompt.
3. Get your response on gemini.google.com.
