# Adding a Fab Asset to a Project

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Steps

1. Go to the [Fab](https://www.fab.com) website and click **Add to Library** on the asset page.

2. Open **Epic Games Launcher**.

3. Go to **Library** and scroll down to the **Vault** section.

4. Find the asset, then click **Add to Project**.

5. Select your project from the list and confirm.

6. Reopen the project. Unreal Engine will compile shaders automatically — wait until it finishes.

7. Open the **Content Drawer** (`Ctrl + Space`) to find the asset files. They appear in a new folder named after the asset pack.

## Note

The asset folder typically contains subfolders for Blueprints, Skeletal Meshes, Materials, Textures, and Animations.
