# Setting Up the MCP Plugin for Claude Code

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The **Unreal MCP** plugin lets an AI coding agent, such as Claude Code, connect directly to the Unreal Editor over the Model Context Protocol — giving it awareness and control over Blueprints, PCG graphs, materials, actors, and levels.

## Prerequisites

- Unreal Engine 5.8 or newer
- Git for Windows or PowerShell
- Claude Code installed and authenticated — see [Installing Claude Code on Windows 11](../claude-code/install-claude-code-on-windows-11.md)

## Step 1: Enable the Required Plugins

Open your project and go to **Edit** → **Plugins**. Search for and enable these three plugins:

- **Unreal MCP** — enables Model Context Protocol communication.
- **Terminal** — enables built-in terminal support for communicating with AI agents inside Unreal Engine.
- **Editor Tool Set** — bridges the editor and the AI agent, granting it context and control over Blueprints, PCG graphs, materials, actors, and levels.

Click **Restart Now** when prompted to restart the Unreal Editor.

## Step 2: Turn On Auto Start Server

Open **Edit** → **Editor Preferences**, then scroll to **Model Context Protocol** in the left sidebar. Check **Auto Start Server** so the MCP server starts automatically whenever the project opens.

## Step 3: Add a Terminal Startup Sequence

In **Editor Preferences**, scroll to the **Terminal** settings and add a startup sequence, replacing the path with your own project's:

```plaintext
set TERM=xterm-256color
cd "<YOUR-PROJECT-PATH>"
claude
```

> **Note:** To find your project's local path, open the Content Drawer, right-click the **Content** folder, and select **Show in Explorer**. Copy the path up to the root project folder.

## Step 4: Generate the Client Configuration

Back in the Unreal Editor, open the console command bar (`~` key) and run:

```plaintext
mcp.GenerateClientConfig claude
```

> **Note:** If you're using Cursor, VS Code, or ChatGPT instead, replace `claude` with that client's identifier.

Verify that `mcp.json` was created in your project's root folder, then restart Unreal Engine once more.

## Step 5: Connect and Test the AI Agent

Open **Tools** → **Terminal**. If prompted to trust the directory, accept it. Confirm that Claude Code initializes and detects the local MCP server (port `8080` by default). Open or create a test level, then enter a prompt such as:

> "Create 5 different colored cubes stacked on top of each other in my level."

Claude Code generates the static meshes, material instances, and actor positions directly in your viewport.

## What You Can Do Next

Once connected, an AI agent can help with:

- **Level design and asset placement** — procedural generation, lighting setups, actor transforms.
- **Blueprint and C++ logic** — generating nodes, debugging Blueprint logic, or writing C++ source code.
- **PCG (Procedural Content Generation)** — constructing complex PCG graphs, such as city or terrain generators.
- **Material creation** — setting up master materials, parameter groups, and material instances programmatically.
