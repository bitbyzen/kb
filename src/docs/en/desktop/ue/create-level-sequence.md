# Creating a Level Sequence

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

A Level Sequence is the container for cinematic animations in Unreal Engine. It holds camera tracks, character tracks, and the timeline for rendering video.

## Steps

1. In the main toolbar, click the **Cinematics** icon (film strip icon, near the Play button).

2. Select **Add Level Sequence**.

3. Enter a name (e.g., `Intro_Sequence`) and click **Save**.

4. The **Sequencer** panel opens at the bottom of the editor, showing a timeline with frame markers.

## Note

Press `Ctrl + Shift + S` to save all assets before closing the editor.
