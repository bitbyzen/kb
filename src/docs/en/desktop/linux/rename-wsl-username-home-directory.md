# Rename WSL Username and Home Directory

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Use this to rename a WSL Linux user account (login name and `/home/<username>` directory) to a new name, e.g. `/home/<OLD-USERNAME>` to `/home/<NEW-USERNAME>`.

> **Warning:** This changes your login account, not just a folder. Close every terminal, editor, and tool using the account first — VS Code Remote-WSL windows, other WSL terminals, background services — before running these commands. `usermod` refuses to run cleanly (or leaves things half-changed) on a user with active processes.

## Step 1: Close Everything Using the Account

Close all WSL terminals and any VS Code Remote-WSL windows connected to the distro.

## Step 2: Stop the Distro

From **Windows PowerShell** (not WSL):

```powershell
wsl --terminate <YOUR-DISTRO>
```

## Step 3: Start a Root Shell

Start the distro logged in as `root` instead of the normal default user, so no processes are attached to the account you're renaming:

```powershell
wsl -d <YOUR-DISTRO> -u root
```

## Step 4: Rename the Account and Move the Home Directory

Inside the root shell:

```bash
usermod -l <NEW-USERNAME> -m -d /home/<NEW-USERNAME> <OLD-USERNAME>
```

- `-l <NEW-USERNAME>` renames the login from `<OLD-USERNAME>` to `<NEW-USERNAME>`.
- `-m -d /home/<NEW-USERNAME>` moves the home directory's contents and updates the account record to point at the new path.

## Step 5: Rename the Matching Group (If One Exists)

Ubuntu's default setup creates a group with the same name as the user. Rename it too, if present:

```bash
getent group <OLD-USERNAME> && groupmod -n <NEW-USERNAME> <OLD-USERNAME>
```

## Step 6: Check for a Default User Setting

```bash
cat /etc/wsl.conf
```

If it has a `[user]` section with `default=<OLD-USERNAME>`, update that value to `<NEW-USERNAME>`.

## Step 7: Restart WSL

```powershell
exit
wsl --shutdown
wsl -d <YOUR-DISTRO>
```

You should land in `/home/<NEW-USERNAME>` as the new user.

## After Renaming

Anything that hardcoded the old `/home/<OLD-USERNAME>/...` path needs a review afterward — project config files, SSH config, git config, and any tool (including Claude Code itself) that stores its own settings under the old home directory.
