# Exporting a UV Layout as an Image

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Export a mesh's UV layout as a flat image, to use as a guide when repainting its texture in another program.

## Export the UV Layout

1. Go to the **UV Editing** workspace, with the mesh you want to export selected.
2. In Edit Mode, press `A` to select all.
3. In the UV Editor, select **UV** → **Export UV Layout**, and save it as a PNG.

> **Note:** Open the exported PNG as a layer above the texture in an image editor and set its opacity low, so you can see where features like the eyes, mouth, and face edges fall — see [Repainting a Texture with Flat Anime Colors](../gimp/repaint-flat-anime-colors.md).
