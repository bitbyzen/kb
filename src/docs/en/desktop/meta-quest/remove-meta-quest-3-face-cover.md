# Removing the Meta Quest 3 Face Cover

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The Meta Quest 3 facial interface (face cover) is held in place by magnetic clips and can be removed without tools.

## Steps

1. Hold the headset with both hands.
2. Grip the facial interface firmly on both sides.
3. Pull it straight away from the headset. It will detach with a firm pull.

## Reattach the Face Cover

1. Align the facial interface with the front of the headset.
2. Press it against the headset until the magnetic clips snap into place.
