# Cancel a ChatGPT Subscription

1. Select **Settings**.
    ![Screenshot](img/cancel-chatgpt-subscription-01.webp)

1. Select **Account**.
    ![Screenshot](img/cancel-chatgpt-subscription-02.webp)

1. Select **Manage** → **Cancel Subscription**.
    ![Screenshot](img/cancel-chatgpt-subscription-03.webp)

1. Click **Cancel subscription**.
    ![Screenshot](img/cancel-chatgpt-subscription-04.webp)

1. Confirm the expiration date.
    ![Screenshot](img/cancel-chatgpt-subscription-05.webp)
