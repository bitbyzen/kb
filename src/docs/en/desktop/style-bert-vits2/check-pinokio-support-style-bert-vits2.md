# Checking Pinokio Support for Style-Bert-VITS2

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

No official Pinokio script for Style-Bert-VITS2 exists. This page summarizes the current state of Pinokio support and the alternatives available.

## Current State

- Style-Bert-VITS2 does not appear on Pinokio's Discover page.
- No community-made `pinokio.js` / `install.json` scripts for it have been published publicly.

## Why It Works Fine Without Pinokio

Style-Bert-VITS2 already supports a one-click-style installation through bundled `.bat` scripts. Download the ZIP, extract it, and double-click `Install-Style-Bert-VITS2.bat` (GPU) or the CPU variant. No Git or Python knowledge is required, which is close to Pinokio's own one-click philosophy. See [Set Up Style-Bert-VITS2 WebUI](set-up-style-bert-vits2-webui.md) for the full setup process.

## Options if You Still Want Pinokio

- **Use the `.bat` installer directly**: This is the officially recommended path, and arguably simpler than Pinokio for this tool.
- **Write your own Pinokio script**: Any GitHub repository with a `pinokio.js` plus `install.js` / `start.js` scripts can be installed through Pinokio. You can write these scripts to clone the Style-Bert-VITS2 repository and run the equivalent of the `.bat` steps with `shell.run`.
- **Use it as a Python library**: For synthesis-only use, Style-Bert-VITS2 is published as a pip package (`pip install style-bert-vits2`) and runs on CPU without an NVIDIA GPU. This suits integration scenarios, such as connecting to YMM4 through its API, more than a standalone WebUI setup.
