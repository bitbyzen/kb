# Migrate MkDocs from Docker to venv

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Move an existing MkDocs project from a Docker-based setup to a lightweight Python virtual environment (venv) on WSL2.

---

## Prerequisites

- WSL2 running Ubuntu
- An existing MkDocs project set up with Docker
- Git configured and connected to GitHub

---

## Step 1: Identify Files to Copy

From your Docker project folder, copy the following:

| Item | Description |
|------|-------------|
| `docs/` | Markdown content |
| `overrides/` | Custom theme overrides |
| `mkdocs.yml` | Site configuration |
| `requirements.txt` | Plugin and dependency list |
| `.git/` | Git history |
| `.github/` | GitHub Actions workflows |

Leave these behind:

| Item | Reason |
|------|--------|
| `Dockerfile` | Docker-specific, no longer needed |
| `site/` | Generated output — MkDocs will rebuild it |

---

## Step 2: Check for Unexpected Files

Run the following to inspect your project folder:

```bash
ls -la ~/projects/docker/python/mkdocs/
```

If you find an unrecognised file, check its contents before deleting:

```bash
cat ~/projects/docker/python/mkdocs/<filename>
```

To delete it:

```bash
rm ~/projects/docker/python/mkdocs/<filename>
```

---

## Step 3: Create the New Folder

```bash
mkdir -p ~/projects/python/mkdocs
```

---

## Step 4: Copy Files with rsync

Use `rsync` to copy everything across, excluding Docker-specific files and the generated `site/` folder:

```bash
rsync -av \
  --exclude='Dockerfile' \
  --exclude='site/' \
  ~/projects/docker/python/mkdocs/ \
  ~/projects/python/mkdocs/
```

---

## Step 5: Set Up the venv

Navigate to the new folder:

```bash
cd ~/projects/python/mkdocs
```

If `python3-venv` is not installed, install it first:

```bash
sudo apt install python3-venv
```

Create and activate the virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

`(.venv)` will appear at the start of your terminal prompt when the venv is active.

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Step 6: Verify the Site Locally

```bash
mkdocs serve
```

Open `http://127.0.0.1:8000` in your browser to confirm the site looks correct.

---

## Step 7: Test the GitHub Workflow

Make a small edit to any file in `docs/`, then commit and push:

```bash
git add .
git commit -m "test: verify new venv setup"
git push
```

Check the **Actions** tab in your GitHub repository to confirm the deployment workflow completes successfully.

---

## Step 8: Remove the Old Docker Folder

Once everything is confirmed working, delete the old project folder:

```bash
rm -rf ~/projects/docker/python/mkdocs
```

> **Warning:** `rm -rf` is irreversible. Double-check the path before running.
