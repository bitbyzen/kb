# Installing ComfyUI with the Desktop Installer

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The official ComfyUI desktop installer is available from the official site. Follow the on-screen instructions to complete the installation.

[https://www.comfy.org/](https://www.comfy.org/)

> **Note:** If the installer fails with an error, check whether your NVIDIA GPU driver is up to date. Install the **NVIDIA App** to manage driver updates:
> [https://www.nvidia.com/en-us/software/nvidia-app/](https://www.nvidia.com/en-us/software/nvidia-app/)
