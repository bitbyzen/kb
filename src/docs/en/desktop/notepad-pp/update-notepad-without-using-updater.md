# Update Notepad++ without Using the Updater

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

> **Note:** You don't need to uninstall the old Notepad++ installed on your PC.

1. Go to the [official download site](https://notepad-plus-plus.org/downloads/).
2. Select the latest version, which is normally shown at the top of the page.
3. Click **Download Notepad++** (green large button with chameleon at the top).
4. Double-check the downloaded installer, then follow the instructions.
