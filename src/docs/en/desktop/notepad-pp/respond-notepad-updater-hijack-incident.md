# Responding to the Notepad++ Updater Hijack Incident

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The Notepad++ updater was reportedly hijacked. See the official announcements:

- [Official incident update](https://notepad-plus-plus.org/news/hijacked-incident-info-update/)
- [Official security clarification](https://notepad-plus-plus.org/news/clarification-security-incident/)

The attack targeted organisations rather than individual users, but the following precautions are recommended:

1. Uninstall your current version and install the latest version from the official site.
1. Run a quick malware scan with Windows Defender or your antivirus software.
1. Delete any previously downloaded Notepad++ installers to avoid accidentally using them.
1. Until further notice, update Notepad++ manually rather than using the built-in updater.
