# Import Voice Lines via Scenario File in YMM4

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

YukkuriMovieMaker4 (YMM4) supports bulk voice generation by importing a **scenario file** (CSV or TXT). This lets you write all your dialogue in a spreadsheet and import it in one go, instead of typing lines one by one.

## CSV Format

The scenario file uses a simple two-column structure:

```
CharacterName,Dialogue text here
CharacterName,Another line of dialogue
```

| Column | Content |
|--------|---------|
| A | Character name (must exactly match the name registered in YMM4) |
| B | Dialogue / セリフ |

### Example

```csv
Yukkuri Reimu,Hello! Welcome to my channel.
YukkuriMarisa,Hey everyone, good to see you!
Yukkuri Reimu,Today we are going to talk about something interesting.
YukkuriMarisa,That sounds exciting! Let's get started.
```

> **Warning:** The name in Column A must be identical to the registered character name in YMM4, including spaces (or lack thereof). For example: `Yukkuri Reimu` (with space) vs `YukkuriMarisa` (no space).

## Step 1: Create the CSV in Excel

1. Open Excel and enter character names in **Column A**, dialogue in **Column B**
2. No headers — start data from row 1
3. Save as: **File → Save As → CSV UTF-8 (Comma delimited)**

> **Note:** Save your scenario files to a dedicated folder, e.g. `D:\<YOUR-FOLDER>\projects\creator\ymm`

## Step 2: Import into YMM4

1. In YMM4, go to **File → Open scenario file**
2. Navigate to your CSV file and select it
3. If a character name is unrecognized, a dropdown will appear — assign the correct character manually
4. Review the lines in the scenario editor
5. Click **Add to timeline** to generate all voice items at once

## Result

YMM4 will automatically generate voice clips and place them sequentially on the timeline. Each line becomes its own voice item assigned to the correct character.

## Reference

- Supports `.csv` and `.txt` formats (shown in file dialog as `Scenario file (*.csv;*.txt)`)
- Long lines may affect timing — keep dialogue concise per line
- Voice speed, pitch, and other settings are applied from each character's existing YMM4 configuration
- Scenario files can be edited and re-imported to regenerate voice lines in bulk
