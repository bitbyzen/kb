# Using Free CoeFont Voices (Allial & Millial) in YMM4

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

YukkuriMovieMaker4 includes two free CoeFont AI voices built in: **Allial** and **Millial**. These are human-sounding voices usable for commercial purposes, no additional software or subscription required.

## What is CoeFont?

CoeFont is a cloud-based AI voice platform that lets creators use natural-sounding voices. Allial and Millial are provided free of charge (including commercial use) directly within YMM4.

> **Note:** When publishing videos that use Allial or Millial, you must include the credit: **"Voiced by https://CoeFont.cloud"**

## Step 1: Complete First-Time Setup

Before you can use Allial or Millial, you must agree to CoeFont's Terms of Use. This only needs to be done once.

1. Go to **File → Edit character**
2. In the left panel, click **Allial** (under the CoeFont group)
3. In the right panel, find the **Terms of Use** section
4. Click the **同意事項** link — this opens the Terms of Use dialog
5. Read the terms and click **Agree**
6. Save your project (`Ctrl+S`)
7. Restart YMM4 — this is required for the agreement to take effect

> **Warning:** Even after clicking Agree, Allial/Millial will not work until you restart YMM4. Always save first.

Repeat the same steps for **Millial** if you want to use that voice too.

## Step 2: Assign a CoeFont Voice to a Timeline Item

Once set up, you can assign Allial or Millial to any individual voice item:

1. Click on a voice item in the timeline to select it
2. In the right panel under **Voice**, find the **Character** dropdown
3. Change it to **Allial** or **Millial**
4. YMM4 will automatically regenerate the voice line with the new character

## Using CoeFont in a Scenario CSV

To use Allial or Millial in a scenario file, use their exact names in Column A:

```csv
Allial,Hello! Welcome to my channel.
Millial,Hey everyone, good to see you!
```

## Other CoeFont Voices

Voices beyond Allial and Millial require a **CoeFont Enterprise plan**, which involves generating an API key from the CoeFont website and configuring it in YMM4.
