# Installing Apps in Bulk

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Reinstall your saved set of Windows apps on a new or freshly reset PC using `winget export` and `winget import` — no extra tool needed, since `winget` is built into Windows 11.

> **Note:** Keep Claude Desktop out of the saved app list. If Claude Cowork can't be turned on, fixing it requires additional setup steps that only apply when Claude Desktop is reinstalled directly, not through a bulk import.

## Step 1: Export the App List on Your Current PC

Open PowerShell as Administrator and run:

```powershell
winget export -o apps-to-install.json
```

This writes every installed app that `winget` recognizes to a JSON file.

> **Note:** Open the JSON file afterward and remove anything you don't want on the new PC — especially large or specialized software you only need on one machine. If the new PC is meant to be a lighter, secondary machine, keep the list to what it actually needs rather than mirroring your main PC exactly.

## Step 2: Open PowerShell as Administrator on the New PC

Open PowerShell with administrator privileges.

## Step 3: Copy the App List to the New PC

Copy `apps-to-install.json` from the network share to a folder on the new PC:

```text
\\<NAS-IP-or-name>\<YOUR-FOLDER>\apps-to-install.json
```

## Step 4: Run the Import Command

```powershell
winget import -i apps-to-install.json --accept-package-agreements --accept-source-agreements
```

> **Note:** `--accept-package-agreements` and `--accept-source-agreements` accept each app's license terms automatically, instead of prompting for every app individually.

## Limits

> **Warning:** Only apps registered in `winget`'s sources (the official winget repository or the Microsoft Store) are covered. Tools you set up manually — for example with `git clone` and a Python virtual environment — aren't included and need to be reinstalled individually.

> **Note:** For a much smaller set of common apps (browser, 7-Zip, VLC, and similar), [Ninite](https://ninite.com) is a lighter alternative — tick the apps you want from its list and it builds a single installer for all of them.
