# Using Narrator in Windows 11

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Activate Narrator

- **Shortcut:** `Windows + Ctrl + Enter` to toggle on/off
- Alternative: **Settings → Accessibility → Narrator**

---

## What Narrator Can Do

- Reads text in Windows apps, browsers, and Office apps
- Works in Chrome, Edge, and Firefox — not limited to Windows apps
- Features include: image description (AI), Braille display support, Scan Mode
- Limitation: some older apps may not work well with it

---

## Change Voice Speed

- **Increase speed:** `Narrator key + Plus ( + )`
- **Decrease speed:** `Narrator key + Minus ( - )`
- Or go to `Windows + Ctrl + N` → *Customize Narrator's voice*
- You can also adjust **Pitch**, **Volume**, and **Voice language**

---

## Read an Entire Document

- **Read from current position:** `Narrator key + R`
- **Read from beginning:** `Narrator key + Ctrl + R`
- **Stop reading:** `Ctrl`
- Common fix: click inside the document first to ensure it has focus
- For browsers: enable **Immersive Reader (`F9`)** in Edge for smoother reading

---

> **Note:** The Narrator key is `Caps Lock` or `Insert`.
