# Setting Default View to Extra Large Icons in File Explorer

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Windows does not offer a single global switch to set Extra large icons for all folders. However, you can configure a folder template so that image folders consistently open with a large icon view.

## Step 1: Apply the Pictures Template

1. Right-click the folder you want to use for images and select **Properties**.
2. Open the **Customize** tab.
3. Under **Optimize this folder for**, select **Pictures**.
4. Check **Also apply this template to all subfolders**.
5. Click **Apply**, then **OK**.

Windows will automatically apply a thumbnail-friendly layout to the folder and its subfolders.

## Step 2: Save the Icon Size (Optional)

To push the view closer to Extra large icons rather than Large icons:

1. Open the folder configured in Step 1.
2. Switch the view to **Extra large icons** (or press `Ctrl`+`Shift`+`1`).
3. Click **...** → **Options**.
4. Open the **View** tab and click **Apply to Folders**.
5. Confirm **Yes**.

This combines the Pictures template with Explorer's saved view preference and improves the chances that subfolders inherit Extra large icons.

## Limitations

- Windows may default to **Large icons** instead of **Extra large icons** even after applying these settings. Large icons is a practical compromise as it behaves more reliably.
- Explorer's folder-view memory can reset after major Windows updates or if its view cache becomes corrupted.
- Different folder types (Pictures, Documents, Music, General items) store their view settings separately.
- Network drives and some special folders may ignore these settings entirely.
