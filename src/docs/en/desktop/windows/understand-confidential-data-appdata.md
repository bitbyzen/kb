# Understanding Confidential Data in AppData

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Before handing off, reselling, or wiping a Windows PC, clearing out the Documents folder isn't enough to protect your privacy. The real blind spot is `AppData`.

## What AppData Holds

`C:\Users\<username>\AppData` stores, per app:

- Browser profiles — saved passwords, autofill data, cookies, and logged-in sessions for Chrome, Edge, and others
- Local data and configuration for desktop apps, including Claude Desktop
- Cached data for most other installed apps

> **Warning:** An empty Documents folder means nothing if someone can open a browser profile that's still logged into your email or other accounts with saved passwords sitting there.

## What to Do About It

- Sign out of accounts and clear saved passwords in each browser before handing off the PC, or
- Reinstall Windows (or securely erase the drive) rather than relying on deleting individual folders, for a clean guarantee that no `AppData` contents carry over
