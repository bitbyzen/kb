# Check Storage on Synology DS720+

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Managing storage on your NAS is essential for maintaining performance and ensuring backups have enough room to grow. This guide covers the three best ways to monitor your DiskStation's capacity.

## Method 1: Quick View via Storage Manager

The fastest way to see a high-level summary of your total, used, and available space.

1. Log in to **DSM** (DiskStation Manager).
2. Open the **Main Menu** (top-left corner) and launch **Storage Manager**.
3. Select **Storage** from the left-hand sidebar.
4. Click on the **Volume** you wish to inspect.

> **Note:** Look for the "Used/Total" bar. If you have multiple volumes, check each one individually.

## Method 2: Granular Breakdown via Usage Details

If you are using the **Btrfs** file system (standard for the DS720+), you can see exactly which services (like Synology Drive or Snapshots) are consuming space.

1. Go to **Storage Manager** → **Storage**.
2. Click the **three dots (...)** icon on the specific volume.
3. Select **Usage Details**.
4. A categorized list appears showing space taken by:
    - Shared Folders
    - Snapshots
    - System Databases (e.g., Synology Photos, Drive)
    - Swap files

## Method 3: Deep Dive via Storage Analyzer

To find specific large files, duplicates, or space-hogging file types, use the **Storage Analyzer** package.

### Installation

1. Open the **Package Center**.
2. Search for **Storage Analyzer** and click **Install**.

### Running a Report

1. Open **Storage Analyzer**.
2. Go to **Report Profile** and click **Create**.
3. Follow the wizard to select which volumes to analyze.
4. Once the report is generated, select it and click **View Report**.

**Key Features:**

- **Large Files:** Identifies files exceeding a specific size.
- **Duplicates:** Finds identical files that can be safely deleted.
- **File Groups:** Shows a breakdown by type (Video, Image, Audio, etc.).

## Troubleshoot Missing Space

If the used space is significantly higher than your actual file size, check the following:

- **Drive Versioning:** Synology Drive keeps versions of files. Check the Admin Console in Drive to limit versions.
- **Recycle Bins:** Empty them via **Control Panel** → **Shared Folder** → **Action** → **Empty all Recycle Bins**.
- **Snapshots:** If using Snapshot Replication, old snapshots can occupy significant space until they rotate out.
