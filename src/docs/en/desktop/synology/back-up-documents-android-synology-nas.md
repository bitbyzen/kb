# Back Up Documents from Android to Synology NAS

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

This guide explains how to back up documents from an Android phone (e.g., Google Pixel) to a Synology NAS using Synology Drive in "Upload only" sync mode. This creates a one-way sync from phone to NAS.

> **Warning:** This is sync, not true backup. Deleting files on your phone may also delete them on the NAS. Enable versioning on your NAS to protect against accidental deletion.

## Step 1: Prepare Your NAS

1. Log in to DSM.
2. Open **Synology Drive Admin Console**.
3. Enable Team Folder if needed.
4. Enable versioning (recommended: 10–20 versions).

## Step 2: Open Synology Drive on Your Phone

1. Launch **Synology Drive**.
2. Tap **More**.
3. Tap **Backup and Sync Tasks**.
4. Tap **Sync Tasks**.
5. Tap the **+** icon.

## Step 3: Configure the Sync Task

### Local Path (Phone)

Choose the folder you want to back up. Examples:

```
Documents/
Download/
```

### Remote Path (NAS)

Choose or create a folder on your NAS. Example:

```
/home/Drive/PhoneBackup/Documents/
```

### Sync Mode

Select **Upload only**. Files go from phone to NAS. Changes on the NAS do not affect your phone.

## Step 4: Adjust Sync Rules

- Enable syncing over Wi-Fi only (recommended).
- Optionally restrict to charging state only.
- Review file size limits if applicable.

## Step 5: Start the Sync

1. Confirm your settings.
2. Tap **Done** / **Apply**.

Your files will now begin syncing.

## How It Works

| Action on Phone | Result on NAS |
|-----------------|---------------|
| Add file        | Uploaded      |
| Edit file       | Updated       |
| Delete file     | Deleted (see warning above) |

## Limitations

- No true backup isolation — this is sync
- Android limits full automation for arbitrary folders
- No full device backup capability

## Best Practices

- Keep documents in a dedicated folder (e.g., `Documents/`) for predictable sync behaviour.
- Use a dedicated NAS folder (e.g., `/home/Drive/PhoneBackup/`) to avoid mixing with other files.
- Enable versioning to protect against accidental deletion and file corruption.
- Avoid editing the same files from multiple devices simultaneously.
