# Running Claude on Synology NAS via Docker and API

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

This guide shows how to run Claude-powered workflows on a Synology NAS using Docker and the Anthropic API.

---

## 📌 Overview

Since Claude Desktop cannot run on Synology, the best approach is:

* Run a lightweight app in Docker
* Connect it to Claude via the Anthropic API
* Use it for automation, chat interfaces, or file processing

---

## ✅ Prerequisites

* Synology NAS with Container Manager (Docker) installed
* An Anthropic API key
* Basic familiarity with Docker and terminal/SSH

---

## 🔑 Step 1: Get an Anthropic API Key

1. Go to the Anthropic Console and sign in.
2. Create an API key.
3. Save it securely — you will need it later.

---

## 🐳 Step 2: Install Docker (Container Manager)

1. Open **Package Center**.
2. Install **Container Manager** (or **Docker** on older DSM versions).
3. Launch it.

---

## 📁 Step 3: Prepare a Project Folder

Create a shared folder for the app, for example:

```
/docker/claude-app/
```

Inside it, create three files:

```
app.py
requirements.txt
Dockerfile
```

---

## 🧾 Step 4: Create the App

### `app.py`

```python
from flask import Flask, request, jsonify
import requests
import os

app = Flask(__name__)

ANTHROPIC_API_KEY = os.environ.get("ANTHROPIC_API_KEY")

@app.route("/chat", methods=["POST"])
def chat():
    user_input = request.json.get("message")

    response = requests.post(
        "https://api.anthropic.com/v1/messages",
        headers={
            "x-api-key": ANTHROPIC_API_KEY,
            "anthropic-version": "2023-06-01",
            "content-type": "application/json"
        },
        json={
            "model": "claude-sonnet-4-6",
            "max_tokens": 500,
            "messages": [
                {"role": "user", "content": user_input}
            ]
        }
    )

    return jsonify(response.json())

@app.route("/")
def home():
    return "Claude API is running!"

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```

### `requirements.txt`

```
flask
requests
```

### `Dockerfile`

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY app.py .

CMD ["python", "app.py"]
```

---

## ⚙️ Step 5: Build the Docker Image

SSH into your Synology and run:

```bash
cd /volume1/docker/claude-app
docker build -t claude-app .
```

---

## ▶️ Step 6: Run the Container

```bash
docker run -d \
  -p 5000:5000 \
  -e ANTHROPIC_API_KEY=<YOUR-API-KEY> \
  --name claude-container \
  claude-app
```

---

## 🌐 Step 7: Test the API

Use `curl` to send a test message:

```bash
curl -X POST http://192.168.x.x:5000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Hello Claude"}'
```

You should receive a JSON response from Claude.

## ⚠️ Tips

* Low-power NAS models struggle with heavy workloads — keep apps lightweight.
* Monitor your Anthropic API usage to control costs.
* Use a smaller model (e.g., `claude-haiku-4-5-20251001`) for high-volume or latency-sensitive tasks.
* Never hardcode your API key in source files; always pass it as an environment variable.
