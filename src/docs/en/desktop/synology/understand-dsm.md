# Understanding DSM

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Synology DiskStation Manager (DSM) is the operating system built for Synology NAS devices.

It has a browser-based interface, which can make it feel like you are accessing a remote web service — but the OS itself is installed directly on the NAS hardware (the DiskStation).
