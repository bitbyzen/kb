# Understanding the Time & Pitch Module

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The **Time & Pitch** module adjusts the speed and pitch of audio independently. It is primarily designed for musical material (instruments and vocals) rather than spoken voice, so options for speech processing are limited.

## Core Parameters

**Stretch Ratio**
Controls playback speed. Lowering the value speeds up the audio; raising it slows it down.

**Pitch Shift**
Controls pitch in semitones. Negative values lower the pitch; positive values raise it.

## Algorithm

| Algorithm | Best for |
|-----------|----------|
| **Radius (best quality)** | Polyphonic material — instrument mixes, drum loops, rhythmic or non-harmonic audio |
| **Solo Instrument** | Monophonic material — solo strings, human voice |
| **Radius RT** | Polyphonic material where faster processing is needed; slightly lower quality than Radius |

> **Note:** Although **Solo Instrument** is described as suitable for human voice, **Radius (best quality)** often produces better results in practice. The optimal choice depends on the source material.

## Advanced Settings

| Setting | Effect on Human Voice |
|---------|----------------------|
| **Transient sensitivity** | No noticeable effect |
| **Pitch coherence** | Minimal effect despite the description suggesting otherwise |
| **Adaptive window** | No noticeable effect |
| **Noise generation** | Setting to `0` reduces background noise — the most useful advanced setting for human voice |

## Shift Formants

Formants are the resonance frequency components of a voice and are closely tied to characteristics such as gender and age. Enabling **Shift Formants** lets you adjust formants independently from pitch and time.

| Setting | Recommended value | Notes |
|---------|-------------------|-------|
| **Strength** | `1.0` (default) | Higher values may increase perceived volume |
| **Shift [Semitones]** | Varies | Negative values lower the voice character; this is the primary setting to adjust for human voice |
| **Width** | Default | No noticeable effect on human voice |
