# Converting Female Voices to Male Voices

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Use iZotope RX8's **Time & Pitch** module to shift a female voice toward a more masculine sound by lowering the pitch.

## Step 1: Open the Audio File

1. Launch iZotope RX8.
2. Drag and drop a video or audio file onto the application window.
3. RX8 analyzes the file and opens it in a new tab. Each file gets its own tab — dropping multiple files opens multiple tabs.

## Step 2: Open Time & Pitch

1. Look at the module list on the right side of the screen.
2. Click **Time & Pitch** to open the Time & Pitch dialog.

## Step 3: Adjust the Pitch

1. Find the **Pitch Shift** slider or input field.
2. Set the value to approximately **-6** semitones. This shifts the voice down to a more masculine range.

> **Note:** Formant adjustment is still experimental. Changing the formant alongside pitch can improve naturalness, but the optimal settings vary by voice. Try small adjustments and compare results.

## Step 4: Preview and Compare

1. Click **Compare** to open the Compare Settings dialog.
2. To hear the original, select **Original audio** and click **Preview**.
3. To hear your adjusted version, select **Time & Pitch: Settings 1** and click **Preview**.
4. If you create additional variations, each appears as **Settings 2**, **Settings 3**, and so on.

## Step 5: Remove Unwanted Variations

1. In the Compare Settings dialog, select the variation you want to discard.
2. Click **Remove** to delete it from the list.
