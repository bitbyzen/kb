# Fixing Settings Changes Not Applied in KensingtonWorks

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

If changes you make in KensingtonWorks do not take effect, reset all settings and restart the application.

## Steps

1. In KensingtonWorks, reset all settings to their defaults.
2. Restart KensingtonWorks.
3. Reapply your customizations.
