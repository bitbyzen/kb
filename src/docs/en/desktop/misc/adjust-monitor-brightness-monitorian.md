# Adjusting Monitor Brightness With Monitorian

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

**Monitorian** is a free, open-source Windows desktop app for adjusting the brightness — and optionally contrast — of multiple monitors from a single place. It lives in the system tray; clicking the icon brings up a brightness controller and access to the settings panel.

## Key Features

- Adjust brightness individually per monitor or all in unison
- Supports both built-in laptop screens and external monitors
- On systems with ambient light sensors, shows both the configured brightness and the sensor-adjusted brightness side by side to help fine-tune lighting
- Set custom min/max ranges for brightness and contrast per monitor
- Gesture control on precision touchpads
- Rename monitors to keep them organized in the UI

## Requirements and Limitations

To control an external monitor, the monitor must be **DDC/CI compatible** and the function must be enabled in the monitor's OSD menu. If the monitor is connected through a converter, docking station, or other device, that device must also be DDC/CI compatible.

If an external monitor does not appear in Monitorian, it is almost always a DDC/CI hardware limitation rather than a software issue.
