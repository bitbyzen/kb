# Creating a Window Layout Using FancyZones

1. Open **PowerToys**.

2. Select **FancyZones**.

    ![Screenshot](img/create-window-layout-using-fancyzones-01.webp)

3. Click **Open layout editor**
   *(Shortcut: Win + Shift + ` )*.

    ![Screenshot](img/create-window-layout-using-fancyzones-02.webp)

4. Click **Create new layout**.

    ![Screenshot](img/create-window-layout-using-fancyzones-03.webp)

5. Enter a **Name**.

6. Select the layout type:

    * **Grid** – stacked rows or columns
    * **Canvas** – freely positioned zones

7. Click **Create**.

    ![Screenshot](img/create-window-layout-using-fancyzones-04.webp)
