# Adding AivisSpeech to VOICEVOX

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

This isn't supported. AivisSpeech's engine and AIVMX voice models can't be added to VOICEVOX — only the VOICEVOX → AivisSpeech direction works, due to compatibility differences.

To bring VOICEVOX characters into AivisSpeech instead, see [Adding VOICEVOX Engine to AivisSpeech](../aivisspeech/add-voicevox-engine-to-aivisspeech.md).
