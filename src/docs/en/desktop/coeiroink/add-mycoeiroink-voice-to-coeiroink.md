# Adding a MyCoeiroInk Voice to CoeiroInk

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

MyCoeiroInk is the community voice library for CoeiroInk, where creators distribute downloadable voice characters.

**Example voice used: 白痴ー (Hakuchi)**
One of the most popular male voices on MyCoeiroInk, available in multiple style variations. The voice can also be used as a character called **黒聡 鵜月 (Kurosato Uzuki)**.

## Step 1: Download the Voice

1. Go to [https://coeiroink.com/mycoeiroink](https://coeiroink.com/mycoeiroink).
2. Click the center illustration **探す (Sagasu / Search)**, which navigates to the voice list at [https://coeiroink.com/mycoeiroink/list](https://coeiroink.com/mycoeiroink/list).
3. Enter **白痴ー (Hakuchi)** in the search box and press **Enter**.
4. Click the **白痴ー** panel in the results — this navigates to the distribution page on BOOTH.
5. Choose and download a variation as a ZIP file.

> **Note:** 白痴ー (Hakuchi) is distributed as multiple separate ZIP files, each representing a different style:
>
> | File name | Romaji | Style |
> |-----------|--------|-------|
> | 若輩.zip | Jakuhai | Inexperienced / junior (kohai) tone |
> | Others | — | Machine-like, Kansai dialect, etc. |
>
> If you are unsure where to start, **若輩 (Jakuhai)** is a good default.

## Step 2: Install the Voice into CoeiroInk

1. Extract the ZIP file — inside you will find a folder with an alphanumeric name (e.g. `a1b2c3d4...`).
2. Copy that alphanumeric folder into the `speaker_info` folder inside your CoeiroInk installation directory:

    ```
    [CoeiroInk folder]\speaker_info\[alphanumeric folder]
    ```

3. Launch (or restart) **CoeiroInk**.
4. Click the character icon at the top of CoeiroInk to open the character dropdown — the new voice should now appear.

## Step 3: Register the Voice in YMM4

1. In YMM4, go to **File → Edit character**.
2. Click the **+** button at the upper left to create a new character.
3. Enter a **Name** (e.g. `Kurosato Uzuki`).
4. Set **Group** to `COEIROINK`.
5. Under **Voice**, click the **↻** (circular arrow icon) next to the voice dropdown.
6. Select **Reload COEIROINK v2 voices** — this refreshes the available voice list.
7. In the **Voice** dropdown, select **COEIROINK2 / 白痴ー**.
8. The **Style** dropdown will be set automatically if only one style is installed (e.g. 若輩 / Jakuhai). If you have multiple styles installed, select the desired one manually.
9. Adjust other settings as needed (volume, pitch, speed, intonation, etc.).

## Notes

- Each style variation is a separate download — you can install multiple variations of the same character.
- If the voice still does not appear after reloading, restart YMM4 and try again.
