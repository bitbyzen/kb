# Fixing a MeCab Initialization Error

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Symptoms

Generating speech with a Japanese voice on the **Kokoro 82M** engine can fail with:

```
Generation failed
Failed initializing MeCab. Please see the README for possible solutions:
https://github.com/polm/fugashi
If you are still having trouble here, and include the ERROR DETAILS below:
https://github.com/polm/fugashi/issues
------------------- ERROR DETAILS -------------------
...
param.cpp(69) [ifs] no such file or directory: C:\Users\<username>\AppData\Local\Temp\_MEI######\unidic\dicdir\...
```

## Cause

Voicebox uses [fugashi](https://github.com/polm/fugashi), a Python wrapper around the **MeCab** Japanese tokenizer, to process Japanese text before synthesis. Per fugashi's README, MeCab always needs a dictionary to run — it can't tokenize anything without one. The `no such file or directory` line points straight at the dictionary path it expected (`unidic\dicdir`) inside `_MEI######`, a temporary folder that PyInstaller-packaged apps like Voicebox extract themselves into at launch. That folder is missing the UniDic dictionary files MeCab needs.

## What Fugashi's README Says

For a normal Python install, fugashi's own fix is to install a dictionary package:

| Option | Command |
|--------|---------|
| Quick start (smaller) | `pip install 'fugashi[unidic-lite]'` |
| Full dictionary | `pip install 'fugashi[unidic]'` then `python -m unidic download` |

> **Note:** These are `pip` commands for a Python environment you control. Voicebox is a self-contained Windows app, not something you `pip install` into, so this isn't a fix you can run yourself. It's included here to explain *why* the error happens, not as a direct solution.

## What You Can Try

- **Restart Voicebox and generate again.** The `_MEI######` folder name changes on every launch — if the dictionary files failed to extract because of a one-off glitch (antivirus interference, a locked file), a clean relaunch may extract them successfully.
- **Reinstall Voicebox.** If the dictionary was never bundled into your installed copy correctly, restarting won't help — reinstalling the latest version should re-extract the full package contents.
- **Stick to English voices** (either engine) if the above doesn't work. English generation doesn't depend on MeCab at all — it's Japanese-specific.
- **Report the error upstream.** If it persists after a reinstall, this looks like a Voicebox packaging bug — the dictionary genuinely isn't shipping inside the executable — rather than something fixable on the fugashi/MeCab side. File it with the full ERROR DETAILS block from the popup.
