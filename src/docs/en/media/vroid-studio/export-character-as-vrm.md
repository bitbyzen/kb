# Exporting a Character as VRM

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Exporting to **VRM** produces a single portable file that other applications — such as Unreal Engine via the VRM4U plugin — can import as a fully rigged character.

## Step 1: Prepare Your Character

Adjust hair, body proportions, face shape, and clothing as desired.

## Step 2: Open the Export Menu

Click **Export / Share** in the top-right corner.

## Step 3: Choose Export as VRM

Select **Export as VRM**.

## Step 4: Fill in the Metadata

Fill in the required metadata fields, such as **Title** and **Author**.

## Step 5: Save the File

Click **Export**, then save the `.vrm` file to a location you can find later.

> **Note:** To bring this character into Unreal Engine, see [Installing the VRM4U Plugin](../ue/install-vrm4u-plugin.md) and [Importing a VRM Character](../ue/import-vrm-character.md).
