# Using Custom Templates for Tops

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

**Custom Items** let you start a new clothing piece from one of VRoid Studio's built-in templates instead of building a mesh from scratch.

## Step 1: Start a New Custom Item

Select the **Outfit** tab, then **Tops**, then the **Custom** sub-tab. Click **Create New** under **Custom Items**.

![Custom Items panel with the Create New button highlighted](img/use-custom-templates-for-tops-01.png)

## Step 2: Choose a Template

In the **Choose Template** window, select the **Tops** category to browse the available base shapes, such as T-shirts, uniform vests, and hoodies.

![Choose Template window showing the Tops category with several template options](img/use-custom-templates-for-tops-02.png)

> **Note:** The left side of the **Choose Template** window also lists other categories — **Dresses**, **Bottoms**, **Neck Accessories**, **Arm Accessories**, and more — for starting custom items in those slots.

> **Note:** See [Creating a Custom T-Shirt](create-custom-tshirt.md) for a full walkthrough that continues from this point through editing and recoloring the texture.
