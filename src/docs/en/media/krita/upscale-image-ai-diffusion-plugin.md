# Upscaling an Image with the AI Diffusion Plugin

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Install the Krita AI Diffusion plugin with its own local server, then use its Upscale mode to enlarge a small anime face image 4×. This guide upscales a 285 × 340 image with two different upscale models.

> **Note:** Written using Krita 5.3.4.1, plugin v1.53.0, on Windows 11 with an RTX 3070 (8 GB).

## What You Need

The plugin adds an **AI Image Generation** panel to Krita. Its Upscale mode runs super-resolution models on a local server that the plugin installs for you. That server is separate from ComfyUI Desktop, so your ComfyUI setup isn't touched.

| Item | Used Here |
|---|---|
| Krita | 5.3.4.1. Use the copy from krita.org. |
| Plugin | v1.53.0, the build for **Krita 5** |
| GPU | NVIDIA RTX 3070, 8 GB VRAM (CUDA backend) |
| Disk | The installer asks for at least 16 GB free. |
| Input image | `ranza-01-004-01.png`, 285 × 340 |

> **Warning:** The newest entry on the releases page, 1.54.0-pre, is for Krita 6 and says it "No longer works with Krita 5.x". With Krita 5, download **1.53.0**.

In Krita, go to **Tools** → **Scripts** → **Import Python Plugin from File…**, select the zip, and click **Open**.

![Krita Tools, Scripts menu with Import Python Plugin from File highlighted](img/upscale-image-ai-diffusion-plugin-04.png)

A dialog says "AI Image Diffusion" was imported and asks to enable it. Click **Yes**. Then restart Krita: **File** → **Quit**, and start it again.

## Step 5: Open Your Image

Start Krita again and open the image you want to upscale (**File** → **Open**).

![Krita start screen after the restart, with no document open](img/upscale-image-ai-diffusion-plugin-08.png)

![Krita with ranza-01-004-01.png open, showing a character face on a white background](img/upscale-image-ai-diffusion-plugin-09.png)

## Step 6: Show the AI Image Generation Docker

Go to **Settings** → **Dockers** and tick **AI Image Generation**. The panel appears at the bottom right.

![Settings, Dockers menu with AI Image Generation highlighted but not ticked](img/upscale-image-ai-diffusion-plugin-10.png)

![The AI Image Generation panel now shows at the lower right with a Configure button](img/upscale-image-ai-diffusion-plugin-11.png)

> **Note:** The panel says "Connection attempt failed!" at this point. That's normal — no server is installed yet.

## Step 7: Click Configure

In the panel, click **Configure**. A settings window opens.

![The Configure button in the AI Image Generation panel is highlighted](img/upscale-image-ai-diffusion-plugin-12.png)

## Step 8: Choose Local Managed Server

The settings window has three connection types: Online Service, **Local Managed Server**, and Custom Server. This guide uses the local managed server, which installs its own ComfyUI inside Krita's data folder. Click **Local Managed Server** (it says "Not installed").

![Configure Image Diffusion window with Local Managed Server highlighted](img/upscale-image-ai-diffusion-plugin-13.png)

## Step 9: Check the Disk Space and Settings

The window says at least **16 GB** of free disk space is needed for a minimal install. The server path is `C:\Users\<user>\AppData\Roaming\krita\ai_diffusion\server`. The backend is **Use CUDA (NVIDIA GPU)**.

![The text "At least 16 GB of free disk space is required for a minimal installation" is circled](img/upscale-image-ai-diffusion-plugin-14.png)

![Windows C: drive properties showing free space](img/upscale-image-ai-diffusion-plugin-15.png)

> **Note:** Check your own free space in Explorer → right-click the drive → **Properties**.

## Step 10: Check the Backend

Leave the backend on CUDA for an NVIDIA card. The yellow text "Please select models for installation" disappears once you tick a model.

![Server path and the CUDA backend drop-down are circled](img/upscale-image-ai-diffusion-plugin-16.png)

## Step 11: Choose a Diffusion Model

On the **Workloads** tab, tick one model. Here: **Nova Anime XL** (SDXL, anime, needs about 6 GB VRAM, so it fits an 8 GB card). A diffusion model is only used by the optional "Refine" step — the plain upscale doesn't need it.

![Workloads tab with Nova Anime XL ticked under SDXL](img/upscale-image-ai-diffusion-plugin-17.png)

## Step 12: Open the Individual Packages Tab

Switch to **Individual Packages**. It lists every package: core components, workloads, **Upscalers (super-resolution)**, and model packs.

![Individual Packages tab, with the Upscalers group showing 2 packages, both not installed](img/upscale-image-ai-diffusion-plugin-18.png)

## Step 13: Tick the Upscalers

Under **Upscalers (super-resolution)**, tick both: **HAT Super-Resolution (quality)** and **Real HAT GAN Super-Resolution (sharper)**.

![Both HAT upscaler packages are ticked, the group shows 2 of 2 selected](img/upscale-image-ai-diffusion-plugin-19.png)

## Step 14: Look at the Nova Anime XL Group

Open **Illustrious/NoobAI XL models**. With Nova Anime XL ticked, the installer selects 9 of 13 packages: the checkpoint, six ControlNets (Inpaint, Scribble, Line Art, Canny, Depth, Pose), CLIP Vision G, and IP-Adapter. The ControlNets are for the plugin's other features — they aren't needed for the plain upscale.

![Illustrious/NoobAI XL models list, 9 of 13 packages selected](img/upscale-image-ai-diffusion-plugin-20.png)

## Step 15: Click Install

Go back to the **Workloads** tab if you like, then click **Install** and wait. The models are large, so this takes a while.

![The Install button is highlighted](img/upscale-image-ai-diffusion-plugin-21.png)

## Step 16: Check that the Server Runs

When it finishes, the window says **Server running – Connected** and Local Managed Server turns green.

![Window showing Server running - Connected in green and Nova Anime XL in green](img/upscale-image-ai-diffusion-plugin-22.png)

## Step 17: Check What's Installed

On **Individual Packages**, "Core components" and "Upscalers" say **All installed**, and the ticked models show "Installed".

![Individual Packages showing Core components and Upscalers as All installed, with Nova Anime XL and two ControlNets installed](img/upscale-image-ai-diffusion-plugin-23.png)

![The Illustrious/NoobAI XL list with the nine packages marked Installed](img/upscale-image-ai-diffusion-plugin-24.png)

## Step 18: Switch the Panel to Upscale

Click **Ok** to close the settings. At the top left of the AI Image Generation panel there's a small mode button. Click it and choose **Upscale**. The other modes are Generate, Live, Animation, and Graph.

![Krita with the AI Image Generation panel in Generate mode](img/upscale-image-ai-diffusion-plugin-25.png)

![Mode drop-down with Generate, Upscale, Live, Animation and Graph; Upscale is highlighted](img/upscale-image-ai-diffusion-plugin-26.png)

## Step 19: Look at the Upscale Settings

The panel now shows a model drop-down, a **Scale** slider, **Refine upscaled image** (ticked by default), and Strength, Image guidance, Tile overlap, and Use Prompt. By default the model is *Default (4x_NMKD-Superscale-SP_178000_G)* and the scale is 2.00×.

![AI Image Generation panel in Upscale mode with the default model, scale 2.00x and Refine upscaled image ticked](img/upscale-image-ai-diffusion-plugin-27.png)

## Step 20: Choose a Model

Open the model drop-down. It has four entries: *Default (4x_NMKD-Superscale-SP_178000_G)*, *Fast (OmniSR_X4_DIV2K)*, *Quality (HAT_SRx4_ImageNet-pretrain)*, and *Sharp (Real_HAT_GAN_sharper)*. Pick **Quality** first.

![Upscale model drop-down listing four models with Quality highlighted](img/upscale-image-ai-diffusion-plugin-28.png)

## Step 21: Set the Scale to 4×

Set **Scale** to **4.00×**. The panel shows the *Target size*: 1140 × 1360 for this image.

![Scale field set to 4.00x with Target size 1140 by 1360 shown below](img/upscale-image-ai-diffusion-plugin-29.png)

## Step 22: Turn off Refine and Click Upscale

Untick **Refine upscaled image**, then click **Upscale**. With Refine off, only the super-resolution model runs — no diffusion model changes the picture.

![Refine upscaled image is unticked and the Upscale button is highlighted](img/upscale-image-ai-diffusion-plugin-30.png)

## Step 23: Look at the Result

The result is added as a new layer named like *[Upscale] 1140x1360*, and the canvas becomes 1140 × 1360.

![A new layer named Upscale 1140x1360 above Background, zoomed into hair and eye at 258 percent](img/upscale-image-ai-diffusion-plugin-31.png)

## Step 24: Compare with the Plain Resize

Click the **eye icon** next to the new layer to hide it. You then see the layer below: your original, stretched to the new size by a plain resize. Click the eye again to show the upscale.

![Eye icon of the upscale layer is highlighted and the layer is hidden; the stretched original is visible](img/upscale-image-ai-diffusion-plugin-32.png)

![Eye icon is on again and the AI-upscaled result is visible](img/upscale-image-ai-diffusion-plugin-33.png)

## Step 25: Rename the Layer and Save

Rename the layer so you know which model made it (here: `Upscaled_by_HAT_SRx4_ImageNet-pretrain`). Then save with **File** → **Save As** as a layered `.kra`, not over the original PNG.

![Layer list showing Upscaled_by_HAT_SRx4_ImageNet-pretrain above Background; the title bar says ranza-01-004-01.kra](img/upscale-image-ai-diffusion-plugin-34.png)

## Step 26: Select the Layer to Upscale

Click the layer you want to use as the source. Here it was **Background**, which is the original stretched to 1140 × 1360.

![Background layer highlighted in the layer list](img/upscale-image-ai-diffusion-plugin-35.png)

Choose **Sharp (Real_HAT_GAN_sharper)**, keep **Scale 4.00×** and Refine off, then click **Upscale**.

![Model drop-down set to Sharp (Real_HAT_GAN_sharper), scale 4.00x, and the Upscale button, marked 1, 2 and 3](img/upscale-image-ai-diffusion-plugin-36.png)

## Step 29: Compare the Two Models

Switch the eye icons to compare. Here, the first model (Quality) shows a fine scale-like texture on flat colours such as the skin and the white of the eye. The second (Sharp) has smoother flat colours.

## Step 30: View the Whole Image

Zoom out to see the whole image. Rename this layer too (here: `Upscaled_by_Real_HAT_GAN_sharper`) and save the `.kra` again.

## Step 31: Run It Again from the Original, for a Fair Test

The first comparison was unfair because of the grown canvas. Reopen the original PNG (285 × 340), choose **Sharp**, scale **4.00×**, and press **Upscale**.

## Notes and Limits

> **Note:** The first comparison wasn't fair, because the second run was 16× on the enlarged canvas. Running Sharp again from a fresh copy of the original (285 × 340 to 1140 × 1360, 4×) finished quickly, with smooth flat colours and clean lines, with no scale-like texture. So for this flat anime face, **Sharp is the better choice**. Quality wasn't re-run on its own, so the texture is only confirmed for the Quality layer in the first test. For a fair comparison, run each model once from the original at the same scale and compare at 100% zoom.

> **Note:** Not tested: the *Default* (4x_NMKD-Superscale) and *Fast* (OmniSR) models, and the "Refine upscaled image" option. Refine runs a diffusion model (here Nova Anime XL) over the result, which can add detail but may also change the face.

> **Note:** Upscaling enlarges everything, including flaws. The white patch in the character's eye in the source image is larger in the results, and it stays jagged in the Sharp result too — neither upscaler fixes it. Fix such flaws in the source before upscaling.

> **Warning:** The plugin is GPL-3.0 and the HAT project is Apache-2.0. Neither says anything about the model weights or about images made with them. Nothing forbids publishing the results, but nothing confirms it either. The Default and Fast upscalers, and the Nova Anime XL checkpoint, weren't individually checked. A sibling model by the same author says "You cannot use the generated images for commercial use if it's not edited". Treat Nova Anime XL as unchecked before using the Refine option for anything you publish. This is not legal advice.

| Problem | What to Do |
|---|---|
| "Connection attempt failed!" in the panel | No server yet. Click **Configure** and install the Local Managed Server. |
| The plugin doesn't load or breaks after an update | Check that you use 1.53.0 with Krita 5. The 1.54.0-pre build needs Krita 6. |
| The upscale is huge and slow (16×) | The canvas was already enlarged. Run from a fresh copy of the original, or use a smaller scale. |
| Install fails | Click **View log files** in the settings window and read the first error line. Make sure Krita comes from krita.org, not the Windows Store or Steam. |
