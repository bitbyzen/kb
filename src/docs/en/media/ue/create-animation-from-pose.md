# Creating an Animation from a Pose

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

This walkthrough builds a single-expression `Animation Sequence` from scratch by keyframing one facial curve, starting from an existing pose-holding asset. The example uses `A_face_silber`, an Animation Sequence belonging to the `silber` VRM character (folder `VroidSilber`), and creates a new expression animation named `SKEL_silber_anim_surprised` around the `Fcl_ALL_Surprised` curve.

> **Note:** See [Creating a Pose Asset from an Animation Sequence](create-pose-asset-from-animation.md) for the reverse workflow — turning an animation like the one built here back into a Pose Asset.

## Adding Start and End Keys

### Step 1: Open the Source Animation

In the Content Browser, open the `VroidSilber` folder and double-click `A_face_silber` (an `Animation Sequence`) to open it.

![Content Browser showing the VroidSilber folder with the A_face_silber Animation Sequence selected among other silber character assets](img/create-animation-from-pose-01.png)

### Step 2: Create an Animation from the Current Pose

With `A_face_silber` open, click **Create Asset** → **Create Animation**, then select **Current Pose**.

![Create Asset menu open with the Create Animation flyout showing Reference Pose, Current Pose, and Current Animation options, with Current Pose highlighted and a Create Animation from current pose tooltip visible](img/create-animation-from-pose-02.png)

> **Note:** **Current Pose** captures only the single frame the playhead is currently on, producing a fresh one-frame Animation Sequence. This is the opposite choice from [Creating a Pose Asset from an Animation Sequence](create-pose-asset-from-animation.md), which uses **Current Animation** to capture an entire existing clip.

### Step 3: Name the New Animation Asset

A **Create a New Animation Asset** dialog opens. Confirm the destination folder and the animation's name. The screenshot shows the `VroidSilber` folder selected and the **Animation Name** field pre-filled as `SKEL_silber_anim_surprised`.

![Create a New Animation Asset dialog with the VroidSilber folder selected and the Animation Name field showing SKEL_silber_anim_surprised](img/create-animation-from-pose-03.png)

Click **OK** to create the file.

### Step 4: Confirm the Animation Opens Automatically

The new animation asset opens in its own editor tab automatically. At this point its **Curves** section is empty (`Curves (0)`).

![New animation editor tab open automatically, previewing SKEL_silber_anim_surprised on the silber character, with the Curves panel showing Curves (0)](img/create-animation-from-pose-04.png)

### Step 5: Open the Add Curve Menu

Next to **Curves**, open the dropdown and select **Add Curve...**. This opens a **Create Curve** panel listing every available curve name on the skeleton, in alphabetical order.

![Curves panel dropdown open with Add Curve highlighted, and the Create Curve panel showing the full alphabetical list of available curve names](img/create-animation-from-pose-05.png)

### Step 6: Select the Curve

Type into the **Create Curve** search box to filter the list. Searching `sur` narrows the list to the `Surprised` family of curves — `Face.M_F00_Fcl_ALL_Surprised`, `Fcl_BRW_Surprised`, `Fcl_EYE_Surprised`, and `Fcl_MTH_Surprised`. Select `Fcl_ALL_Surprised`.

![Create Curve panel with sur typed into the search box, filtering to Face.M_F00_Fcl_ALL_Surprised and related BRW, EYE, and MTH entries, with Fcl_ALL_Surprised highlighted](img/create-animation-from-pose-06.png)

> **Note:** The narrower `BRW` (brow), `EYE`, and `MTH` (mouth) curves drive only one part of the face each. `ALL` drives the combined expression across all three at once, which is why it's the one picked for a single-expression animation.

### Step 7: Open the Curve Editor

The `Fcl_ALL_Surprised` curve now appears under **Curves**. Open its row's dropdown and select **Edit Curve** to open the Curve Editor tab.

![Curves list now showing Fcl_ALL_Surprised, with its row dropdown menu open and Edit Curve highlighted, tooltip reading Edit this curve in the curve editor tab](img/create-animation-from-pose-07.png)

### Step 8: Add a Key at the Start

In the Curve Editor, right-click the empty graph area and select **Add Key**. A key is added at the playhead's current position — the animation's starting point, with a value of `0`.

![Curve Editor right-click context menu open with Add Key highlighted, tooltip reading Add a new key to all curves at the current time](img/create-animation-from-pose-08.png)

![Curve Editor showing a key added at time 0 with value 0, selected at the sequence's start](img/create-animation-from-pose-09.png)

### Step 9: Move the Playhead Toward the End

Drag the playhead across the timeline toward the animation's end point.

![Playhead dragged partway across the Curve Editor's time ruler, tooltip reading 0+ (0.02) (59%)](img/create-animation-from-pose-10.png)

> **Note:** See [Moving the Playhead](move-playhead.md) for the two ways to position the playhead precisely — dragging the ruler, or typing an exact frame number.

### Step 10: Add a Key at the End

Right-click the graph again and select **Add Key**. A second key is added at this new playhead position.

![Right-click context menu open again at the new playhead position with Add Key highlighted](img/create-animation-from-pose-11.png)

![A second key added at the new position, selection fields reading 0.033333 and 0.0](img/create-animation-from-pose-12.png)

### Step 11: Raise the End Key to `1`

With the new key selected, edit its value field and set it to `1`. The curve now draws as a rising diagonal line from `0` to `1` — the single-expression animation is complete.

![Selected end key's value field changed to 1.0, curve now drawn as a rising diagonal line from 0 to 1](img/create-animation-from-pose-13.png)

## Checking the Created Animation

### Step 1: Disable Looping

In the transport bar below the preview, click the loop-mode button until its tooltip reads `No Looping`. This prevents the playback from repeating.

![Transport bar with the loop-mode button highlighted, tooltip reading No Looping](img/create-animation-from-pose-14.png)

### Step 2: Return the Playhead to the Start

Click the jump-to-start button in the transport bar to move the playhead back to frame `0`.

![Transport bar with the jump-to-start button highlighted, playhead back at 0 (0.00) (0%)](img/create-animation-from-pose-15.png)

### Step 3: Slow Down Playback

Open the playback speed dropdown and select `x0.1`. At full speed, a one-second animation plays too fast to evaluate frame by frame.

![Playback speed dropdown open with x0.1 highlighted, tooltip reading Set the animation playback speed to a tenth of normal](img/create-animation-from-pose-16.png)

### Step 4: Play the Animation

Click **Play**. The silber character's expression rises smoothly into the surprised pose — mouth open, eyes widened — confirming the curve works as expected.

![Play button highlighted in the transport bar, silber character's mouth open in the surprised expression, playhead at 1 (0.03) (100%)](img/create-animation-from-pose-17.png)

## Increasing the Play Duration

A newly created single-pose animation defaults to a very short play duration (one frame's worth of time). To stretch it out:

### Step 1: Right-Click the Time Row and Append Frames

Right-click the time row (the ruler above the curve graph) and select **Append frames at end of sequence**.

![Right-click context menu on the time row with Append frames at end of sequence highlighted](img/create-animation-from-pose-18.png)

### Step 2: Set the Number of Frames to Add

A **Number of Frames to Add** field appears. Enter `1` and confirm.

![Number of Frames to Add field showing 1](img/create-animation-from-pose-19.png)

### Step 3: Locate the Shifted Key

Appending a frame doubles the total sequence length. The key that used to sit at the animation's end (100%) now reads as sitting at the sequence's midpoint.

![Curve Editor after appending, selection readout showing the existing key now at 1 (0.03) (50%) of the extended sequence](img/create-animation-from-pose-20.png)

### Step 4: Disable Time Snapping

Select that key, then click the **Toggle Time Snapping** icon in the Curve Editor toolbar to turn snapping off. This is required to move the key to an exact time rather than the nearest whole frame.

![Toggle Time Snapping icon highlighted in the Curve Editor toolbar, with the key at time 0.033333 selected](img/create-animation-from-pose-21.png)

### Step 5: Move the Key Back to the Start

With snapping disabled, edit the selected key's time field and set it to `0`.

![Selected key's time field changed to 0.0, snapping icon no longer highlighted](img/create-animation-from-pose-22.png)

> **Note:** The source memo describes this move as necessary to "play the same animation in 2 seconds," but neither the memo nor the screenshots fully explain the resulting curve shape after the key is relocated — the numeric field changes are confirmed here, but the underlying reasoning isn't independently verified in this session. Treat this step as documented technique rather than a fully explained mechanism.

> **Note:** See [Understanding the Number of Sampled Frames Limit](understand-sampled-frames-limit.md) for background on **Append Frames at End of Sequence** and why an Animation Sequence's frame count can't be edited directly in the Details panel.

### Step 6: Play the Extended Animation

Click **Play** again. The same expression now plays out across the extended, two-frame timeline.

![Play button highlighted again, mouth open, playhead reaching further across the extended timeline](img/create-animation-from-pose-23.png)

## Decreasing the Play Duration

To shrink the play duration back down — for example, from two seconds back to one:

### Step 1: Move the Playhead to the New End Point

Use the transport bar's step-back button (or drag the ruler) to move the playhead to the frame where you want the animation to end — in this case, the `1` second mark.

![Transport bar's step-back button highlighted, playhead at 1 (0.03) (50%)](img/create-animation-from-pose-24.png)

### Step 2: Remove the Frames After That Point

Right-click the time row and select **Remove frames in range 2 to 2**.

![Right-click context menu on the time row with Remove frames in range 2 to 2 highlighted, tooltip reading Remove sequence after current position](img/create-animation-from-pose-25.png)

> **Warning:** Removing frames trims the sequence permanently. Undo (`Ctrl+Z`) recovers it within the same editing session, but there's no separate confirmation step before the frames are cut.

The sequence's total length drops back to `1`.

![After removing frames, playhead back at 0 (0.00) (0%), sequence length field reading 1 (0.033s)](img/create-animation-from-pose-26.png)

### Step 3: Select the Key at the End Point

Because the sequence's total length was cut in half, the key that used to sit at the very end now evaluates partway through the shortened curve — its value tooltip reads `0.5` instead of `1`.

![Selected key's tooltip reading Name: Fcl_ALL_Surprised, Time: 0.033, Value: 0.5](img/create-animation-from-pose-27.png)

### Step 4: Set the Value Back to `1`

Edit the key's value field and set it back to `1`, restoring the full expression at the new end point.

![Selected key's value field changed back to 1.0](img/create-animation-from-pose-28.png)

### Step 5: Play the Restored Animation

Click **Play** to confirm the animation now plays the full expression across the shortened, one-second timeline again.

![Play button highlighted, mouth open, final check of the restored one-second animation](img/create-animation-from-pose-29.png)
