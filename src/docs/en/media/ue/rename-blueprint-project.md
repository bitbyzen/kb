# Renaming a Blueprint Project

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

> **Reference Video:** [UE5 Quick Tip 24: 3 Steps to Correctly Rename Your Projects](https://www.youtube.com/watch?v=qGn1SfX6s9I) by *WorldofLevelDesign*

Renaming a project's folder alone breaks it — Unreal Engine also needs the `.uproject` file and a few config entries updated to match. This applies to **Blueprint projects only**; C++ projects need additional code references updated too.

## Step 1: Rename the Outer Project Folder

In the Epic Games Launcher, go to **Library**, right-click the project, and select **Show in Folder**. Go up one directory level and rename the project folder itself.

> **Note:** Keep project names under 20 characters, and use underscores instead of dashes.

## Step 2: Rename the .uproject File

Open the renamed project folder. Locate the `.uproject` file (for example, `OldName.uproject`) and rename it to match the folder's new name exactly.

## Step 3: Update DefaultEngine.ini

Open `Config/DefaultEngine.ini` inside the project folder and update three entries to the new name:

- Under `[URL]`, update `GameName=YourNewName`.
- Under `[/Script/Engine.Engine]`, update both references to the old project name.

Save and close the file.

## Result

Double-click the `.uproject` file to launch the renamed project. The Epic Games Launcher automatically updates to show the new name.
