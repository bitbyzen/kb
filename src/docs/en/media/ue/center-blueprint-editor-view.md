# Centering the View in the Blueprint Editor

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

These techniques re-center or zoom the Blueprint graph editor to fit its nodes on screen.

## Method 1: Fit All Nodes in View

1. Click inside the graph area (the empty gray space) to give the Blueprint editor panel focus.
2. Press **Home**.
3. The view zooms and pans to fit all nodes in the current graph.

Use this when the graph feels scattered or you've lost track of where everything is.

## Method 2: Fit Selected Nodes in View

1. Select the nodes you want to focus on — click a single node, drag a selection box around several, or hold **Ctrl** and click each node to add it to the selection.
2. Press **F**.
3. The view zooms and pans to fit only the selected nodes.

Use this to jump to one part of a large graph, such as a specific event chain.

## Method 3: Pan and Zoom Manually

1. Hold the right mouse button and drag to pan around the graph.
2. Scroll the mouse wheel to zoom in or out.
3. Release the right mouse button once you're positioned where you want.

## Quick Reference

| Action | Shortcut |
|---|---|
| Fit all nodes in view | Home |
| Fit selected node(s) in view | F |
| Pan | Right-click + drag |
| Zoom | Mouse scroll wheel |
