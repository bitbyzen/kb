# Placing a Character Blueprint in the Scene

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Steps

1. Open the **Content Drawer** (`Ctrl + Space`).

2. Navigate to the asset's **Blueprints → Characters** folder.

3. Locate the character Blueprint file (blue icon). For the Anime Character Pack, this is `bp_AnimeCharacter`.

    > **Note:** Use the Blueprint file, not the raw Skeletal Mesh (`SK_...`). The Blueprint includes animation support and character logic.

4. Click and drag the Blueprint into the **Viewport** and release to place the character.

5. If the character is facing backward, rotate it 180°:

    1. Select the character in the Viewport.
    2. Press **E** to activate the Rotate tool.
    3. In the **Details** panel under **Transform → Rotation**, set **Z** to `180` and press `Enter`.
