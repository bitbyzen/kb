# Capturing Unreal Editor Screenshots with Claude Code

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

With the [Unreal MCP plugin](set-up-mcp-plugin-for-claude-code.md) connected, Claude Code can capture screenshots of the Unreal Editor directly — no external screenshot tool or browser automation needed.

## Available Capture Tools

The plugin's `EditorToolset.EditorAppToolset` toolset exposes three image-capture tools:

| Tool | Captures |
|---|---|
| `CaptureEditorImage` | The entire editor application as you see it on your desktop — all panels, viewport, outliner, and so on. Use this for a general screenshot of the editor. |
| `CaptureViewport` | Just the level viewport, with optional annotation overlays (a world-space grid, plus actor name/position labels) — useful for spatial reasoning tasks such as directing actor placement. |
| `CaptureAssetImage` | A thumbnail of a specific asset, such as a static mesh, material, or texture. |

All three return a `ToolsetImage` — base64-encoded PNG data plus its MIME type.

## Working Around Large Results

The raw tool result can be large enough to exceed the tool-output token limit, in which case it's redirected to a saved file instead of being returned inline. To view it anyway:

1. Parse the JSON result and extract `returnValue.data`.
2. Base64-decode it and write it out as a PNG file — for example, in PowerShell:

    ```powershell
    [System.IO.File]::WriteAllBytes(
        "<YOUR-FOLDER>\screenshot.png",
        [System.Convert]::FromBase64String($base64Data)
    )
    ```

3. Read the resulting PNG file to view it.

## Example Call

```plaintext
mcp__unreal-mcp__call_tool(
  tool_name = "CaptureEditorImage",
  toolset_name = "EditorToolset.EditorAppToolset",
  arguments = {}
)
```
