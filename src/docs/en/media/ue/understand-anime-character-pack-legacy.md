# Understanding Anime Character Pack (Legacy)

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

**Anime Character Pack (Legacy)** by Studio SyndiCat is a starter pack of anime-style character meshes (male and female) for Unreal Engine, including base meshes, multiple clothing pieces, hairstyles, and textures for easy customization.

> **Warning:** This asset pack is marked **Legacy** on Fab — it won't receive further updates or support.

## Features

- 2 body types (Average Male & Average Female)
- 1 head, 3 tops, 3 bottoms, and 2 hairstyles for each body type
- Custom anime-style character shader
- Blueprint-ready for easy face animation in Level Sequences
- Control Rig included for body and face — the **Control Rig** plugin is required for full use
- Rigged to the Epic skeleton

See [Changing Clothing in Anime Character Pack (Legacy)](change-clothing-anime-character-pack.md) for how to swap tops, bottoms, or hairstyles on a character.

## Included Locomotion Animations

The pack includes 17 locomotion assets:

| Set | Assets |
|---|---|
| Walk (8 directions) | `a_man_walk_F`, `_B`, `_LF`, `_LB`, `_RF`, `_RB`, plus two more |
| Jog (6 directions) | `a_man_jog_F`, `_B`, `_LF`, `_LB`, `_RF`, `_RB` |
| Others | `a_man_run_F`, `a_man_sprint`, `a_manM_idle`, `ThirdPerson_Jump_Loop` |

`abs_Loco_Move` is a blend space that combines walk, jog, and run into a single movement graph driven by speed.
