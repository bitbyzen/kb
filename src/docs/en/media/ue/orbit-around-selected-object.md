# Orbiting Around the Selected Object

Rotate the camera around the selected object.

## Steps

1. Select an object in the **Viewport** or **Outliner**.
2. Press **F** to focus on the object.
3. Hold **Alt**.
4. Hold the left mouse button and move the mouse to orbit around the object.

## Optional

* Hold **Alt** + middle mouse button to pan.
* Hold **Alt** + right mouse button to zoom.

## Tips

* Press **F** on the object first — it centers the orbit pivot on it, so `Alt` + left mouse button drag spins cleanly around it instead of some far-off point.
* The **Orbit toggle** button in the viewport toolbar (near the camera-speed controls) lets you orbit with a plain left mouse button drag once enabled — handy if you don't want to hold `Alt`.
