# Setting Up Animation for a VRM Character

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

After [importing a VRM character](import-vrm-character.md) with VRM4U, retarget the default mannequin animations onto it, wire up an Animation Blueprint, and assign both to a playable character Blueprint.

## Part 1: Retarget Mannequin Animations

### Step 1: Open the Retarget Menu

Navigate to the default mannequin animation folder, such as `Characters/Mannequins/Animations/`. Right-click **ABP_Manny** (or **ABP_Quinn**) and select **Retarget Animation Assets**.

### Step 2: Configure the Retarget Target

In the retarget window, uncheck **Auto-generate Retargeter**. Set **Target Skeletal Mesh** to your imported VRM character mesh, and **Retarget Asset** to the IK Retargeter that VRM4U generated — it automatically matches A-pose alignment.

### Step 3: Select and Export Animations

Select the animations and blendspaces to transfer, such as:

- Idle (`MF_Idle` or `MM_Idle`)
- Walk/Run blendspace (`BS_MM_WalkRun`)
- Jump start (`MM_Jump`)
- Fall loop (`MM_FallLoop`)

Click **Export Animations**, choose a destination folder, such as `Content/AnimeCharacter/Animations`, and confirm the export.

## Part 2: Create an Animation Blueprint

### Step 4: Create the Blueprint

In your character folder, right-click and select **Animation** → **Animation Blueprint**. Select your VRM character's skeleton and name the Blueprint, such as `ABP_AnimeCharacter`.

### Step 5: Copy the Event Graph

Open your new Animation Blueprint alongside `ABP_Manny`. Copy the **Event Graph** nodes from `ABP_Manny` into your Blueprint's Event Graph, then right-click any missing variable warnings (`Velocity`, `ShouldMove`, `IsFalling`, and so on) and select **Create Variable**.

### Step 6: Copy the Anim Graph and Update References

Copy the **Anim Graph** state machine nodes from `ABP_Manny`. Open each state and update the animation references:

- **Locomotion / Idle** — replace the default mannequin idle with your retargeted idle animation, and make sure **Loop Animation** is checked.
- **Walk/Run** — replace with the retargeted `BS_MM_WalkRun` blendspace and wire it to **Ground Speed**.
- **Jump / Fall** — replace with the retargeted jump and fall animations.

> **Note:** If mesh distortion occurs during land transitions, try unlinking or removing the landing additive animation.

Compile and save the Blueprint.

## Part 3: Assign the Character Blueprint

### Step 7: Set the Mesh and Animation Class

Open your playable character Blueprint, such as `BP_ThirdPersonCharacter`. Select the **Mesh** component and set **Skeletal Mesh** to your imported VRM character mesh, and **Anim Class** to your new Animation Blueprint.

### Step 8: Adjust the Capsule Component

Select the **Capsule Component** and adjust its height and radius to match the smaller anime character scale — for example, lower **Capsule Half Height** to around 85–87. Adjust the mesh's vertical position slightly down so the character's feet sit precisely on the base of the capsule.

### Step 9: Test

Compile, save, and press **Play** to test movement, jumping, and the cell-shaded visuals.
