# Checking the Polygon Count

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Show the Statistics Overlay

Click the **Overlays** dropdown (the two overlapping circles icon in the viewport header), then check **Statistics**. This shows a live text overlay in the top-left of the viewport with Verts, Edges, Faces, Tris, and Objects counts, updating as you select things.

## Show Scene Statistics in the Status Bar

Right-click the status bar at the bottom of the window and enable **Scene Statistics** for the same breakdown, always visible for the whole scene.

> **Note:** With modifiers like [Mirror](apply-mirror-modifier.md) or [Subdivision Surface](apply-subdivision-surface-modifier.md) applied, the Faces count in Edit Mode reflects the base, unmodified mesh — not the final result. Switch to Object Mode to see the modifier-evaluated count; Blender's Statistics overlay typically shows both the base mesh and evaluated mesh counts when modifiers are active.
