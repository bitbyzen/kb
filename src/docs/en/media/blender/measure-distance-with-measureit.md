# Measuring a Distance with MeasureIt

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

**MeasureIt** is a free Blender add-on that displays distance, angle, and area measurements directly in the viewport.

## Step 1: Open Preferences

Go to **Edit** → **Preferences**.

![Edit menu with Preferences highlighted](img/measure-distance-with-measureit-01.png)

## Step 2: Search for MeasureIt

In Preferences, click **Get Extensions**, then search for `measureit`.

![Preferences window with the Get Extensions tab highlighted](img/measure-distance-with-measureit-02.png)

![Get Extensions search results showing MeasureIt, with the Install button highlighted](img/measure-distance-with-measureit-03.png)

## Step 3: Install and Enable It

Click **Install**.

![MeasureIt now listed under Installed](img/measure-distance-with-measureit-04.png)

Click the **Add-ons** tab to confirm it's enabled.

![Add-ons list with MeasureIt checked and enabled](img/measure-distance-with-measureit-05.png)

## Step 4: Save Preferences

Open the menu in the lower-left corner, then click **Save Preferences** so MeasureIt stays enabled the next time you open Blender.

![Preferences menu with Save Preferences highlighted](img/measure-distance-with-measureit-06.png)

## Step 5: Open MeasureIt Tools

In Edit Mode, open the viewport sidebar's **View** tab (press `N` if it's closed), then expand **MeasureIt Tools**.

![Viewport sidebar with the View tab highlighted and MeasureIt Tools collapsed](img/measure-distance-with-measureit-07.png)

![MeasureIt Tools panel expanded, showing Show and Add Measures options](img/measure-distance-with-measureit-08.png)

## Step 6: Measure Between Two Vertices

Select 2 vertices, then click **Segment**.

![Segment button highlighted, with a tooltip reading "(EDITMODE only) Add a new measure segment between 2 vertices (select 2 vertices or more)"](img/measure-distance-with-measureit-09.png)

## Step 7: Show the Measurement

Click **Show** to display the measurement in the viewport.

![Show button highlighted, with an Items list now showing the Bracket object's measurements](img/measure-distance-with-measureit-10.png)

![Measurement line and label reading "0.01 m" shown in the viewport between the two selected vertices](img/measure-distance-with-measureit-11.png)

## Step 8: Change the Measurement Unit

Under **Units**, choose **Millimeters** (or another unit) for a more readable value at this scale.

![Units dropdown open with Millimeters highlighted](img/measure-distance-with-measureit-12.png)

![Same measurement now displayed as "8.60 mm"](img/measure-distance-with-measureit-13.png)
