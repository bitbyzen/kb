# Checking Whether Two Shapes Are One Object

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Two shapes can look separate in the viewport while actually being one mesh — a single object with two disconnected "islands" of geometry. In that case, **Join** won't do anything new, since they're already joined.

## Check Whether They're Separate

In Object Mode, hover over one shape and press `L` (or click it).

- If only that shape highlights, the shapes are **separate objects**.
- If both highlight together, they're already part of the **same object**.

## Split and Rejoin Properly

If they turn out to be the same object and you want to treat them as separate again:

1. Press `Tab` to enter **Edit Mode**.
2. Hover over just the piece you want to separate and press `L` to select its linked vertices and faces only.
3. Press `P` → **Selection** to separate it into its own object.
4. Back in **Object Mode**, select the new object, then `Shift`+click the main shape, then press `Ctrl+J` to join them (see [Joining Multiple Objects](join-multiple-objects.md)).

This gives the two pieces independent origins and transforms again, so operations like Join behave the way you'd expect.
