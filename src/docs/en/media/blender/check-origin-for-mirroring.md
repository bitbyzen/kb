# Checking an Object's Origin for Mirroring

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

For a [Mirror modifier](apply-mirror-modifier.md) to work correctly, the object's origin — and the seam vertices along the cut edge — need to sit exactly on the mirror axis, usually `X = 0`.

## Check the Origin's Location Numerically

Press `N` to open the sidebar, then go to the **Item** tab. With the object selected in Object Mode, check its **Location** X/Y/Z values. If you're mirroring across X, you want `X = 0` — check Y or Z instead if that's your mirror axis.

## Check the Origin Visually

Switch to Front or Top Orthographic view (`Numpad 1` / `Numpad 7`), and enable X-Ray (`Alt+Z`) if needed. Look at where the object's orange origin dot sits relative to the center gridline running through the world origin.

## Snap the Origin to World Center

If Location isn't 0 and your model should be centered at world origin:

1. In Object Mode, press `Shift+C` (or `Shift+S` → **Cursor to World Origin**) to reset the 3D cursor to `(0, 0, 0)`.
2. Select the object, then **Object** → **Set Origin** → **Origin to 3D Cursor**.

This moves the origin to world center without moving the mesh itself.

> **Warning:** The origin needs to sit on the mirror plane, but that isn't necessarily world origin — it depends on where you want the mirror axis to be. If your model isn't centered at world origin, snapping the origin there would be wrong.

## Check the Seam Vertices Separately

Even with a correct origin, the seam edge itself can be off-axis. In Edit Mode, select the vertices along the cut or seam edge and check their location in the N-panel — they should all match your intended center value exactly, not just be close to it.
