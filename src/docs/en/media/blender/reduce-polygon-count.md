# Reducing the Polygon Count

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Several approaches convert a high-poly model into a low-poly one, depending on how much control you need over the result.

## Method 1: Decimate Modifier

The fastest, fully automated option. Click the **wrench** icon (**Modifier Properties**), then **Add Modifier** → **Generate** → **Decimate**. It has three modes:

| Mode | Best For |
|---|---|
| Collapse | Reduces the poly count by a ratio (for example, `0.5` = 50% fewer faces). Works uniformly across the whole mesh. |
| Un-Subdivide | Reverses even, regular subdivision cleanly. |
| Planar | Merges nearly flat, coplanar faces — good for hard-surface objects, less useful for organic shapes. |

> **Warning:** Decimate doesn't respect edge loops, so UVs, rig deformation, and topology flow can degrade — especially around areas like eyes and mouth that need clean loops for expressions.

## Method 2: Remesh Modifier

**Add Modifier** → **Generate** → **Remesh**, using **Voxel** mode, rebuilds the mesh at a target resolution. This is good for simplifying dense sculpts, but it replaces the existing topology and UVs entirely with a uniform grid.

## Method 3: Manual Retopology

Manually draw new, clean low-poly topology over the high-poly model, using tools like Poly Build, a Shrinkwrap modifier, or add-ons like RetopoFlow. This is the standard for game-ready or animation-ready characters, since it preserves proper edge loops for deformation — but it takes much more time than the other methods.

> **Note:** If the model already has a [Subdivision Surface modifier](apply-subdivision-surface-modifier.md), its lower-resolution base mesh may already serve as a low-poly cage — check the modifier stack before decimating. If you do need to reduce the base mesh and plan to animate facial expressions, enable **Symmetry** in Decimate to respect an existing [Mirror modifier](apply-mirror-modifier.md), rather than decimating blindly.
