# Installing YukkuriMovieMaker4

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

YukkuriMovieMaker4 (YMM4) is a free, portable video editing tool developed by 饅頭遣い, popular for creating Yukkuri commentary videos. It is not available on Steam — download it directly from the official site.

**Requirements:**

- Windows 10 or 11
- .NET Framework 4.7.2 or later
- DirectX 11 compatible GPU

## Step 1: Download

1. Go to the official site and download the app:

    [https://manjubox.net/ymm4/](https://manjubox.net/ymm4/)

2. Click one of the following:

    **"ゆっくりMovieMaker4をダウンロード"** — full version (recommended)

    **"Lite"** — lighter version with fewer features

## Step 2: Extract the ZIP

YMM4 is a portable app — there is no installer.

1. Locate the downloaded `.zip` file.
2. Right-click → **Extract All**.
3. Open the extracted folder.

> **Warning:** Do not run the app directly from inside the ZIP file. Always extract first.

## Step 3: Launch the App

Inside the extracted folder, double-click `YukkuriMovieMaker.exe`. No setup wizard is required.

> **Note:** Windows may show the message **"WindowsによってPCが保護されました"** (Windows protected your PC). Click **"詳細情報"** (More info) → **"実行"** (Run anyway) to proceed.

## Managing the App

The extracted folder is the application itself. Keep it in a permanent location.

| File | Action |
|------|--------|
| Downloaded `.zip` file | Safe to delete after extraction |
| Extracted folder (contains `.exe`) | Do not delete — this is the app |

Recommended storage locations:

- `Documents\YMM4`
- `C:\Tools\YMM4`

Create a desktop shortcut to `YukkuriMovieMaker.exe` for convenient access without moving the folder.
