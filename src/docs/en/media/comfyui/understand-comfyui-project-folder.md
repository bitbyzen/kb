# Understanding the ComfyUI Project Folder

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Comfy Desktop sets up ComfyUI's data directory automatically on first launch — by default somewhere like `C:\Users\<you>\Documents\ComfyUI`, or a path you chose during setup. ComfyUI then reads and writes to this folder every time you run a workflow.

## Folder Layout

| Folder | What It's For |
|---|---|
| `models/` | AI model files — checkpoints, LoRAs, VAEs, text encoders, upscale models, and more, each in its own subfolder |
| `output/` | Generated images, saved automatically after each run |
| `input/` | Images you want to use as workflow inputs |
| `custom_nodes/` | Extensions and plugins that add new node types |

> **Note:** Model subfolders match the node that loads them — for example, `models/checkpoints/` for a Load Checkpoint node, `models/upscale_models/` for a Load Upscale Model node, and `models/loras/` for a LoRA loader. See [Downloading the Anima Model](download-anima-model.md) and [Fixing a Missing Model in a Template](fix-missing-model-in-template.md) for examples of files going into specific model subfolders.
