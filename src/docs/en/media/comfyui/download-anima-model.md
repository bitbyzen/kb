# Downloading the Anima Model

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Unlike a standard SDXL checkpoint, Anima needs two extra component files to run — its own text encoder and VAE. This downloads all three files and places them in the right [ComfyUI project folders](understand-comfyui-project-folder.md). See [Understanding the Anima Model](understand-anima-model.md) for background on the model itself.

## Step 1: Open the Anima Page

Go to [Anima - Base-v1.0 on Civitai](https://civitai.com/models/2458426/anima). The model is also published on Hugging Face under the official CircleStone Labs repo.

## Step 2: Download the Main Checkpoint

Click **Download (3.89 GB)** to get the main model (`bf16 SafeTensor`).

## Step 3: Download the Required Components

Click **Download All Components (1.35 GB)** to get the two extra files Anima needs:

- `qwen_3_06b_base.safetensors` (1.11 GB) — the text encoder
- `qwen_image_vae.safetensors` (242 MB) — the VAE

> **Note:** Civitai renames the text encoder file on download — look for `anima_baseV10_txt.safetensors` instead of `qwen_3_06b_base.safetensors`. You can confirm it's the right file by its size (~1.11 GB).

## Step 4: Move the Files into Place

Move each downloaded file into its matching `models/` subfolder:

| File | Destination Folder |
|---|---|
| `anima_baseV10.safetensors` | `models/checkpoints/` |
| `anima_baseV10_txt.safetensors` | `models/text_encoders/` |
| `qwen_image_vae.safetensors` | `models/vae/` |

> **Note:** In Comfy Desktop, use **Help** → **Open Folder** → **Open Model Folder** to jump straight to the root `models/` directory.
