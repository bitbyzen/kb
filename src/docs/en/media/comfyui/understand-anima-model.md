# Understanding the Anima Model

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Anima is a text-to-image diffusion model released May 15, 2026, built specifically for anime, manga, and illustration-style art — unlike general-purpose models such as SDXL, which aren't tuned for any particular style.

## Why It Fits Anime and Manga Work

- Designed specifically for anime/manga art, rather than photorealism
- Supports both natural-language prompts and Danbooru-style tags, so either prompting style works
- A newer, lighter architecture (~2B parameters) than SDXL — runs comfortably on an 8 GB GPU such as an RTX 3070
- Natively supported in ComfyUI, with a ready-made template bundled in Comfy Desktop — see [Running Anima Locally with ComfyUI](run-anima-locally-with-comfyui.md)
- Higher prompt-following than SDXL, so detailed character descriptions tend to translate more consistently into the generated image

## Getting It

Anima needs its own checkpoint plus two extra component files it depends on (a text encoder and a VAE), unlike a standard SDXL setup. See [Downloading the Anima Model](download-anima-model.md) for where to get each file and which `models/` subfolder it goes in.
