# Upscaling an Image 4× in ComfyUI

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Make a small image bigger with an AI upscale model, using only ComfyUI's built-in nodes. This guide enlarges a 255 × 347 character image to 1020 × 1388.

> **Note:** Written using ComfyUI Desktop 0.39.2 (frontend v1.53.10, templates v0.11.78) on Windows 11 with an RTX 3070 (8 GB). Node names and menus can differ in other versions — check **Settings** → **About**.
>
> ![ComfyUI Settings, About page, showing ComfyUI 0.39.2, frontend v1.53.10, templates v0.11.78, an RTX 3070 with 8 GB VRAM](img/upscale-image-4x-in-comfyui-01.png)

## What This Does

A plain resize only changes the number of pixels, so the picture gets blurry. An **AI upscale model** also draws in detail that it guesses from what it learned. The result looks sharper, but the extra detail is a plausible guess, not information recovered from the original.

The workflow chains four nodes: **Load Image** → **Upscale Image (using Model)** → **Preview Image** → **Save Image**. A fifth node, **Load Upscale Model**, feeds the model into the upscale node.

| Item | Value Used Here |
|---|---|
| Model | `RealESRGAN_x4plus_anime_6B.pth` (17.1 MB, made for anime-style images) |
| Scale | Always 4× (fixed by the model) |
| Input | `ranza-01-004-03.png`, 255 × 347 |
| Output | 1020 × 1388 |

## Step 1: Download the Upscale Model

Download `RealESRGAN_x4plus_anime_6B.pth` from the Real-ESRGAN project's release page (see References). The file is about 17 MB.

![Browser download list showing RealESRGAN_x4plus_anime_6B.pth, 17.1 MB, Done](img/upscale-image-4x-in-comfyui-02.png)

## Step 2: Open the upscale_models Folder

In File Explorer, go to `Documents\ComfyUI\models\upscale_models`. It's empty at first.

![File Explorer at Documents, ComfyUI, models, upscale_models; the folder is empty](img/upscale-image-4x-in-comfyui-03.png)

## Step 3: Put the File in It

Move or copy the `.pth` file into this folder.

![File Explorer showing RealESRGAN_x4plus_anime_6B.pth, 17,519 KB, inside upscale_models](img/upscale-image-4x-in-comfyui-04.png)

## Step 4: Open a New, Empty Workflow

Click the **+** next to the workflow tabs. A new tab ("Unsaved Workflow (2)") opens with an empty canvas. Using a new tab keeps your other workflows untouched.

![The + button next to the workflow tabs is highlighted](img/upscale-image-4x-in-comfyui-05.png)

![A new empty tab named Unsaved Workflow (2)](img/upscale-image-4x-in-comfyui-06.png)

## Step 5: Add Load Image

Double-click the empty canvas, type `load image` in the search box, and pick **Load Image**.

![Node search box with Load Image highlighted in the list](img/upscale-image-4x-in-comfyui-07.png)

![A Load Image node on the canvas showing a sample image](img/upscale-image-4x-in-comfyui-08.png)

## Step 6: Add Load Upscale Model

Double-click an empty spot again, type `load ups`, and pick **Load Upscale Model** (not "Load Latent Upscale Model").

![Node search for 'load ups' with Load Upscale Model highlighted](img/upscale-image-4x-in-comfyui-09.png)

![A small Load Upscale Model node added to the canvas](img/upscale-image-4x-in-comfyui-10.png)

## Step 7: Add Upscale Image (using Model)

Search `upscale image`. Several nodes have similar names. Pick **Upscale Image (using Model)**, the one with a model input. The plain **Upscale Image** at the top of the list is an ordinary resize.

![Node search for 'upscale image' with Upscale Image (using Model) highlighted](img/upscale-image-4x-in-comfyui-11.png)

![Three nodes on the canvas: Load Image, Load Upscale Model and Upscale Image (using Model)](img/upscale-image-4x-in-comfyui-12.png)

## Step 8: Connect the Nodes

Drag from the `UPSCALE_MODEL` output of Load Upscale Model to the `upscale_model` input of Upscale Image (using Model). Then drag from the `IMAGE` output of Load Image to its `image` input.

![Load Upscale Model and Load Image both connected to Upscale Image (using Model); model_name reads undefined](img/upscale-image-4x-in-comfyui-13.png)

> **Note:** `model_name` still says `undefined` here — that's fixed in the next part.

## Step 9: Choose Your Image

In Load Image, click the arrows next to `image` to pick a file. Click **choose file to upload** to add one that isn't in the list.

![Load Image node showing ranza-01-004-03.png, size 255 by 347](img/upscale-image-4x-in-comfyui-14.png)

## Step 10: Refresh the Node Definitions

ComfyUI reads the model folders when it starts. A file you added while it was already open isn't in the list yet, so `model_name` shows `undefined`. Click an empty part of the canvas, then press `R`. A green message says **Node definitions updated**.

![Green 'Updated, Node definitions updated' message at the top right](img/upscale-image-4x-in-comfyui-15.png)

## Step 11: Pick the Model

Click the arrows on `model_name`. `RealESRGAN_x4plus_anime_6B.pth` now appears. Select it.

![The model_name list showing RealESRGAN_x4plus_anime_6B.pth](img/upscale-image-4x-in-comfyui-16.png)

![Load Upscale Model with RealESRGAN_x4plus_anime_6B selected](img/upscale-image-4x-in-comfyui-17.png)

> **Note:** Still undefined? Check that the file is directly inside `upscale_models` (not in a sub-folder) and that it ends in `.pth`. If the list is still empty, use the refresh icon at the top left of ComfyUI to reload the page.

## Step 12: Add Preview Image

Use **Preview Image** first — it shows the result without saving a file, so you can test freely. Double-click an empty spot, search `preview image`, and pick it.

![Node search with Preview Image highlighted at the top of the list](img/upscale-image-4x-in-comfyui-18.png)

![A Preview Image node on the canvas, not yet connected](img/upscale-image-4x-in-comfyui-19.png)

## Step 13: Connect Preview Image

Drag from the `IMAGE` output of Upscale Image (using Model) to the `images` input of Preview Image.

![Upscale Image (using Model) connected to the Preview Image node](img/upscale-image-4x-in-comfyui-20.png)

## Step 14: Run It

Click **Run**. The first run loads the model, which can take a few seconds.

![The Run button at the top right is highlighted](img/upscale-image-4x-in-comfyui-21.png)

## Step 15: Check the Size

The size is shown under each image. The source is **255 × 347** and the result is **1020 × 1388** — exactly four times larger in each direction.

![Source image 255 by 347 on the left and the Preview Image result 1020 by 1388 on the right](img/upscale-image-4x-in-comfyui-22.png)

## Step 16: Add Save Image

Preview Image doesn't keep a file. To keep the result, double-click an empty spot, search `save`, and pick **Save Image** (not "Save Image (Advanced)").

![Node search for 'save' with Save Image highlighted](img/upscale-image-4x-in-comfyui-23.png)

![A Save Image node on the canvas with filename_prefix ComfyUI](img/upscale-image-4x-in-comfyui-24.png)

## Step 17: Connect Save Image

Connect the upscaled image to `images` on Save Image. Dragging from the `images` output of Preview Image or from the `IMAGE` output of Upscale Image (using Model) both work the same way.

![Preview Image's images output connected to Save Image's images input](img/upscale-image-4x-in-comfyui-25.png)

## Step 18: Run Again

Click **Run**. When "Job completed" appears, the image has been saved. Save Image shows the same 1020 × 1388 picture.

![The Run button is highlighted](img/upscale-image-4x-in-comfyui-26.png)

![Job completed; Preview Image and Save Image both show 1020 by 1388](img/upscale-image-4x-in-comfyui-27.png)

## Step 19: Open ComfyUI's Output Folder

Save Image writes to `Documents\ComfyUI\output`. The new file is named `ComfyUI_00001_.png` (the prefix plus a counter).

![File Explorer at Documents, ComfyUI, output, with ComfyUI_00001_.png highlighted](img/upscale-image-4x-in-comfyui-28.png)

## Step 20: Open the File and Look Closely

The file is 1020 × 1388 and 665.7 KB. Zoom to 100% and look at the lines and the hair. An AI upscale usually makes outlines smoother and more even, but it also guesses, so compare with the original before you rely on it.

![The upscaled character image open in the Windows photo viewer, 1020 by 1388, PNG, 665.7 KB](img/upscale-image-4x-in-comfyui-29.png)

## Notes and Limits

> **Warning:** Typing a folder path into the search box in the right-hand panel does not change where Save Image writes. Files always go to ComfyUI's output folder. Move or copy the result to where you want it afterwards.

> **Note:** The model adds detail that wasn't in the small image. It's good at clean line art, but it can smooth away tiny marks or invent small shapes. For work that must match the original exactly, compare the two at 100% first.

| Problem | What to Do |
|---|---|
| `model_name` shows `undefined` | Click the empty canvas and press `R`. Check that the `.pth` file is in `Documents\ComfyUI\models\upscale_models`. |
| The result is only a bit larger, or blurry | You may have used the plain **Upscale Image** node. Use **Upscale Image (using Model)** with a model loaded. |
| Can't find the saved file | Look in `Documents\ComfyUI\output`. The name starts with the `filename_prefix`. |
