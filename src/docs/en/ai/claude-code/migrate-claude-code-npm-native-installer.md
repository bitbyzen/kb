# Migrating Claude Code from npm to Native Installer

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Symptom

When launching Claude Code in VS Code (WSL/Ubuntu), the following message appears in the terminal:

```
Claude Code has switched from npm to native installer.
Run `claude install` or see https://docs.anthropic.com/en/docs/claude-code/getting-started
X Auto-update failed · Try `claude doctor` or `npm i -g @anthropic-ai/claude-code`
```

## Cause

Anthropic released a native binary installer for Claude Code in October 2025, replacing the previous npm-based installation. The old npm version detects this and prompts you to migrate. The native installer is simpler, more stable, and does not require Node.js.

## Fix

### Step 1: Run the Migration Command

In your terminal (any directory is fine):

```bash
claude install
```

Expected output:

```
✓ Claude Code successfully installed!

  Version: 2.1.x
  Location: ~/.local/bin/claude

  Next: Run `claude --help` to get started

⚠ Setup notes:
  • Native installation exists but ~/.local/bin is not in your PATH. Run:

  echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc
```

### Step 2: Add `~/.local/bin` to Your PATH

If the setup notes warn that `~/.local/bin` is not in your PATH, run:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc
```

### Step 3: Verify the Installation

```bash
which claude
```

Expected output:

```
/home/<username>/.local/bin/claude
```

If this is correct, the migration is complete.

### Step 4: Restart VS Code

Restart VS Code to ensure all terminals and extensions pick up the new PATH. The warning message should no longer appear.

## Troubleshooting

### `which claude` Still Points to an asdf or nvm Shim

If you use a Node.js version manager like `asdf` or `nvm`, its shim may still take priority. Uninstall the old npm package from your Node.js versions:

```bash
# For asdf
for version in $(asdf list nodejs | tr -d ' *'); do
  echo "Uninstalling from nodejs $version..."
  ASDF_NODEJS_VERSION=$version npm uninstall -g @anthropic-ai/claude-code 2>/dev/null
done

# For nvm
nvm use <version> && npm uninstall -g @anthropic-ai/claude-code
```

Then confirm again:

```bash
which claude
# Should now show: /home/<username>/.local/bin/claude
```

### General Health Check

```bash
claude doctor
```

This command reports any issues with your installation, such as missing binaries or PATH problems.
