# Understanding Cowork and Dispatch

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Claude can operate apps on your computer (browser, spreadsheets, email) to complete tasks while you focus on other things.

---

## Key Features

- **Dispatch** — Assign tasks from your phone; Claude runs them on your desktop
- **Scheduled tasks** — Set recurring tasks (e.g. daily inbox scan, weekly reports)
- **Persistent context** — Claude remembers previous work so tasks pick up where they left off
- **No configuration needed** — Claude uses connected apps first, then browser or screen

---

## How to Get Started

1. Leave your desktop awake
2. Open Dispatch in Claude Desktop
3. Pair with the mobile app
4. Hand off your first task from anywhere

---

## Limitations

- These are **research previews** — complex tasks may need more than one attempt
- Available on **Pro and Max plans** only
- **Computer use is limited to macOS** — Windows users can use Dispatch but cannot use the full computer control feature yet

> **Note:** Windows users can use Dispatch, but the "Claude operates your screen" feature is not yet available. No release date has been announced.
