# Managing Your Claude.ai Memory

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

A practical guide to viewing, editing, and controlling what Claude remembers about you.

---

## What Is Claude's Memory?

Claude.ai has two memory mechanisms:

- **Auto-generated memory** — Claude analyzes your conversation history roughly every 24 hours and synthesizes key context (your job, preferences, projects, etc.) into a memory profile.
- **User-directed edits** — Things you explicitly tell Claude to remember or forget. These are stored as discrete entries (up to 30 slots, ~100 characters each).

> **Note:** Memory is scoped separately for regular chats vs. Projects. Information from inside a Project only applies to that Project.

---

## Enabling Memory

1. Go to **Settings → Capabilities**
2. Toggle on **"Generate memory from chat history"**
   - This is the core switch — Claude won't build a memory profile without it.
3. Optionally enable **"Search and reference chats"**
   - This allows Claude to search back through past conversations for relevant details. Useful, but not required for basic memory.

---

## Viewing Your Memory

Once Claude has accumulated enough context:

1. Go to **Settings → Capabilities**
2. Click **"View and edit memory"** in the Memory section
3. The **Manage Memory** modal shows everything Claude currently remembers about you

You can also ask Claude directly in any chat:

```
What do you remember about me?
```

---

## Adding to Memory

**Option A — Tell Claude in chat:**
```
Please remember that I work as a Python programmer.
Remember that I prefer dark mode in all tools.
```

**Option B — Via the memory modal:**
1. Open **Settings → Capabilities → View and edit memory**
2. Click the **pencil icon** in the lower-left corner of the summary
3. Type the information you want added

Any edits made this way apply immediately to your next conversation.

---

## Editing Existing Memory

**To update a specific fact:**
```
Update your memory — I no longer work at Acme Corp, I now work at Example Inc.
```

**To correct something:**
```
You have my job title wrong. I'm a senior engineer, not a junior engineer.
```

Claude will use the memory tool to update the entry in place.

---

## Deleting / Forgetting Memory

**To remove a specific item:**
```
Please forget that I mentioned my old company.
Forget about my preference for tabs over spaces.
```

**To clear everything:**
1. Go to **Settings → Capabilities**
2. Click **"Reset memory"**
3. Confirm

> **Warning:** Resetting memory permanently deletes all memories and cannot be undone.

---

## Pausing Memory (Without Deleting)

If you want Claude to stop learning new things without wiping existing memory:

1. Go to **Settings → Capabilities**
2. Select **"Pause memory"**

Claude will retain its current memory but won't add new entries or reference it until you re-enable it.

---

## Using Incognito Mode

For conversations you don't want to influence your memory profile at all:

- Click the **ghost icon** in the top-right corner of a new chat to enable Incognito mode
- Incognito chats are **never** added to memory, regardless of your settings

---

## Tips for Getting the Most Out of Memory

| Do | Avoid |
|---|---|
| Reserve explicit edits for stable, permanent facts | Burning edit slots on temporary context |
| Use Project knowledge bases for project-specific info | Relying on memory across different Projects |
| Periodically review and prune outdated entries | Letting old/irrelevant facts accumulate |
| Use Incognito for sensitive or one-off conversations | Sharing sensitive info in regular chats |

---

## Importing Memory from Other AI Providers

If you use ChatGPT, Gemini, or another AI tool:

1. Go to **Settings → Capabilities**
2. Click **"Start Import"** under *Import memory from other AI providers*
3. Claude will generate a prompt you can use to export your context from the other service, then import it

> **Note:** This feature is experimental and still in active development.
