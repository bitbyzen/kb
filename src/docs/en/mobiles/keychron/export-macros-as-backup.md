# Exporting Macros as Backup

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Export your macros as a backup file from Keychron Launcher.

---

## Steps

1. Launch **Keychron Launcher** in your browser.
2. Select your keyboard and connect.
3. Select **Macro** in the left sidebar.
4. At the bottom of the **Macro** pane, locate the **Flash** progress bar.
5. Click the **Export** button (↓ downward arrow icon) to the right of the **Flash** field.
6. Save the exported file to your computer.

---

> **Tip:** Export your macros before flashing new firmware or making major changes, so you can restore them if needed.
