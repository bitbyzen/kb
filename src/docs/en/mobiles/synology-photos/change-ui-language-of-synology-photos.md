# Changing the UI Language of Synology Photos

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The Synology Photos app does not have a built-in language setting. The display language follows the system language of your Android device.

To display the app in English, change the system language of your phone:

1. Open **Settings** (gear icon) on your phone.
2. Tap **System** → **Language**.
3. Tap **System language**.
4. Drag **English** to the top of the list to make it the primary language.

> **Warning:** Changing the system language affects all apps on your phone. If you are based in Japan, this may cause inconvenience with Japanese banking apps, notifications, and map apps. Synology Photos does not support Android's per-app language setting, so there is no way to change its language independently.
