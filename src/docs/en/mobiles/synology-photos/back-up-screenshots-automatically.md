# Back Up Screenshots Automatically with Synology Photos

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

> **Note:** This procedure is based on Pixel 8a (Android).

1. Open the **Synology Photos** app on your phone.
2. Tap the **More** tab at the bottom of the screen.
3. Tap the area showing **"Image backup complete"** (or the current backup status).
4. Tap the **gear icon (Settings)** in the top right.
5. Tap **Backup source**.
6. Select **Customize**.
7. In the folder list, check **Screenshots**.
8. Tap **Done** in the top right.

> **Note:** Selecting **Back up all folders** will send unwanted images — such as LINE saved images and app cache — to your NAS. Use **Customize** to limit backup to only the folders you need.
