# Understanding Simplenote

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Simplenote is a Markdown-compatible note app that works on Windows, Android, and the web. You can import and export notes, and publish individual notes publicly.

> **Note:** According to ChatGPT, you can only publish one note at a time, and notes cannot contain images.

## Overview

- Simple text note app
- Markdown support
- Multi-device sync (mobile, PC, web)

## Features

- Fast and lightweight
- Automatic sync (sign in to sync)
- Version history (restore previous states)
- Tag-based organisation
- Collaborative editing (shareable)

## Publishing and Sharing

- Generate a URL with **Publish**
- Only people with the link can view the note
- Read-only (cannot be edited by viewers)

> **Note:** Not suited for blog-style publishing — there is no index or structure.

## Pros

- Completely free
- Almost no ads
- Lightweight and fast
- Near-zero learning curve

## Cons

- No image or file attachments
- Limited features
- No folder structure (tags only)
- No design or customisation options

## Best Use Cases

- Personal notes
- Draft ideas
- Temporary sharing (e.g. meeting minutes)
- Lightweight Markdown notes

## Poor Use Cases

- Blog publishing
- Documentation sites (use MkDocs instead)
- Image-heavy notes
- Advanced note management
