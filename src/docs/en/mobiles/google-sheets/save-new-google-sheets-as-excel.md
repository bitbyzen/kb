# Saving New Google Sheets as Excel

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

To bypass Google Sheets' native format and save all new spreadsheets as Excel (`.xlsx`) from the start, enable the **Create Excel files** setting.

1. Open the Google Sheets app and tap the hamburger menu (**☰**) in the top-left corner.
2. Tap **Settings**.
3. Toggle on **Create Excel files**.

Any new spreadsheet you create will automatically use the `.xlsx` format, and downloads will remain in Excel.
