# Access Flashcard Deluxe Local Exports on Google Pixel

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

On modern Android versions, the operating system restricts access to the `/Android/data/` folder for security. Because Flashcard Deluxe exports to its own private directory, the files will **not** appear in the standard **Files by Google** app.

To find your files, you must use the hidden **system "Files" tool** instead of the standard app.

---

## ⚠️ Important: "Files" vs. "Files by Google"

While the icons look similar, they have different permission levels:

* **Files by Google (Colorful icon):** **Cannot** access the `/Android/data/` folder. Use this for general cleanup only.
* **Files (Blue folder icon):** The **only** native way to access restricted app data folders on your Pixel.

---

## The Storage Path

Flashcard Deluxe saves local exports to:  
`Internal Storage` → `Android` → `data` → `com.orangeorapple.flashcards` → `files` → `Import Export`

---

## Step-by-Step Guide

1. **Open Settings**: Navigate to **Settings** → **Storage**.
2. **Access the System Tool**: Tap on **Files**.
3. **Choose the Right App**: When the "Open with" prompt appears, select **Files** (the blue folder icon).
    * **Note:** If you select *Files by Google* here, the specific export folder will appear empty or hidden.
4. **Navigate to the Path**:
    * Tap the **Menu (≡)** and select your **Pixel** (Internal Storage).
    * Navigate to: `Android` → `data` → `com.orangeorapple.flashcards` → `files` → `Import Export`.
5. **Bypass Permissions**: If you see a message saying "The contents of this folder can't be displayed here," tap the **View in Files** button at the bottom of the screen.
6. **Move the File**: Once you locate your deck, long-press it and select **"Copy to..."** to move it to a visible folder like **Downloads** for easier use.

---

## 💡 Quick Tips

* **Show Internal Storage**: If your Pixel doesn't appear in the sidebar, tap the **three-dot menu (⋮)** in the top right and select **Show internal storage**.
* **Streamline Exports**: To avoid this process in the future, use the **Email** export option within the Flashcard Deluxe app to send the deck directly to yourself.
