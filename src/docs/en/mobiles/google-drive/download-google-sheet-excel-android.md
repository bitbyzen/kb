# Downloading a Google Sheet as Excel on Android

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The Google Sheets app for Android does not offer a setting to change the default download format. Tapping **Download** from the home screen exports the file as a PDF.

To get an Excel (`.xlsx`) file on your phone, open the spreadsheet first and use the **Save As** route.

## Use Save As Inside the Sheet

1. Open the spreadsheet in the Google Sheets app.
2. Tap the three-dot menu (**⋮**) in the top-right corner.
3. Select **Share & export**.
4. Tap **Save as**.
5. Choose **Excel (.xlsx)** and tap **OK**.

A new `.xlsx` version of the file appears on your Google Sheets home screen.

> **Note:** Once the Excel version exists on the home screen, tap the three-dot menu (**⋮**) next to it and select **Download**. It downloads directly as an Excel file to your phone's local storage.
