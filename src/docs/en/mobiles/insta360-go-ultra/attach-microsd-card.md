# Attach a microSD Card

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

1. Detach the standalone camera from the action pod.

    > **Note:** The microSD card slot is on the left side of the standalone camera.

2. Slide up the slot cover firmly.

    > **Note:** The cover is very tight. The button-like object at the center is not a button — do not press it. Wearing rubber gloves helps grip the cover.
