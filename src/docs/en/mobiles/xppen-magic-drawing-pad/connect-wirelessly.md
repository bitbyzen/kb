# Connecting Wirelessly

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Two apps let you use the Magic Drawing Pad as a wireless screen for Windows over Wi-Fi: **SpaceDesk**, which adds the tablet as an extra monitor, and **Sunshine and Moonlight**, which streams your existing desktop to the tablet as a video feed. Both your PC and the Magic Drawing Pad must be on the same Wi-Fi network.

## Method 1: SpaceDesk (Extra Monitor)

SpaceDesk is a free, unofficial third-party app that turns the Magic Drawing Pad into a wireless pen display for Windows. The tablet appears as an additional monitor, and the stylus works as a pen input device.

### Set Up SpaceDesk

#### On Windows

1. Go to [spacedesk.net/download/](https://www.spacedesk.net/download/).
2. Download the SpaceDesk Driver for Windows.
3. Run the installer and follow the prompts.
4. Open the SpaceDesk Driver Console and confirm the driver is on.

#### On the Magic Drawing Pad

1. Open the Google Play Store.
2. Search for **SpaceDesk**.
3. Install the **SpaceDesk VIEWER** app.

### How It Works

| State | Effect on Windows |
|-------|-------------------|
| SpaceDesk Viewer connected | Tablet appears as an extra monitor |
| Viewer disconnected or closed | Extra monitor disappears from Windows |
| Driver turned off | No new connections can be established |

### Connect

1. Open the SpaceDesk Driver Console on Windows and turn the driver on.
2. Open the SpaceDesk Viewer app on the Magic Drawing Pad.
3. Tap your PC in the list.

Windows adds the tablet as an extra monitor.

### Disconnect

1. Swipe away the SpaceDesk Viewer app on the Magic Drawing Pad, or disconnect from inside the app.
2. Open the SpaceDesk Driver Console on Windows and turn the driver off.

The session has ended when Windows Display Settings no longer shows the tablet as a monitor.

> **Note:** If Windows gets confused about monitor arrangement after reconnecting, open **Display Settings** and drag the monitors back into the correct positions. Windows sometimes places a reconnected monitor in an unexpected location.

## Method 2: Sunshine and Moonlight (Screen Mirroring)

**Sunshine** (host, on your PC) and **Moonlight** (client, on the Magic Drawing Pad) stream your Windows desktop using your GPU's hardware encoder for low latency. Unlike SpaceDesk, the tablet does not appear as a new Windows monitor — it shows a mirrored, remote view of your existing desktop instead.

For the full installation, pairing, and streaming steps, see [Streaming a Windows PC to an Android Tablet with Sunshine and Moonlight](../sunshine/set-up-sunshine-and-moonlight.md).

> **Note:** Pen pressure through this method has not been verified for apps like Blender. See that guide's Known Limitations section for details.
