# Prevent Finger False Touch

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The Magic Drawing Pad supports both hand touch and pen touch. By default, the system gives priority to pen touch: when the stylus is detected, finger input is ignored.

There are two additional ways to prevent accidental finger touches while drawing.

## Method 1: Use the Included Glove

The package includes a glove designed for use while painting. Wearing it on your drawing hand prevents accidental finger touches.

## Method 2: Disable Handwriting Touch

Disabling handwriting touch lets you draw with the stylus without any risk of finger input being registered. There are two ways to toggle this setting:

- **Shortcut menu:** Pull down the shortcut menu from the top of the screen and tap the **Handwriting Touch** switch.
- **Settings:** Go to **Settings** → **Advanced Features** → **Handwriting Touch** and toggle it off.
