# Connecting by Cable

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The Magic Drawing Pad supports DisplayPort Alt Mode over its USB-C port, so it can act as a wired pen display with no app or Wi-Fi required.

> **Note:** Your PC needs a USB-C port that supports **DisplayPort output (DP Alt Mode)** — not every USB-C port does.

1. Connect the Magic Drawing Pad to your PC using the provided cable.
2. Press the **DP-IN** button shown on the tablet's screen.

The tablet switches to display the PC's output directly, with no separate viewer app needed.

> **Note:** See [this video](https://youtu.be/CS0R2QcA5Q0?si=ph7jzkcQChQcxl0h&t=616) for a demonstration of the wired setup.
