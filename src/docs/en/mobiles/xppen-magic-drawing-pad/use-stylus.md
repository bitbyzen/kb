# Using the Stylus

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

The included stylus is a passive pressure-sensing pen. It does not require a power supply or Bluetooth pairing — pick it up and start drawing.

## Pen Button

The stylus has a button on the pen body that works with supported drawing apps. It is currently compatible with **ibis Paint X** (more apps will be supported in the future).

## Set Up the Pen Button for ibis Paint X

> **Note:** ibis Paint X must be version V11.1.1 or later.

1. Open ibis Paint X, go to **Settings** → **Supported Stylus**, and select **X3 Pro Pencil**.
2. Go to **Settings** → **Stylus Settings** → **Button 1**, then select the function you want (for example, **brush/eraser**).
