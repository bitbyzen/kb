# Comparing Pen Display Apps for the Magic Drawing Pad

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Several apps let you use the Magic Drawing Pad as a wireless pen display on Windows 11. They fall into two categories: display extension apps and remote desktop apps. For Blender's pressure-sensitive tools, only SpaceDesk, SuperDisplay, and Duet Display are practical on Windows — Weylus's pressure and tilt support is Linux-only, and remote desktop apps generally do not pass pressure through either.

## Display Extension Apps

These apps add the tablet as an extra Windows monitor. The stylus works as pen input on that display.

| App | Price | Strength | Limitation |
|-----|-------|----------|------------|
| SpaceDesk | Free | Broad device support | Pen experience varies; may need tweaking |
| SuperDisplay | Paid | Polished pen experience for artists | Focused on drawing; less general-purpose |
| Duet Display | Paid | Reliable, low latency | Subscription-based |
| Weylus | Free & open source | No account required; works through any browser | Pressure and tilt require a Linux host — on Windows 11 it only provides pointer and touch, not usable for Blender's pressure-sensitive tools |

## Remote Desktop Apps

These apps stream the entire Windows desktop to the tablet as a video feed. The tablet does not appear as a second monitor in Windows — it shows a mirrored or remote view of the existing display.

| App | Pen Pressure for Blender |
|-----|---------------------------|
| Chrome Remote Desktop | Not supported — stylus input is treated as mouse clicks |
| Microsoft Remote Desktop | Not supported — same limitation; designed for remote access, not display extension |
| Sunshine + Moonlight | Not yet verified — low-latency, GPU-encoded game streaming, but pressure passthrough for apps like Blender has not been confirmed |

Blender relies on pressure-sensitive stylus input for sculpting and texture painting. Chrome Remote Desktop and Microsoft Remote Desktop do not pass stylus pressure data through, making them unsuitable for this workflow. Sunshine and Moonlight are architecturally similar but untested for pressure support — see [Connecting Wirelessly](connect-wirelessly.md) for setup steps if you want to try it.

## Set Up Weylus

> **Note:** Weylus's pressure and tilt support requires a Linux host. On Windows 11, Weylus only provides pointer and touch control — it will not give you pressure-sensitive input in Blender.

1. Download Weylus for Windows from GitHub.
2. Install the Weylus virtual input driver: the setup wizard guides you through installing vJoy, which lets Weylus send pointer and touch input to Windows.
3. Run Weylus on your PC. It displays a local URL such as `192.168.x.x:8001` and a QR code.
4. Open a web browser on your tablet, enter the URL, and your PC screen appears.
5. In the Weylus browser interface on your tablet, check **Capture Stylus** to use the stylus as a pointer. The **Pressure Sensitivity** option has no effect on Windows.

## Why SpaceDesk

SpaceDesk works well when:

- You already have a large Android drawing tablet and want to use it without extra cost.
- Your PC and tablet are on the same local network.
- You need an extra monitor with pen input for Blender rather than a dedicated drawing workspace.
- The use case does not require a professional or portable studio setup.

For Blender work in particular, having the tablet as an additional display with stylus input is enough for most workflows. SpaceDesk provides this at no cost.
