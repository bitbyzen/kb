# Create an Album in LINE

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

LINE's album feature lets everyone in a talk save and share photos together.

## Steps

1. Open the talk (friend or group) where you want to create an album.
2. Tap the menu icon (≡) in the top right.
3. Tap **Album**.
4. Tap **+** in the bottom right.
5. Select the photos you want to save.
6. Tap **Next**.
7. Enter an album name and tap **Create**.

## Tips

- Long-press a photo in a talk and select **Album** to add it directly.
- You can add more photos to an album after it is created.
- All group members can view and contribute to the album.

## Limitations

- Albums are not available in multi-person talks. Create an official group first.
- Video saving may be restricted depending on the feature used.
