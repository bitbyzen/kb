# Blocking and Deleting a Friend on LINE

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Block a Friend

1. Open the chat screen with the person.
2. Tap the menu icon (≡) in the top right.
3. Select **Block**.

## Delete a Friend

1. Go to the Home screen and open your Friends list.
2. Long-press on the account you want to delete.
3. Select **Delete**.

## Recommended: Do Both Together

If you only block someone, they remain in your Friends list. To remove them completely, do both in this order:

1. Block first.
2. Then delete.

> **Note:** Neither blocking nor deleting sends a notification to the other person.
