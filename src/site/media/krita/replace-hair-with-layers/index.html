    Replacing Hair with Layers

    Note: This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

    Copy the hair from one image onto a character in another, hide the parts you don't want with a transparency mask, and fill the gaps with mirrored copies of the face. This is a rough first try, made to see what Krita layers can do — not a finished technique.

    Note: Written using Krita 5.3.4.1 on Windows 11.

    What You Need

    Two images, both open in Krita. The goal isn't a perfect result but to find out what layers can do.

    Item Used Here
    Character ranza-01-004-01.png, canvas 629 × 750, black hair, tan skin
    New hair blonde-hair-01.png, a different character with blonde hair
    Result A layered Krita file, ranza-01-004-01-blonde.kra

    The rough flow is: save a copy → paste the hair layer → fit it → mask it → erase the old hair → mirror a copy to fill in what's missing → check.

    Note: A layer can cover the old hair, and a transparency mask can hide part of a layer without deleting it. But the skin under the character's bangs was never drawn, so a layer can't create it. In this guide the missing eye and ear are filled by copying and mirroring the other side of the face.

    Save a Working Copy

    Step 1: Use Save As with a New Name

    Open ranza-01-004-01.png, then choose File → Save As…. Saving a new .kra file keeps the original PNG untouched.

    Step 2: Name the File

    Type a new file name (here ranza-01-004-01-blonde), keep the type as Krita (.kra), and click Save.

    Bring in the New Hair

    Step 3: Open the Hair Image

    Choose File → Open… and pick blonde-hair-01.png.

    Step 4: Copy It

    The image opens in a second tab. Click that tab, press Ctrl+A to select everything, then Ctrl+C to copy.

    Step 5: Paste It into the Ranza File

    Switch back to the Ranza tab and press Ctrl+V. The picture arrives as a new layer above the Ranza layer, small and in the top-left corner. The new layer is called Background because that was the layer name in the hair file.

    Fit the Hair to the Head

    Step 6: Scale and Move It with the Transform Tool

    Select the Transform tool (Ctrl+T) with the new layer selected. Drag a corner handle to resize it, hold Shift to keep the proportions, and drag inside the box to move it. Press Enter to apply.

    Step 7: Lower the Opacity to See Through It

    To line the hair up with the head, make the layer see-through. Right-click the layer in the Layers docker and choose Properties…, then set Opacity to about 60%.

    Step 8: Adjust, Then Set the Opacity Back to 100%

    With the layer see-through, use the Transform tool again to line up the hair with the head. When it fits, open Properties… again and set Opacity back to 100%.

    Hide the Parts You Don't Want

    Step 9: Add a Transparency Mask

    The pasted image also has the blonde face, neck, and shirt. A transparency mask hides them without deleting anything. With the blonde layer selected, click the + drop-down at the bottom left of the Layers docker and choose Add Transparency Mask.

    Step 10: Paint Black on the Mask

    With the mask selected, pick the Brush tool and set the colour to black. Black on the mask hides the layer; white brings it back. Paint over the blonde face, neck, and shirt so that Ranza shows through.

    Now only the hair is left on top — but Ranza's own black hair still shows at one eye, where the blonde hair doesn't cover it.

    Remove the Old Hair

    Step 11: Erase Ranza's Black Hair

    Select the Ranza layer. Use the Brush tool in eraser mode (the eraser button in the top toolbar) and rub out the black hair that still shows.

    Step 12: Add a White Layer at the Bottom

    So that erased areas show white instead of transparency, add a new paint layer (Layer → New → Add Paint Layer), fill it with white using the Fill tool, and rename it background-white. Move it to the bottom of the layer list.

    Step 13: Look at the Result

    The black hair is gone and the blonde hair sits on the head. One eye is now a white patch — nothing was ever drawn under the bangs.

    Fill the Missing Eye with a Mirrored Copy

    Step 14: Select the Visible Eye

    Hide the blonde layer (click its eye icon) so you can see the face. Select the Ranza layer, then use a selection tool to draw around the visible eye. A tight selection copies less skin.

    Step 15: Copy It into a New Layer

    Copy the selection into a new layer. Afterward, the Layers docker shows a second layer with the Ranza name.

    Step 16: Erase More Hair Where the Copy Will Go

    Switch to the Brush tool in eraser mode, select the lower Ranza layer (the original), and erase the black hair around the missing eye, so the copy has a clear area to sit in.

    Step 17: Mirror the Copy

    Select the copy layer, then choose Layer → Transform → Mirror Layers Horizontally. The eye jumps to the other side of the face. The Krita manual says this mirrors around the centre of the whole image, which is why it lands close to the right place on a centred face.

    Step 18: Move It into Place

    Use the Transform tool to drag the copy so it lines up with the eyebrow and face, then press Enter.

    Step 19: Compare

    Hide the eye-only layer (click its eye icon) to compare. The eye fits, but the ear and the edge of the face beside it are also missing — a bigger copy fixes that next.

    Use a Bigger Copy: Eye and Ear

    Step 20: Select the Whole Side of the Face

    Select the lower Ranza layer. Draw a selection around the whole visible side of the face: eye, brow, and ear.

    Step 21: Copy It into a New Layer

    Copy the selection into a new layer, as before. The Layers docker now has the new copy on top of the Ranza layers.

    Step 22: Mirror and Move It

    With the copy selected, use Layer → Transform → Mirror Layers Horizontally again, then the Transform tool to place it.

    Step 23: Look at the Result

    Both eyes and both ears are drawn now. A small white patch is left on the forehead, which the blonde bangs cover.

    Check and Finish

    Step 24: Check the Face Without the Hair

    With the blonde layer still hidden, zoom out and check the whole face.

    Step 25: Show the Hair Again and Tidy the Mask

    Turn the blonde layer back on and select Transparency Mask 1. Choose black and paint on the mask wherever the blonde layer still covers the face or leaves stray marks. Paint white to bring a hidden part back.

    Step 26: The Result

    Blonde hair on Ranza, both eyes and both ears drawn. Rough, but it shows what layers, a mask, and a mirrored copy can do.

    Notes and Limits

    Note: See Changing Hair Color, Cutting Out Hair, and Closing the Hair Line with a Curve for further work continuing on this same file.

    Note: The transparency mask hid the unwanted parts without deleting them, so every change could still be undone. A mirrored copy filled in an eye and an ear that were never drawn.

    Warning: The final image has a few faint pale marks on the left edge of the jaw and along the neckline, and a few loose pale strands around the blonde hair. The hair also comes from a different image, so its line weight and head angle don't fully match. This was a first try, not a finished piece.

    Note: All the work was done in a new .kra file. The original PNGs weren't changed.

    Problem What to Do
    The pasted layer is small and in the corner Select the Transform tool, drag a corner handle (hold Shift to keep the proportions), and move it.
    A part of the hair got hidden by mistake Select the transparency mask and paint white over that area.
    Erased areas show a checkerboard Add a paint layer at the bottom and fill it with white.
    The mirrored copy lands in the wrong place Mirror Layers Horizontally flips around the centre of the whole image. Move the copy afterwards with the Transform tool.
