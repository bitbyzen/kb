# Inno Setup Overview

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Inno Setup is a free, open-source installer creation tool for Windows, originally developed by Jordan Russell. It packages an application — including all its files, dependencies, and settings — into a single `.exe` installer that end users can run to install the software.

## Key Features

- **Script-based configuration** — Installers are defined using `.iss` script files (Pascal-based syntax), giving fine-grained control over the installation process.
- **Single-file output** — Produces a compact, self-contained `.exe` installer.
- **Customizable UI** — The installation wizard's appearance, steps, and dialogs can be customized.
- **Registry and shortcut support** — Can write to the Windows Registry, create Start Menu shortcuts, and set environment variables.
- **Uninstaller generation** — Automatically generates an uninstaller.
- **Unicode support** — Supports multilingual installers.
- **Free to use** — No cost, even for commercial projects.

## Use with PyInstaller

A common workflow for distributing Python desktop apps to Windows users is:

1. Use **PyInstaller** to convert a Python script into a standalone `.exe` with all its dependencies.
2. Use **Inno Setup** to package the PyInstaller output folder into a polished Windows installer with install/uninstall support.

See [Create an Installer for a Python App](../../python/operations/create-installer.md) for the full workflow.
