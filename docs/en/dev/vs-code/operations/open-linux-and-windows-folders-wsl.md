# Open Linux and Windows Folders in VS Code (WSL)

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

When using VS Code with WSL (Windows Subsystem for Linux), you can open both Linux folders and Windows folders in the same workspace.

## Opening a Linux Folder

Linux folders live under your home directory (`~/`) inside WSL. To open one:

1. Go to **File → Open Folder...**
2. Navigate to your folder (e.g., `~/projects/myproject`)
3. Click **OK**

The title bar will show `[WSL: Ubuntu]`, confirming you are in the Linux environment.

## Opening a Windows Folder

Windows drives are mounted under `/mnt/` inside WSL:

| Windows Path | WSL Path  |
|--------------|-----------|
| `C:\`        | `/mnt/c/` |
| `D:\`        | `/mnt/d/` |
| `E:\`        | `/mnt/e/` |

To open a Windows folder, use the WSL path format. For example:

- Windows: `D:\projects\my-project`
- WSL path: `/mnt/d/projects/my-project`

## Opening Multiple Folders with a Workspace

You can open both a Linux folder and a Windows folder at the same time using a **Multi-root Workspace**.

### Setting Up a Workspace

1. Open your main folder in VS Code.
2. Go to **File → Save Workspace As...**
3. Enter a name (e.g., `myworkspace.code-workspace`) and click **OK**.
4. Go to **File → Add Folder to Workspace...**
5. Enter the path of the second folder (Linux or Windows) and click **Add**.

Both folders will appear as separate roots in the Explorer sidebar.

### Reopening a Workspace

Double-click the `.code-workspace` file in your file explorer, or use **File → Open Workspace from File...** inside VS Code.

## Previewing Markdown Files

VS Code has a built-in Markdown preview. After opening or editing a `.md` file:

- Press `Ctrl+Shift+V` to open the preview in a new tab.
- Press `Ctrl+K V` to open the preview side by side.

## Notes

- Accessing Windows files (`/mnt/d/...`) from WSL works fine for reading and editing, but can be slightly slower than working with files inside WSL (`~/...`).
- For simple file types like Markdown, the performance difference is not noticeable.
- Claude Code can access both Linux and Windows paths and can edit files in either location.
