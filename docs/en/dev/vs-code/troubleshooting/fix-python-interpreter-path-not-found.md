# Fix Python Interpreter Path Not Found in VS Code

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

When VS Code shows a warning about `python.defaultInterpreterPath` pointing to a path that no longer exists, the Python interpreter VS Code was previously configured to use has been deleted or moved.

Common causes:

- You deleted a virtual environment folder.
- You uninstalled or moved a Python installation.
- The project was opened on a different machine with a different folder structure.

---

## Fix: Select a New Interpreter

1. Open the Command Palette:

      - **Windows/Linux:** `Ctrl+Shift+P`
      - **Mac:** `Cmd+Shift+P`

      If the shortcut doesn't work, go to **Help → Show All Commands** in the menu bar.

2. Type **`Python: Select Interpreter`** and press Enter.

3. Select the interpreter you want to use from the dropdown. VS Code marks the recommended one with a **Recommended** label.

| Label | What It Means |
|---|---|
| Recommended | System Python installed from python.org |
| Conda | Python from an Anaconda/Miniconda environment |
| (path shown) | A specific virtual environment |

VS Code updates the setting automatically and the warning disappears.

---

## Understanding the Setting

`python.defaultInterpreterPath` stores the file path to a `python.exe` (Windows) or `python` (Mac/Linux) executable. VS Code uses this interpreter for:

- Running scripts
- IntelliSense and code completion
- Linting and formatting
- The integrated terminal

### Default Installation Paths

| Source | Typical Path |
|---|---|
| python.org (Windows) | `~\AppData\Local\Programs\Python\Python3xx\python.exe` |
| python.org (Mac) | `/usr/local/bin/python3` |
| Miniconda/Anaconda | `C:\ProgramData\miniconda3\python.exe` |
| Virtual environment | `<project_folder>\venv\Scripts\python.exe` (Windows) |

---

## Edit the Setting Manually (Alternative)

If the Command Palette approach does not work, edit the setting directly.

### Method 1: Edit in Settings UI

1. Go to **File → Preferences → Settings** (or `Ctrl+,`).
2. Search for `python.defaultInterpreterPath`.
3. Clear the existing invalid path and enter the correct one, or leave it blank to let VS Code auto-detect.

### Method 2: Edit settings.json

1. Open the Command Palette → **Open User Settings (JSON)**.
2. Find the line:
   ```json
   "python.defaultInterpreterPath": "D:\\old\\path\\to\\python.exe"
   ```
3. Update or delete it.

---

## Tips

- If you are using a virtual environment, activate or recreate it before selecting it as the interpreter.
- `python.defaultInterpreterPath` is a fallback — once you select an interpreter for a workspace, VS Code stores it separately and uses that instead.
- To check which interpreter is currently active, look at the status bar at the bottom-left of the VS Code window.
