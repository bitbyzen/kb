# Create an Installer for a Python App

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Creating an installer packages a Python application into a standalone executable that end users can install without needing Python or any dependencies pre-installed.

## Common Options

### PyInstaller

Bundles a Python app and its dependencies into a single executable. Works on Windows, macOS, and Linux.

```
pip install pyinstaller
pyinstaller --onefile your_script.py
```

The output is placed in the `dist/` folder.

### Inno Setup

A free Windows installer builder. Use it after PyInstaller to wrap the executable into a proper Windows installer (`.exe`) with install/uninstall support, shortcuts, and a setup wizard.

Typical workflow:

1. Use PyInstaller to produce the standalone executable.
2. Download and install [Inno Setup](https://jrsoftware.org/isinfo.php).
3. Create an Inno Setup script (`.iss`) that points to the executable and any supporting files.
4. Compile the script to produce the final installer `.exe`.

### cx_Freeze

An alternative to PyInstaller that also produces standalone executables. Useful when PyInstaller is not compatible with a specific package.

```
pip install cx_Freeze
```

## Notes

- Inno Setup is Windows-only. For macOS, consider tools like `create-dmg` or `py2app`.
- Always test the generated installer on a clean machine to catch missing files or dependencies.
