# Opt Out of GitHub Copilot AI Training

> **Source:** GitHub product announcement, effective April 24, 2026

---

## Summary

Starting **April 24, 2026**, GitHub will use Copilot activity to train AI models.
Free, Pro, and Pro+ users are opted in by default.

---

## Who Is Affected

| Plan | Status |
|------|--------|
| Free | ⚠️ Affected — opted in by default |
| Pro | ⚠️ Affected — opted in by default |
| Pro+ | ⚠️ Affected — opted in by default |
| Business | ✅ Not affected |
| Enterprise | ✅ Not affected |

---

## What Data Is Collected

- Prompts (inputs) and generated code (outputs)
- Code snippets and surrounding context (e.g. near the cursor)
- Accepted or edited suggestions
- Comments and documentation
- File names, repository structure, and navigation patterns
- User feedback on suggestions

---

## How to Opt Out

1. Sign in to the GitHub account you use with Copilot.
2. Go to [github.com/settings/copilot/features](https://github.com/settings/copilot/features).
3. Find the setting labelled **"Allow GitHub to use my data for AI model training"**.
4. Open the dropdown and select **Disabled**.

---

## Notes

- **Deadline:** April 24, 2026. Data collection begins for anyone who has not opted out by this date.
- Data may be shared within GitHub and its parent company Microsoft, but is not shared with external third-party AI providers.
- If you have not started using Copilot yet, opt out before your first session so no data is ever collected.
