# Manage Docker Images

> **Note:** This guide was generated by [Claude](https://claude.ai) (AI) and has not been fully reviewed by a human. Please verify the steps before following them in a production environment.

View, inspect, and delete Docker images using Docker Desktop.

---

## Open the Images Panel

1. Launch **Docker Desktop**.
2. Select **Images** in the left sidebar.

You will see a list of all locally available images with their name, tag, and size.

---

## Common Tasks

### Delete an image

1. Hover over the image you want to remove.
2. Click the **Delete** icon (trash) on the right.
3. Confirm the deletion.

> **Note:** You cannot delete an image that is currently used by a running container. Stop the container first.

### Inspect an image

1. Click the image name to open its details.
2. Review layers, environment variables, and exposed ports.

---

## Manage Images via Terminal

For more control, use the Docker CLI:

```bash
# List all local images
docker images

# Remove a specific image
docker rmi <image-name>:<tag>

# Remove all unused images
docker image prune
```
