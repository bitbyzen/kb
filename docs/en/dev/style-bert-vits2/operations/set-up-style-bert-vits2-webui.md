# Set Up Style-Bert-VITS2 WebUI

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Style-Bert-VITS2 is a free, open-source text-to-speech engine that supports Japanese, English, and Chinese. It runs locally on your PC and can be connected to YMM4 as a voice engine.

## What is Style-Bert-VITS2?

- Developed by litagin02, based on the original Bert-VITS2 project
- Not YMM4-specific — it is a general-purpose TTS engine
- Connects to YMM4 via a local API server (similar to VOICEVOX and CoeiroInk)
- Supports multiple languages including English with the right voice model

```text
Bert-VITS2 (original)
    └── Style-Bert-VITS2 (litagin02's fork, adds style control)
            └── AivisSpeech (uses Style-Bert-VITS2 as its engine)
```

## Requirements

- Windows 10/11
- Python 3.12.x
- ~5 GB free disk space (for models and dependencies)
- NVIDIA GPU recommended but not required (CPU works for inference)

## Step 1: Download Style-Bert-VITS2

1. Go to the [Style-Bert-VITS2 GitHub repository](https://github.com/litagin02/Style-Bert-VITS2).
2. Click the green **Code** button → **Download ZIP**.
3. Extract to a folder with no Japanese characters or spaces in the path.

> **Warning:** The path must not contain Japanese characters or spaces. Example of a valid path: `D:\00-portable-apps\Style-Bert-VITS2-master`

## Step 2: Set Up the Virtual Environment

Open a terminal in the extracted folder and run the following commands one by one.

**Create the venv:**

```bat
python -m venv venv
```

**Activate the venv:**

```bat
venv\Scripts\activate
```

You should see `(venv)` at the start of your prompt.

**Verify Python version:**

```bat
python --version
```

Python 3.12.x is recommended.

## Step 3: Install Dependencies

This version of Style-Bert-VITS2 includes `requirements-infer.txt` for inference-only use (lighter than the full `requirements.txt`, which includes training tools).

**Install inference dependencies:**

```bat
pip install -r requirements-infer.txt
```

> **Note:** This will take several minutes as it downloads PyTorch and other large packages.

**Upgrade PyTorch to the latest version** (required — the version pinned in `requirements-infer.txt` is too old):

```bat
pip install torch torchaudio --upgrade
```

**Upgrade pip (optional but recommended):**

```bat
python.exe -m pip install --upgrade pip
```

## Step 4: Initialize (Download Models)

Run `initialize.py` with the `--only_infer` flag to skip downloading heavy training models:

```bat
python initialize.py --only_infer
```

This downloads:

- BERT language models (including English `deberta-v3-large`)
- Default Japanese voice models (jvnv-F1-jp, jvnv-F2-jp, jvnv-M1-jp, jvnv-M2-jp, koharune-ami, amitaro)

> **Note:** The script may complete silently with no output — this is normal. Verify by checking that the `bert\` and `model_assets\` folders were created and populated.

## Step 5: Launch the WebUI

```bat
python app.py
```

The WebUI will open automatically in your browser at `http://127.0.0.1:7860`.

> **Note:** To launch in future sessions, activate the venv first, then run `python app.py`:
> ```bat
> venv\Scripts\activate
> python app.py
> ```

## Default Voice Models

| Model | Type |
|-------|------|
| jvnv-F1-jp | Japanese female 1 |
| jvnv-F2-jp | Japanese female 2 |
| jvnv-M1-jp | Japanese male 1 |
| jvnv-M2-jp | Japanese male 2 |
| koharune-ami | Japanese female (Koharune Ami) |
| amitaro | Japanese female (Amitaro) |

> **Note:** The default models are Japanese only. To use native English TTS, an English-trained model such as the RikkaBotan model must be added separately.

## Notes

- Keep the terminal window open while using the WebUI — closing it stops the server.
- The venv must be activated each session before launching.
- The PyTorch upgrade (`pip install torch torchaudio --upgrade`) is required due to a version conflict with the `transformers` library.
