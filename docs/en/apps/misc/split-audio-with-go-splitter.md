# Split Audio with Go-Splitter

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

**Go-Splitter** is a free Windows app by SoliderSound Ltd. that uses AI to separate audio files into individual parts.

## Supported Formats

WAVE, MP3, FLAC, M4A, AAC, AIFF, Ogg Vorbis, and others.

## Separable Parts

- Vocals
- Bass
- Drums
- Other

## Output

- Each part is exported as a WAVE file
- Multiple files can be saved together as a ZIP
- Processing is done locally — works offline

## Quality

- Separation quality is generally high
- A slight "shimmering" artifact may remain in some cases
- Adjustable with three quality presets
- Post-processing with effects can bring results to a usable level
