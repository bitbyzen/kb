# Filter Blue Light With f.lux

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

**f.lux** is a free application that reduces blue light emitted by your monitor by lowering the screen's **color temperature**, shifting the display toward warmer, amber tones — especially at night.

## How It Works

Light color is measured in **Kelvin (K)**. A lower color temperature produces warmer, redder light; a higher value produces cooler, bluer light. f.lux gradually reduces this value as the day progresses to cut blue light exposure.

## Key Features

### Day and Night Settings

Set separate color temperatures for daytime and nighttime use via sliders.

### Biorhythm Presets

Version 4 and later includes presets such as:

- Recommended Colors
- Reduce Eyestrain
- Working Late
- Cave Painting (for very dark rooms)
- Color Fidelity

### Location Setting

Enter your ZIP code or city name so f.lux can automatically adjust based on your local sunrise and sunset times.

### Transition Speed

Choose how quickly the screen shifts: fast (20 seconds) or slow (60 minutes). Fast is the default.

### Disable Options

Temporarily disable f.lux for one hour, until sunrise, or only when using fullscreen apps.

### Expanded Color Range

Click **Expand Color Range** to push the slider below the Incandescent setting. A restart is required.

## Summary

f.lux is a set-and-forget tool that reduces eye strain during long hours at a computer, particularly in the evening.
