# Add CoeiroInk Voices to YMM4

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

CoeiroInk (COEIROINK) is a free local AI text-to-speech engine that integrates directly with YMM4. It runs on your PC and connects via a local API, similar to VOICEVOX.

## What is CoeiroInk?

- Free TTS engine developed by Shirowani
- Includes downloadable voice characters
- Default port: `50032` (can run simultaneously with VOICEVOX on port `50021`)
- Available at [https://coeiroink.com](https://coeiroink.com)

## Step 1: Install CoeiroInk

1. Go to [https://coeiroink.com](https://coeiroink.com) and download the appropriate version:
    - **Windows / CPU** — recommended for most users
    - **Windows / GPU** — faster synthesis if you have an NVIDIA GPU
2. Extract the downloaded ZIP file
3. Run the `.exe` self-extractor inside to get the final folder
4. Launch `COEIROINKv2.exe`

> **Note:** The download is a ZIP containing a self-extracting EXE. You need to extract twice to get the final application folder.

> **Warning:** `engine.exe` inside the CoeiroInk folder may be flagged as a virus by security software. If CoeiroInk fails to launch, check your security software's quarantine and manually restore `engine.exe`.

## Step 2: Set the Executable Path in YMM4

1. In YMM4, go to **File → Settings**
2. Navigate to **Voice synthesis → COEIROINK v2**
3. Click the folder icon and select `COEIROINKv2.exe` from your CoeiroInk folder
4. Optionally enable **"Run in background"** — this launches CoeiroInk silently without opening its UI every time YMM4 generates a voice

## Step 3: Register a Character in YMM4

1. Go to **File → Edit character**
2. Click the **+** button to create a new character
3. Set the following:
    - **Name**: your preferred character name (e.g. `Tsukuyomi`)
    - **Group**: `COEIROINK`
    - **Voice**: select `COEIROINK v2 / [character name]` from the dropdown
    - **Style**: choose a style (e.g. れいせい = calm)
4. Close the Character settings window

> **Note:** If a newly installed CoeiroInk character doesn't appear in the voice dropdown, look for a refresh button in the voice list to reload available voices.

## Step 4: Launch CoeiroInk Before Using YMM4

Before generating voices in YMM4, launch `COEIROINKv2.exe` first — unless you enabled **"Run in background"** in Step 2.

## Use the Voice in YMM4

Once registered, the character works like any other YMM4 character:

- Select the character from the bottom bar and type dialogue to add voice items
- Or use a **scenario CSV file** with the character name in Column A

## Terms of Use

When publishing videos that use CoeiroInk voices, you must include a credit in the video content or description. The required format is:

```
COEIROINK合成音声名
```

For example: `COEIROINK つくよみちゃん`

Check the individual voice character's terms for any additional requirements.

## Default Voice: Tsukuyomi-chan (つくよみちゃん)

CoeiroInk includes **Tsukuyomi-chan** as the built-in starter character with the following styles:

| Style (JP) | Meaning |
|------------|---------|
| れいせい | Calm |
| おちゃめ | Playful |
| びっくり | Surprised |
| こわい | Scary |

Additional voices can be downloaded from [https://coeiroink.com](https://coeiroink.com).
