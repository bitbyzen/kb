# Understand Genspark

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Genspark is a research tool that combines search with AI summarisation. You search as you would with a standard search engine, and the AI organises information from multiple sources into a structured guide page.

For example, searching "Tokyo sightseeing" returns a page already organised into recommended spots, suggested itineraries, and tips — rather than a list of links to browse individually.
