# Add a MyCoeiroInk Voice to CoeiroInk

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

MyCoeiroInk is the community voice library for CoeiroInk, where creators distribute downloadable voice characters. This page uses **白痴ー (Hakuchi)** — one of the most popular male voices on MyCoeiroInk — as an example. The same steps apply to any MyCoeiroInk voice.

## Step 1: Find the Voice on MyCoeiroInk

1. Go to [https://coeiroink.com/mycoeiroink](https://coeiroink.com/mycoeiroink)
2. Click the center illustration **探す (Sagasu / Search)** to open the voice list
3. Enter **白痴ー** in the search box and press **Enter**
4. Click the **白痴ー** panel in the results — this takes you to the BOOTH distribution page

## Step 2: Download a Variation

白痴ー is distributed as multiple separate ZIP files, each representing a different style:

| File name | Romaji | Style |
|-----------|--------|-------|
| 若輩.zip | Jakuhai | Inexperienced / junior (kohai) tone |
| Others | — | Machine-like, Kansai dialect, etc. |

If you are unsure where to start, **若輩 (Jakuhai)** is a good default.

Download the ZIP file for the style you want.

## Step 3: Install the Voice into CoeiroInk

1. Extract the ZIP file — inside you will find a folder with an alphanumeric name (e.g. `a1b2c3d4...`)
2. Copy that folder into the `speaker_info` folder inside your CoeiroInk installation directory:

    ```
    [CoeiroInk folder]\speaker_info\[alphanumeric folder]
    ```

3. Launch (or restart) **CoeiroInk**
4. Click the character icon at the top of CoeiroInk to open the character dropdown — the new voice should now appear

> **Note:** Each style variation is a separate download. You can install multiple variations of the same character by repeating these steps.

## Step 4: Use the Voice in YMM4

After adding a new voice, you may need to refresh the voice list in YMM4 for it to appear:

1. Go to **File → Edit character**
2. Open the voice dropdown and look for a refresh button to reload available voices

The voice can also be registered as a character named **黒聡 鵜月 (Kurosato Uzuki)**.
