# Install VOICEVOX

> **Note:** This guide was generated by [Claude](https://claude.ai) (AI) and has not been fully reviewed by a human. Please verify the steps before following them in a production environment.

[VOICEVOX](https://voicevox.hiroshiba.jp) is a free, open-source text-to-speech application for Windows, macOS, and Linux.

---

## Step 1: Download the Installer

1. Go to the [official VOICEVOX website](https://voicevox.hiroshiba.jp).
2. Click the **Download** button for Windows.
3. Save the installer file (e.g. `VOICEVOX-installer.exe`) to your computer.

---

## Step 2: Run the Installer

1. Double-click the downloaded `.exe` file to launch the setup wizard.
2. Click **Next** to proceed past the welcome screen.

---

## Step 3: Choose an Installation Scope

You will be asked: *"Who should this application be installed for?"*

| Option | When to choose |
|--------|---------------|
| **Only for me** *(recommended)* | Personal use on your own Windows account. No admin rights needed. |
| **Anyone who uses this computer** | Only if multiple Windows users need access to VOICEVOX. Requires admin rights. |

> **Tip:** For most users, **Only for me** is the right choice — it installs faster and requires no administrator privileges.

Click **Next** to continue.

---

## Step 4: Choose an Install Location

The installer suggests a default folder. Leave it as-is or click **Browse** to choose a different location.

Click **Next** when ready.

---

## Step 5: Complete the Installation

1. Click **Install** to begin copying files.
2. Wait for the progress bar to finish.
3. Click **Finish** to close the setup wizard.

---

## Step 6: Launch VOICEVOX

1. Find **VOICEVOX** in your Start menu or on your desktop and open it.
2. On first launch, it may download additional voice model data — this is normal.

---

## Troubleshoot

| Problem | Solution |
|---------|----------|
| Installation fails | Right-click the installer → **Run as administrator** |
| Voice models not loading | Check your internet connection — some assets are downloaded on first run |
| Slow performance | Update your GPU drivers — VOICEVOX can use your GPU for faster synthesis |
