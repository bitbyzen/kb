# Set Up Discord and Follow a Server

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

1. Download and install the Windows app from the official Discord site, then launch it.
1. Log in to your account.
1. Add the server you want to follow using one of these methods:
    - **Click an invite link** — click a Discord link on an official site or repository. You will be taken to an invite screen where you can accept the invitation. For example, the ComfyUI Discord link is in the **README** of the [official GitHub repository](https://github.com/Comfy-Org/ComfyUI).
    - **Enter an invite link manually** — click the **+** button (Add a Server) in the left navigation, then paste the invite link on the next screen.
1. After joining, answer the **Customization Questions** in the centre of the screen. Answering unlocks additional channels.
1. Right-click **#announcement** in the left navigation, go to **Notification Settings** → **All Messages** to receive notifications for updates and announcements.

## Recommended Channels

| Channel | Purpose |
|---|---|
| `#announcement` | New versions and important notices |
| `#help` | Usage questions and troubleshooting |
| `#general` | Discussion and information sharing |
