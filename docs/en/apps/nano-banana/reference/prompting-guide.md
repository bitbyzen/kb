# Apply Nano Banana Prompting Best Practices

Nano Banana models apply deep reasoning to fully understand your prompt before generating an image. Built on the Gemini 3 family, they support real-time web search, multimodal inputs, multilingual text rendering, and studio-quality visual controls.

## Core Best Practices

| Principle | Description |
|---|---|
| **Be Specific** | Provide concrete details on subject, lighting, and composition |
| **Positive Framing** | Say "empty street" not "no cars" — describe what you want |
| **Control the Camera** | Use cinematic terms: "low angle," "aerial view," "f/1.8" |
| **Iterate** | Refine with follow-up prompts conversationally |

## The Five Frameworks

### 01 — Image Generation

Your prompt structure depends on whether you are using reference images or relying solely on text. You are the director — a simple list of keywords won't cut it.

#### Text-to-Image (No References)

Starting from a blank canvas, describe the scene narratively.

**Formula:**

```
[Subject] + [Action] + [Location/Context] + [Composition] + [Style]
```

**Example prompt:**

> A striking fashion model wearing a tailored brown dress, sleek boots, and holding a structured handbag. Posing with a confident, statuesque stance, slightly turned. A seamless, deep cherry red studio backdrop. Medium-full shot, center-framed. Fashion magazine style editorial, shot on medium-format analog film, pronounced grain, high saturation, cinematic lighting effect.

#### Multimodal Generation (With References)

Combine up to 14 reference images in a single prompt — perfect for maintaining character consistency or merging a product into a new environment.

**Formula:**

```
[Reference Images] + [Relationship Instruction] + [New Scenario]
```

**Example prompt:**

> Using the attached napkin sketch as the structure and the attached fabric sample as the texture, transform this into a high-fidelity 3D armchair render. Place it in a sun-drenched, minimalist living room.

### 02 — Image Editing

Editing requires a different mindset. You already have a base image — focus your prompt on what is changing and, critically, what is staying the same.

#### Conversational Editing (No New References)

Generate an image, then tweak it through natural conversation. Semantic masking lets you define a "mask" through text to edit only a specific part of an image.

- Be explicit about what to keep exactly the same
- Use clear, direct language for what to remove or change

**Example prompt:**

> "Remove the man from the photo"

#### Composition and Style Transfer (With New References)

Bring new images into the prompt to alter an existing one:

- **Adding elements:** Upload a base image + an object image, then tell the model to combine them
- **Style transfer:** Upload a photo and ask the model to recreate its content in a different artistic style (e.g., transform a city street into a Van Gogh painting)

### 03 — Real-Time Information from Web Search

Instead of describing a fictional scene, instruct the model to retrieve real-world data and then specify how to visualize it. Nano Banana 2 is powered by live web search.

**Formula:**

```
[Source/Search Request] + [Analytical Task] + [Visual Translation]
```

**Example prompt:**

> Search for the current weather and date in San Francisco. Analytically, use this data to modify the scene (e.g., if raining, make it look grey and rainy). Visualize this in a miniature city-in-a-cup concept embedded within a realistic, modern smartphone UI.

### 04 — Text Rendering and Localization

Nano Banana excels at rendering sharp, legible text for posters, diagrams, and product mockups. It supports multilingual text generation in over 10 languages.

**Key rules:**

- Enclose desired words in quotes — e.g., `"Happy Birthday"` or `"URBAN EXPLORER"`
- Describe typography style or font name — e.g., "bold, white, sans-serif" or "Century Gothic 12px"
- Write in one language, specify a different target language for output to localize
- **Text-first hack:** First converse with the model to generate text concepts, then ask for an image with that text

**Example prompt:**

> A high-end, glossy commercial beauty shot of a sleek, minimalist nude-colored face moisturizer jar on a warm studio background. Soft, radiant lighting. Render three lines of text: "GLOW" in a flowing Brush Script font; "10% OFF" in a heavy Impact font; "Your First Order" in a thin Century Gothic font. Then translate the text into Korean and Arabic.

### 05 — Prompting Like a Creative Director

Stop typing keywords and start directing the scene. Elevate results from good to breathtaking with four studio-quality controls.

#### Lighting

Tell the model exactly how the scene is illuminated.

| Style | Example |
|---|---|
| Studio | "Three-point softbox setup" |
| Dramatic | "Chiaroscuro lighting, harsh high contrast" |
| Natural | "Golden hour backlighting, long shadows" |

#### Camera, Lens and Focus

Dictate the exact camera type to change the visual DNA of the image.

| Camera | Effect |
|---|---|
| GoPro | Immersive, distorted action feel |
| Fujifilm | Authentic color science |
| Disposable | Raw, nostalgic flash aesthetic |

For lenses: `"f/1.8 shallow depth of field"` / `"wide-angle lens"` / `"macro lens"`

#### Color Grading and Film Stock

The texture and color of the image set the emotional tone.

- **Nostalgic/gritty:** `"1980s color film, slightly grainy"`
- **Modern/moody:** `"Cinematic color grading, muted teal tones"`

#### Materiality and Texture

Define the physical makeup of every element — don't just name it, describe it.

| Instead of... | Say... |
|---|---|
| "suit jacket" | "navy blue tweed jacket" |
| "armor" | "ornate elven armor, etched with silver leaf patterns" |
| "coffee mug" | "minimalist ceramic coffee mug" |
