# Duplicate a Macro in Keychron Launcher

> **Note:** This guide was generated by [Claude](https://claude.ai) (AI) and has not been fully reviewed by a human. Please verify the steps before following them in a production environment.

Keychron Launcher does not currently provide a built-in **Duplicate** button for macros.
You can work around this by copying the macro code in **Code Input** mode.

---

## Steps

1. Open the **Macro** tab in Keychron Launcher.
2. Select the macro you want to duplicate.
3. Switch from **Configuration** to **Code Input**.
4. Copy the entire macro code.
5. Select an empty macro slot (e.g. `M01`).
6. Switch to **Code Input** for the new slot.
7. Paste the copied code.
8. Edit the parts you want to change.

---

## Example

### Original macro

```
{+KC_LCTL}{+KC_LSFT}{-KC_2}{-KC_LSFT}{-KC_LCTL}docker run --rm -it -p 8000:8000 -v $(pwd):/mkdocs my-mkdocs{+KC_ENT}{-KC_ENT}
```

### Duplicated and modified macro

```
{+KC_LCTL}{+KC_LSFT}{-KC_2}{-KC_LSFT}{-KC_LCTL}git add .{+KC_ENT}{-KC_ENT}git commit -m "Update docs"{+KC_ENT}{-KC_ENT}git push{+KC_ENT}{-KC_ENT}
```

---

## Understand the Syntax

| Token | Meaning |
|-------|---------|
| `{+KC_XXX}` | Key press |
| `{-KC_XXX}` | Key release |
| `{+KC_ENT}{-KC_ENT}` | Enter key (sends a new line) |

For most use cases, you only need to modify the **text portion** (the commands between key tokens).

---

## Tips

- Keep key press/release pairs intact to avoid broken macros.
- Use multiple `{+KC_ENT}{-KC_ENT}` sequences to simulate multi-line input.
- Test your macro after editing to confirm it behaves as expected.
