# Export Keymap

> **Note:** This guide was generated by [Claude](https://claude.ai) (AI) and has not been fully reviewed by a human. Please verify the steps before following them in a production environment.

Export your keymap as a backup file from Keychron Launcher.

---

## Steps

1. Launch **Keychron Launcher** in your browser.
2. Select your keyboard and connect.
3. Select **Keymap** in the left sidebar.
4. Select the layer you want to export (e.g. **Layer 2**) using the layer tabs at the top.
5. Click **Export** on the right side of the keyboard map.
6. Save the exported file to your computer.

---

> **Tip:** Export your keymap before flashing new firmware or making major changes, so you can restore it using **Import** if needed.
