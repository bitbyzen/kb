# Update Payment Method

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

In DeepL, the only accepted payment method is a credit card.

## Steps

1. Click your account icon in the upper right.
2. Select **Account** from the dropdown menu.
3. Select **Account** on the top menu.
4. Scroll down to the **Identity Verification** section.
5. Click the **Change** link to update your credit card number.

> **Note:** There does not appear to be an option to remove an expired credit card.
