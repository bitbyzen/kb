# Understand Spectrum in ComfyUI

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Spectrum is an inference acceleration technique for diffusion models. Instead of running the full UNet/DiT every step, it skips some steps by using predictions — achieving roughly 1.5–2× speed-up depending on settings.

## Recommended Nodes

| Node | Notes |
|---|---|
| **ComfyUI Spectrum SDXL Node** (ruwwww) | Best for general use — supports SDXL and Anima (DiT), easy to tune |
| Spectrum SDXL Proper | Closer to the paper; SDXL only; less customisable |
| Anima-Enhancer | Anima-specific; focused on image quality; not general-purpose |

Start with **ComfyUI Spectrum SDXL Node**.

## Key Settings

### `window` (most important)

- Small → stable but slower
- Large → faster but prone to artifacts
- Recommended starting value: **2–3**

### Late-step behaviour

Spectrum tends to produce artifacts in the final steps. Turn it off for the last 20% of steps to avoid this.

### Colour desaturation

Prediction errors can reduce colour saturation. Enable the **calibration** feature or turn Spectrum off for the later steps.

## Recommended Starting Settings

| Setting | Value |
|---|---|
| `window` | 2–3 |
| `m` | 2–3 |
| `lam` | 0.1–0.3 |
| Last 20% of steps | Spectrum off |
