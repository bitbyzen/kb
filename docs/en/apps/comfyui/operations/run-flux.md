# Run FLUX Locally with ComfyUI

> **Note:** This guide was generated by [Claude](https://claude.ai) (AI) and has not been fully reviewed by a human. Please verify the steps before following them in a production environment.

Run [FLUX by Black Forest Labs](https://blackforestlabs.ai) locally using [ComfyUI](https://github.com/comfyanonymous/ComfyUI) on Windows.

---

## Prerequisites

### GPU requirements

| Tier | GPU | VRAM |
|------|-----|------|
| Minimum | RTX 3060 | 12 GB |
| Recommended | RTX 4070 Ti / 4080 / 4090 | 16 GB+ |

NVIDIA GPU with CUDA support is required.

### Check your GPU

Open **Task Manager** → **Performance** → **GPU**, or run:

```
Win + R → dxdiag
```

---

## Step 1: Install ComfyUI

### Download the portable version

1. Go to the [ComfyUI GitHub releases page](https://github.com/comfyanonymous/ComfyUI/releases).
2. Download `ComfyUI_windows_portable`.
3. Extract it to a simple path, e.g.:

```
C:\AI\ComfyUI
```

### Launch ComfyUI

Double-click `run_nvidia_gpu.bat`.

ComfyUI will open in your browser at:

```
http://127.0.0.1:8188
```

If the UI loads — you are ready to continue.

---

## Step 2: Download the FLUX Model

1. Go to [Hugging Face](https://huggingface.co) and download one of:

    - **FLUX.1-dev** — most popular, higher quality
    - **FLUX.1-schnell** — lighter and faster

2. Place the `.safetensors` file in:

```
ComfyUI\models\checkpoints\
```

---

## Step 3: Install Required Nodes

FLUX is not standard Stable Diffusion and requires additional custom nodes.

1. Open **ComfyUI Manager**.
2. Click **Install Custom Nodes**.
3. Search for and install:

    - `Flux nodes`
    - `T5 loader`
    - Updated sampler nodes (if prompted)

4. Restart ComfyUI after installing.

---

## Step 4: Set Up the FLUX Workflow

Build the following node graph in ComfyUI:

```
Load Checkpoint (Flux)
       ↓
CLIP / T5 Text Encode
       ↓
KSampler
       ↓
VAE Decode
       ↓
Save Image
```

> **Note:** FLUX uses a **T5 text encoder** instead of the classic CLIP encoder used in standard Stable Diffusion workflows.

## Optimize Performance

### Low VRAM (under 16 GB)

Open `run_nvidia_gpu.bat` and append the following flags after `python main.py`:

```bat
--force-fp16 --lowvram
```

### High VRAM (16 GB+)

```bat
--force-fp16
```

### Enable xFormers (optional)

If xFormers is not enabled automatically, install it manually:

```bash
pip install xformers
```

This can significantly speed up image generation.
