# Stop Loading Previous Sessions on Startup

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

When the **Load previous session** option is enabled, iZotope RX8 saves your work to a session folder and reloads it the next time you launch the application. If you move or delete the original audio files after a session is saved, RX8 displays errors on every startup.

Disabling the option clears all saved session data and prevents RX8 from reloading past work.

## Steps

1. Open the application preferences.
2. Find the **Load previous session** checkbox and uncheck it.
3. RX8 deletes all existing session data immediately.

> **Note:** If you re-enable the checkbox later, RX8 starts saving sessions again from that point onward. Previously deleted session data is not restored.
