# Download a Website

Use [HTTrack Website Copier](http://www.httrack.com/page/1/en/index.html) to save a complete copy of any website for offline use.

## Prerequisites

- Download and install HTTrack from the official site:
  http://www.httrack.com/page/1/en/index.html

## Usage

1. Open HTTrack.
2. Create a new project and give it a name.
3. Enter the URL of the website you want to download.
4. Click **Next** and then **Finish** to start the download.

> **Note:** Make sure you have permission to mirror a website before downloading it.
