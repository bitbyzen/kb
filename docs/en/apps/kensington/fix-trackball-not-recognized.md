# Fix a Trackball Not Recognized by KensingtonWorks

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

If you have multiple USB receivers connected, KensingtonWorks may fail to recognize a newly added trackball.

## Steps

1. Unplug the USB receiver of the existing trackball.
2. Allow KensingtonWorks to detect the new trackball.
3. Reconnect the previous USB receiver.
