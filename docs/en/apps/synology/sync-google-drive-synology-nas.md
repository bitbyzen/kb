# Sync Google Drive to Synology NAS

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Cloud Sync is a Synology package that downloads files from Google Drive to a folder on your NAS automatically. This guide walks you through the full setup.

---

## Step 1: Install Cloud Sync

1. Log into DSM.
2. Open **Package Center**.
3. Search for **Cloud Sync**.
4. Click **Install**.

---

## Step 2: Open Cloud Sync and Choose Google Drive

1. Launch **Cloud Sync** from the main menu.
2. Select **Google Drive** from the list of cloud providers.
3. Click **Next**.

---

## Step 3: Authorize Your Google Account

1. On the permissions screen, check the box to grant access to your Google Drive files.
2. Click **Continue**.
3. Sign in to your Google account and allow the requested permissions.

> **Note:** The permission says "see, edit, create, and delete" — this is the standard Google OAuth scope. Cloud Sync will only delete files if you configure it to do so.

---

## Step 4: Configure Sync Settings

Set the following options on the configuration screen:

| Setting | Recommended value |
|---|---|
| **Local path** | A folder on your NAS (e.g., `/volume1/GoogleDrive`) |
| **Remote path** | `/` to sync all of Drive, or a specific folder (e.g., `/My Folder`) |
| **Sync direction** | Download remote changes only |

Then enable these two checkboxes:

- **Don't remove files in the destination folder when they are removed in the source folder** — prevents accidental deletions on your NAS if you delete something in Drive.
- **Convert Google online documents to Microsoft Office or jpeg formats** — downloads Google Docs, Sheets, and Slides as `.docx`, `.xlsx`, and `.pptx` files you can open locally.

Leave **Data encryption** unchecked unless you need it.

---

## Step 5: Start the Sync

Click **Next** to save your settings. Cloud Sync begins the initial download automatically.

You can monitor progress from the Cloud Sync main window. After the initial sync, any new or updated files in the selected Google Drive folder will download to your NAS automatically.

---

## Tips

- **Sync direction matters.** "Download remote changes only" is the safest option. Two-way sync can cause deletions on either side if misconfigured.
- **Sync a subfolder, not all of Drive.** If you only need specific content, set the remote path to that folder to avoid downloading everything.
- **Add more tasks later.** You can create additional sync tasks for other Google Drive folders from the Cloud Sync main window.
