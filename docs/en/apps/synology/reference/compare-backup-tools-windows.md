# Compare Synology Backup Tools for Windows 11

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

A practical overview of the two main Synology tools and what they are best at.

---

## Your Goal

You want to:

- Automatically back up files from Windows 11 to a Synology NAS
- Possibly target a specific folder like `C:\Users\black\Documents\Obsidian Vault`

---

## The Two Main Options

### 1. Active Backup for Business

> Think: "Full backup / disaster recovery"

#### What It Does

- Backs up your entire PC or whole drive (e.g., `C:`)
- Uses image-based backup
- Lets you restore:
  - Entire system
  - Individual files or folders later

#### Automation

Fully automatic (schedule or event-based).

#### Limitation

You cannot choose a specific folder to back up — it is all-or-nothing at the disk or volume level.

#### Best For

- Protection against PC failure, OS corruption, or ransomware
- Full system recovery

---

### 2. Synology Drive

> Think: "Dropbox / Google Drive style sync and backup"

#### What It Does

- Lets you pick specific folders to sync or back up to the NAS
- Keeps versions (file history)

#### Automation

Runs continuously or on a schedule.

#### Key Advantage

You can select exactly the folder you want:

```
C:\Users\black\Documents\Obsidian Vault
```

#### Limitation

Not a full system backup — cannot restore your entire PC.

#### Best For

- Daily working files
- Specific folders (like Obsidian, Documents, Projects)

---

## Side-by-Side Comparison

| Feature | Active Backup for Business | Synology Drive |
|---|---|---|
| Backup type | Full system (image-based) | File/folder |
| Select specific folder | No | Yes |
| Full PC restore | Yes | No |
| File-level restore | Yes | Yes |
| Automation | Yes | Yes |
| Best use | Disaster recovery | Everyday file sync |

---

## The Key Insight

- **Active Backup for Business** — "Backup everything, restore anything"
- **Synology Drive** — "Backup only what you choose"

---

## Recommended Setup

For most people, the best approach is to use both together:

| Tool | Purpose |
|---|---|
| **Synology Drive** | `Obsidian Vault` — daily work, instant sync, versioning |
| **Active Backup for Business** | Full PC safety — in case everything breaks |

This gives you:

- Fast access and versioning for your notes
- Full protection if your PC dies

---

## Bottom Line

- Automatic backup from Windows 11 to Synology works.
- Active Backup for Business cannot target a specific folder.
- Synology Drive is the right tool for folder-level backup.

> **Note:** If you are using Obsidian, look into avoiding sync conflicts and data corruption — it is a common issue when combining Obsidian with sync tools.
