# Restore a Deleted File

> **Note:** This guide was generated by Claude and has not been fully reviewed by a human.

## Reference

https://kb.synology.com/ja-jp/DSM/tutorial/How_do_I_restore_files_deleted_from_Synology_NAS

## Steps

1. Log in to Synology DSM.
2. Navigate to the folder from which the file was deleted. For example, if the file was deleted from the **office** folder, select that folder.
3. Select the **Enable Recycle Bin** checkbox.
4. Confirm that a Recycle Bin has been created inside the selected folder.
5. Locate the deleted file inside the Recycle Bin.
6. Drag and drop the file from the Recycle Bin back to its original folder.
