# Analyze Storage

## Overview

Use Storage Analyzer to generate a storage usage report.

## Steps

### Launch Storage Analyzer

1. Log in to Synology DiskStation Manager.
2. Open the Main Menu at the upper-left corner (gray grid icon).
3. Find and launch **Storage Analyzer**.

### Set the Report Save Location (First Time Only)

4. The **Storage Usage Report Wizard** opens automatically. Close it.
5. Open **Settings**.
6. In the **General** tab, click **Select** next to **Save report to:**.
7. In the **Select** dialog, click **Create Folder**.
8. Create a folder (e.g., `reports`), then select it.
9. Click **OK** to close the **Settings** dialog.

### Generate the Report

10. Click **Create** at the bottom of the **Storage Analyzer** window.
11. The **Storage Usage Report Wizard** opens.
12. Enter a task name (e.g., `Storage Analysis 260321 1623`), then click **Next**.

    > **Note:** Spaces are allowed, but hyphens and underscores are not.
    
13. Select the report items, then click **Next**.
14. Select the folders to analyze, then click **Next**.
15. Set the options for potential duplicate files and the file list, then click **Next**.
16. Select **Generate reports now**, then click **Done**.

### View the Report

17. Wait for the analysis to complete. A **Successful** message appears in green.
18. Double-click the message to view the report.
