# Use Synology NAS as a Claude Workflow Hub

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Overview

This guide documents the complete workflow for using Synology NAS as a central file hub between Windows PC (Claude Code) and Google Pixel (Claude mobile app). The setup uses only official tools — no third-party MCP connectors required.

---

## Architecture

```
Windows PC (<YOUR-PC>)
└── Claude Code
    └── D:\02-assistant\          ← local working folder
        └── projects\creator\bxz\
            └── project-video\    ← active workspace
                │
                │  Synology Drive (Two-way sync)
                ▼
Synology DS720 NAS
└── office\02-assistant\          ← NAS mirror
    └── projects\creator\bxz\
        └── project-video\
                │
                │  Synology Drive app (read/write)
                ▼
Google Pixel
└── Claude app
    └── + button → upload file from Synology Drive app
```

---

## Workflow

### On Windows PC

1. Use **Claude Code** to create and edit files in `D:\02-assistant\projects\creator\bxz\project-video`.
2. **Synology Drive** automatically syncs all changes to the NAS in the background.
3. No manual steps needed — files are always up to date on NAS.

### On Google Pixel

1. Open the **Claude app**.
2. Tap the **`+`** button at the bottom of the chat window.
3. Select the file from the **Synology Drive app** (e.g. a prompt or MD file created on PC).
4. Ask Claude to generate a video script, SRT file, or any other output.
5. Save the output back to NAS via the Synology Drive app if needed.

## Why No MCP Connector?

During setup, a community-built MCP server (`mcp-server-synology`) was considered to allow Claude on Pixel to autonomously access NAS files. It was decided **not** to use it because:

- It is not an official tool from Synology or Anthropic.
- It requires storing NAS credentials in a config file.
- The simpler alternative — uploading files via the `+` button in Claude app — achieves the same result safely.

When an official MCP connector becomes available from Synology or Anthropic, this workflow can be upgraded at that point.

- `bxz` — brand abbreviation for Bitbyzen
- `project-` prefix — used for project subfolders, allowing future expansion (e.g. `project-music`, `project-blog`)
- `project-video` — all files related to video production, not just scripts

| Folder | Method | Reason |
|--------|--------|--------|
