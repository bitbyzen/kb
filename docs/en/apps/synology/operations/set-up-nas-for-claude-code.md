## Overview

This guide documents the setup of a Synology NAS (DS720) as a central file hub accessible by Claude Code on a Windows PC and Claude on Android (Google Pixel). The goal is a workflow where files created on PC are instantly available on any device, with Claude able to read and write files across all platforms.

### Target Workflow

1. Generate prompt or MD files on Windows PC using Claude Code.
2. Files automatically sync to Synology NAS (`office` share).
3. On Google Pixel, Claude reads those files via MCP and generates video scripts.
4. Scripts are written back to NAS, accessible on PC again.

## Phase 1: NAS Configuration

### Step 1: Enable SSH

**Location:** Control Panel → Terminal & SNMP → Terminal tab

1. Check **Enable SSH service**.
2. Leave port as `22` (default).
3. Click **Apply** and confirm the warning dialog.

> **Note:** SSH only supports logins from accounts in the administrators group for direct DSM access. The `claude-mcp` account uses SFTP/API access instead.

---

### Step 2: Create the `claude-mcp` User

**Location:** Control Panel → User & Group → Create

#### User Details

- **Username:** `claude-mcp`
- **Password:** Set a strong password and store it securely.
- **Group:** `users` only — do not add to `administrators` or `http`.

#### Shared Folder Permissions

| Folder | Permission |
|--------|-----------|
| `office` | Read/Write |
| `homes` | No Access |
| `ActiveBackupforBusiness` | No Access |

#### Application Permissions

| Application | Permission |
|-------------|-----------|
| File Station | Allow |
| SFTP | Allow |
| Synology Drive | Allow |
| DSM, FTP, AFP, Active Backup | Not granted |

#### Other Settings

- **Quota:** Unlimited (default — fine for a service account)
- **Speed limit:** Unlimited (default)
- **2FA:** Do not enable

> **Warning:** The MCP server cannot handle 2FA prompts. Never enable 2FA on the `claude-mcp` account.

## Phase 2: Folder Structure

Open **File Station** and create the following structure inside the `office` share.

> **Note:** Check your existing `office` share contents before creating folders to avoid conflicts.

```
office/
├── projects/          ← active project files
│   └── claude-work/   ← Claude Code generated files
├── scripts/           ← video scripts for YMM4
├── prompts/           ← reusable prompt MD files
└── archive/           ← completed projects
```

## Phase 3: MCP Server Setup

Install `mcp-server-synology` on the Windows PC to allow Claude Code and claude.ai to interact with the NAS.

**Repository:** `atom2ueki/mcp-server-synology`

> **Warning:** Use the dedicated `claude-mcp` account with minimal permissions — not your primary admin account.

### Step 1: Install Python

Install Python on Windows if not already installed.

### Step 2: Install the MCP Server

Clone `mcp-server-synology` from GitHub.

### Step 3: Configure Settings

Create `settings.json` at `~/.config/synology-mcp/settings.json` with the NAS IP (`192.168.xx.xx`) and `claude-mcp` credentials.

### Step 4: Add to Claude Code

Add the MCP server to Claude Code configuration.

### Step 5: Connect to claude.ai

Connect the MCP server to your claude.ai account for Pixel access.

---

## Phase 4: Synology Drive Sync

Install Synology Drive client on Windows to keep a local sync copy for Claude Code to work on without network latency.

1. Install Synology Drive client from Synology Download Center.
2. Connect to DS720 at `192.168.xx.xx`.
3. Sync `office/projects` to a local folder (e.g. `D:\SynologyDrive\projects`).
4. Claude Code works on the local folder — changes sync to NAS automatically.
