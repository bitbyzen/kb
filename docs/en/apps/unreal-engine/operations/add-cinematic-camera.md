# Add a Cinematic Camera to a Level Sequence

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Prerequisites

- A Level Sequence created and open in the Sequencer panel. See [Create a Level Sequence](create-level-sequence.md).

## Steps

1. In the **Sequencer** panel, click **+ Track**.

2. Select **Actor to Sequencer**.

3. Choose the character Blueprint (e.g., `bp_AnimeCharacter`) to add it as a track.

4. Click the **camera icon** in the Sequencer toolbar.

5. Select **Create Camera**.

Unreal Engine adds a Cinematic Camera Actor and switches the Viewport to the camera's point of view, showing a framed movie-style shot.

## Note

To reposition the camera, select it in the Viewport and use **W** (Move) and **E** (Rotate) to frame the subject.
