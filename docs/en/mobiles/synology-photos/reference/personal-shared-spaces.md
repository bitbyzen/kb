# Understand Personal Space and Folder Structure in Synology Photos

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## The `home` and `homes` Folders

In Synology NAS, `home` and `homes` are two views of the same data — no files are duplicated.

- **`homes` folder:** The parent folder for all user home directories on the NAS (visible to admins only by default).
- **`home` folder:** A shortcut to the currently logged-in user's personal folder.

When you back up to **Personal Space**, photos are saved to:

- Actual path: `/homes/<username>/Photos/MobileBackup/...`
- Your shortcut: `/home/Photos/MobileBackup/...`

Both paths point to the same files.

## Recommended Settings for a Single-User NAS

If you are running the NAS as a private personal environment:

1. **Enable User Home** — this is required.
2. **Set the backup destination** in Synology Photos to **Personal Space**.
3. **Check permissions** — if other users are registered on the NAS, confirm they cannot access the `homes` folder (the default setting) to keep your photos private.

## Storage Usage

If storage usage appears to spike in Storage Manager, this is not caused by duplicate data. It reflects background processing such as index creation, thumbnail generation, and metadata management — all of which run quickly on a DS720+ with WD Red SA500 SSDs.
