# Convert Google Sheets to Excel on Android

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

On Android, downloading a spreadsheet from the Google Sheets app defaults to PDF. Follow these steps to save the file as an Excel (`.xlsx`) file and download it to local storage.

## Step 1: Convert to Excel Format

1. Open your spreadsheet in the **Google Sheets** app.
2. Tap the **three-dot menu** in the top right.
3. Select **Share & export**.
4. Tap **Save as**.
5. Choose **Excel (.xlsx)** and tap **OK**.

This creates an Excel copy of the file in your Google Drive. The original Google Sheet remains unchanged.

## Step 2: Download to Local Storage

1. Open the **Google Drive** app.
2. Locate the newly created file — it shows a green Excel icon.
3. Tap the **three-dot menu** next to the file name.
4. Select **Download**.

## Troubleshooting

- **File not found after download** — Open the **Files by Google** app and check the **Downloads** category or the **Recent** tab.
- **Wrong file selected** — The original Google Sheet and the Excel copy both appear in Drive. Select the file with the green Excel icon, not the original Sheets file.
