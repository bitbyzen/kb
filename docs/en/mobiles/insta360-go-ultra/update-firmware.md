# Update the Firmware

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

1. Attach the standalone camera to the action pod.

    > **Note:** You cannot update the firmware without the standalone camera attached to the action pod.

2. Press the power button to turn on the camera.

3. The display shows any available firmware update.

4. Install the Insta360 app on your phone. If already installed, launch it.

5. Connect your Insta360 GO Ultra to the Insta360 app.

6. The app shows any available firmware update.

7. Follow the on-screen instructions to complete the update.
