# Use the Magic Drawing Pad as a Pen Display in Windows 11

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

SpaceDesk is a free app that turns the Magic Drawing Pad into a wireless pen display for Windows. The tablet appears as an additional monitor, and the stylus works as a pen input device.

Both your PC and the Magic Drawing Pad must be on the same Wi-Fi network.

## Set Up SpaceDesk

### On Windows

1. Go to [spacedesk.net/download/](https://www.spacedesk.net/download/).
2. Download the SpaceDesk Driver for Windows.
3. Run the installer and follow the prompts.
4. Open the SpaceDesk Driver Console and confirm the driver is on.

### On the Magic Drawing Pad

1. Open the Google Play Store.
2. Search for **SpaceDesk**.
3. Install the **SpaceDesk VIEWER** app.

## How It Works

| State | Effect on Windows |
|-------|-------------------|
| SpaceDesk Viewer connected | Tablet appears as an extra monitor |
| Viewer disconnected or closed | Extra monitor disappears from Windows |
| Driver turned off | No new connections can be established |

## Connect

1. Open the SpaceDesk Driver Console on Windows and turn the driver on.
2. Open the SpaceDesk Viewer app on the Magic Drawing Pad.
3. Tap your PC in the list.

Windows adds the tablet as an extra monitor.

## Disconnect

1. Swipe away the SpaceDesk Viewer app on the Magic Drawing Pad, or disconnect from inside the app.
2. Open the SpaceDesk Driver Console on Windows and turn the driver off.

The session has ended when Windows Display Settings no longer shows the tablet as a monitor.

> **Note:** If Windows gets confused about monitor arrangement after reconnecting, open **Display Settings** and drag the monitors back into the correct positions. Windows sometimes places a reconnected monitor in an unexpected location.
