# Host a Private MkDocs Site on Synology NAS

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

This guide shows how to serve a static MkDocs site from a Synology NAS on your local network using Web Station, so the site is always accessible without running `mkdocs serve`.

**Requirements:**

- Synology NAS running DSM 7
- MkDocs project in WSL2 on Windows 11
- Admin access to DSM

## Step 1: Install Web Station

1. Open **Package Center** on the NAS.
2. Search for **Web Station**.
3. Click **Install**.

After installation, Web Station automatically creates a Default Portal on port 80. No new portal needs to be created.

## Step 2: Verify Shared Folder Permissions

1. Open **Control Panel** → **Shared Folder**.
2. Select **web** → **Edit** → **Permissions**.
3. Confirm your user account has **Read/Write** access.

## Step 3: Install cifs-utils in WSL2

```bash
sudo apt-get install cifs-utils
```

## Step 4: Mount the NAS Web Folder in WSL2

```bash
sudo mkdir -p /mnt/nas-web
sudo mount -t cifs //192.168.x.x/web /mnt/nas-web -o username=<YOUR-VALUE>,uid=1000,gid=1000
```

Replace `192.168.x.x` with your NAS IP address. Enter your NAS password when prompted.

> **Note:** To find your NAS IP, open **Control Panel** → **Network** → **Network Interface** tab.

> **Note:** This mount does not persist after a reboot. Repeat this step each time you restart WSL2.

## Step 5: Build and Sync the Site

```bash
.venv/bin/mkdocs build
mkdir /mnt/nas-web/kb
rsync -av --delete site/ /mnt/nas-web/kb/
```

The `mkdir` line is only needed the first time.

## Step 6: Verify

Open a browser and go to `http://192.168.x.x/kb/`. The site should load.

## Updating the Site

Each time you update content, run the following steps:

1. Mount the NAS web folder (skip this step if WSL2 has not been restarted since the last sync):

   ```bash
   sudo mount -t cifs //192.168.x.x/web /mnt/nas-web -o username=<YOUR-VALUE>,uid=1000,gid=1000
   ```

2. Build the site:

   ```bash
   .venv/bin/mkdocs build
   ```

3. Sync the build output to the NAS:

   ```bash
   rsync -av --delete site/ /mnt/nas-web/kb/
   ```
