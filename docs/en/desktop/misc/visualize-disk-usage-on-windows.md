# Visualize Disk Usage on Windows

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Before backing up or cleaning up your system, it helps to **see** what's actually
taking up space. This guide covers the best tool to visualize disk usage on Windows.


## Why Visualize First?

Blindly deleting files is risky. Visualizing disk usage lets you:

- Instantly identify the largest files and folders
- Make informed decisions about what to delete
- Reduce backup size and time before copying to NAS or external storage

## WizTree (Windows)

> ⚡ **Recommended** — the fastest disk analyzer available for Windows.

WizTree reads directly from NTFS's **MFT (Master File Table)**, bypassing the
normal file system layer. This lets it scan even multi-terabyte drives in seconds.

### How to Use

1. Download and install WizTree from the [official site](https://www.diskanalyzer.com/).
2. Launch WizTree and select the drive you want to scan (e.g. `D:`).
3. Click **Scan**.
4. The **treemap view** renders immediately — large rectangles = large files.
5. Click any rectangle to reveal the full file path.
6. Sort the file list by **Size** to find the top offenders.

### Read the Treemap

```
┌─────────────────────────────────────────┐
│  D:\                                    │
│  ┌──────────────┐  ┌───────┐  ┌──────┐ │
│  │              │  │       │  │      │ │
│  │  Videos/     │  │ VMs/  │  │ etc. │ │
│  │  45 GB       │  │ 20 GB │  │      │ │
│  │              │  │       │  │      │ │
│  └──────────────┘  └───────┘  └──────┘ │
└─────────────────────────────────────────┘
```

Larger rectangle = more disk space consumed. Spot the biggest block and investigate first.

### Tips

- **Right-click** any file in the list → **Open Containing Folder** to locate it quickly.
- Use the **Files** tab (not just the treemap) to sort all files by size across the entire drive.
- Filter by extension (e.g. `.iso`, `.vhdx`, `.bak`) to find specific file types.

> **Note:** Always double-check before deleting. Some large files (e.g. page files,
> hibernation files) are system-managed and should not be removed manually.

## Suggested Workflow

```bash
# Step-by-step cleanup workflow

1. Scan D: with WizTree
2. Sort by Size (largest first)
3. Identify candidates for deletion:
   - Old installer files (.exe, .msi, .iso)
   - Unused virtual machine images (.vhdx, .vmdk)
   - Redundant backups or archives (.zip, .tar, .bak)
4. Delete or move to cold storage
5. Re-scan to confirm free space
```

## Next Steps

Once you've cleaned up Windows, consider also checking:

- **WSL disk usage** — WSL2 virtual disk files (`ext4.vhdx`) can grow very large
  and do not shrink automatically even after deleting files inside Linux.
- **NAS / backup size** — re-scan after cleanup to confirm how much you've saved
  before starting your backup job.
