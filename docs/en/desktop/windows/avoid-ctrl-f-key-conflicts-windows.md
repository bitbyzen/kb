# Avoid Keyboard Shortcut Conflicts in Windows

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

When assigning macros, check the tables below to avoid overwriting built-in shortcuts.

## F-Key

| Shortcut | Application | Function |
|---|---|---|
| F1 | Windows / most apps | Open Help |
| F2 | Windows Explorer | Rename selected file or folder |
| F2 | Microsoft Excel | Edit active cell |
| F3 | Windows Explorer | Open search bar |
| F3 | Most text editors | Find next |
| F4 | Windows Explorer | Focus address bar |
| F4 | Microsoft Word | Repeat last action |
| F4 | Microsoft Excel | Repeat last action / toggle cell reference type |
| F5 | Browsers, Windows Explorer | Refresh |
| F5 | Microsoft PowerPoint | Start slideshow |
| F5 | Microsoft Word | Open Go To dialog |
| F6 | Windows Explorer / Office | Cycle through panes and screen elements |
| F7 | Microsoft Word | Spell check |
| F7 | Firefox / Chrome | Toggle caret browsing |
| F8 | Microsoft Word | Extend selection mode |
| F8 | Windows (at boot) | Enter Safe Mode |
| F9 | Microsoft Excel | Recalculate worksheets |
| F9 | Microsoft Outlook | Send and receive mail |
| F9 | Microsoft Word | Update fields |
| F10 | Most Windows apps | Activate menu bar |
| F11 | Browsers / Excel | Toggle full-screen |
| F12 | Microsoft Office | Open Save As dialog |
| F12 | Browsers | Open Developer Tools |
| F12 | Adobe Dreamweaver | Preview page in primary browser |

**High-risk binding:** `F5` refreshes across virtually all Windows applications — browsers, File Explorer, and most desktop apps. Avoid assigning it to a macro unless you are certain it will never fire while those apps are in focus.

## Ctrl + F-Key

| Shortcut | Application | Function |
|---|---|---|
| Ctrl + F1 | Microsoft Office | Toggle ribbon (collapse / expand) |
| Ctrl + F2 | Microsoft Word | Open Print Preview / print pane |
| Ctrl + F3 | Microsoft Word | Cut selected text to AutoText |
| Ctrl + F4 | Browsers, Office | Close active tab or document |
| Ctrl + F5 | Browsers | Hard refresh (bypass cache) |
| Ctrl + F5 | IDEs | Run / start debugging |
| Ctrl + F6 | Microsoft Office | Cycle between open documents |
| Ctrl + F7 | Microsoft Word | Move window (non-maximized) |
| Ctrl + F8 | Microsoft Word | Resize window (non-maximized) |
| Ctrl + F9 | Microsoft Word | Insert empty field braces `{ }` |
| Ctrl + F9 | Microsoft Excel | Minimize workbook |
| Ctrl + F10 | Microsoft Word | Maximize / restore document window |
| Ctrl + F10 | Microsoft Excel | Maximize workbook |
| Ctrl + F11 | Microsoft Excel | Insert macro sheet |
| Ctrl + F12 | Microsoft Word / Excel | Open dialog |

**Relatively safe choices:** `Ctrl + F1` and `Ctrl + F2` conflict only in Office apps. If you do not use Office while the macro is active, these are low-risk bindings.
