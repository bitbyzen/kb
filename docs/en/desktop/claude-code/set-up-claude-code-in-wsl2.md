# Set Up Claude Code in WSL2

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Set up Claude Code in a WSL2 Ubuntu environment and connect it to an existing MkDocs project.

---

## Prerequisites

- WSL2 running Ubuntu
- VS Code with the Remote – WSL extension installed
- An existing MkDocs project with a Python venv

---

## Step 1: Set Up the Folder Structure

Create a dedicated folder for your Claude Code projects:

```bash
mkdir -p ~/projects/<YOUR-FOLDER>/python/mkdocs
```

The suggested structure is:

```
~/projects/
└── <YOUR-FOLDER>/
    └── python/
        └── mkdocs/       ← Claude Code project root
```

---

## Step 2: Install Node.js

Claude Code requires Node.js 18 or later. Install it via `nvm` (Node Version Manager):

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
```

Restart your terminal, then install and activate Node.js:

```bash
nvm install --lts
nvm use --lts
```

Verify the installation:

```bash
node --version
```

---

## Step 3: Install Claude Code

Install Claude Code globally via npm:

```bash
npm install -g @anthropic-ai/claude-code
```

Verify the installation:

```bash
claude --version
```

---

## Step 4: First Launch and Authentication

Navigate to your project folder and launch Claude Code:

```bash
cd ~/projects/<YOUR-FOLDER>/python/mkdocs
claude
```

On first launch, Claude Code will prompt you to authenticate:

1. A browser window opens at `claude.ai`.
2. Log in with your Anthropic account.
3. Copy the authorisation code displayed in the browser.
4. Paste it back into the terminal prompt.

Claude Code stores the session token locally. You will not need to re-authenticate on subsequent launches.

---

## Step 5: Choose How to Use Claude Code

There are two ways to run Claude Code depending on your workflow:

### Option A: VS Code Terminal (Recommended for development)

1. Open VS Code.
2. Connect to WSL2 via the Remote – WSL extension (**F1** → **Remote-WSL: New Window**).
3. Open your project folder in VS Code.
4. Open the integrated terminal (**Ctrl+`**).
5. Run `claude` from the terminal.

Claude Code runs in the same shell as your project, with full access to the filesystem and git history.

### Option B: Claude Desktop (Recommended for general tasks)

1. Install [Claude Desktop](https://claude.ai/download) on Windows.
2. Open Claude Desktop and sign in.
3. Use the built-in Claude Code integration to connect to your WSL2 filesystem.

Use Option B when you want a graphical interface without opening VS Code.

---

## Step 6: Recreate the venv After Copying a Project

If you copied or moved the project folder, the existing `.venv` will have broken absolute paths. Delete it and rebuild:

```bash
cd ~/projects/<YOUR-FOLDER>/python/mkdocs
rm -rf .venv
```

Install `python3-venv` if it is not already available:

```bash
sudo apt install python3-venv
```

Create a fresh virtual environment and install dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`(.venv)` will appear at the start of your terminal prompt when the environment is active.

---

## Step 7: Verify with MkDocs Serve

With the venv active, start the local development server:

```bash
mkdocs serve
```

Open `http://127.0.0.1:8000` in your browser. If the site loads correctly, the setup is complete.

To stop the server, press **Ctrl+C**.
