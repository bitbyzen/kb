# Install Claude Code on Windows 11

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Claude Code is a command-line coding agent. It runs on Node.js and works well inside VS Code's integrated terminal. This guide walks through installing Node.js, installing Claude Code via npm, and completing first-time setup (theme, login, and trusting your project folder).

## Part 1: Install Node.js

Claude Code requires Node.js. If you don't already have it installed, follow these steps.

### Step 1: Go to nodejs.org

Open [nodejs.org](https://nodejs.org) in your browser.

![Screenshot](img/install-claude-code-on-windows-11-01.webp)

### Step 2: Download the Windows Installer

Go to the download page. Choose your Node.js version (LTS recommended), **Windows**, and download the **Windows Installer (.msi)**.

![Screenshot](img/install-claude-code-on-windows-11-02.webp)

### Step 3: Run the Installer

Step through the Node.js Setup wizard. On the "Tools for Native Modules" screen, leave the optional Chocolatey/Python/Visual Studio Build Tools checkbox unchecked unless you need to compile native npm modules. Click **Next**.

![Screenshot](img/install-claude-code-on-windows-11-03.webp)

### Step 4: Finish the Install

Click **Finish** once the wizard reports Node.js was installed successfully.

![Screenshot](img/install-claude-code-on-windows-11-04.webp)

## Part 2: Install Claude Code

### Step 5: Open VS Code and a Terminal

Open VS Code, then open a terminal via **Terminal** → **New Terminal**.

![Screenshot](img/install-claude-code-on-windows-11-05.webp)

![Screenshot](img/install-claude-code-on-windows-11-06.webp)

![Screenshot](img/install-claude-code-on-windows-11-07.webp)

A new terminal (cmd, in this case) opens at your project path.

![Screenshot](img/install-claude-code-on-windows-11-08.webp)

### Step 6: Verify Node.js Is Installed

Run this command to confirm Node.js installed correctly:

```bash
node --version
```

![Screenshot](img/install-claude-code-on-windows-11-09.webp)

### Step 7: Install Claude Code Globally via npm

Run:

```bash
npm install -g @anthropic-ai/claude-code
```

![Screenshot](img/install-claude-code-on-windows-11-10.webp)

npm installs the package. You may see `allow-scripts` warnings — these are informational and don't block the install.

![Screenshot](img/install-claude-code-on-windows-11-11.webp)

> **Note:** If you separately try `npm approve-scripts --allow-scripts-pending` (as suggested by the warning) and it fails with `ENOMATCH` / "No installed packages match", don't worry — the Claude Code package itself is still installed correctly. This error only affects optional post-install script approval, not the `claude` command below.

![Screenshot](img/install-claude-code-on-windows-11-12.webp)

### Step 8: Launch Claude Code

Run:

```bash
claude
```

![Screenshot](img/install-claude-code-on-windows-11-13.webp)

## Part 3: First-Time Setup

### Step 9: Choose a Terminal Text Style

On first launch, Claude Code asks you to pick a color theme (dark mode, light mode, colorblind-friendly variants, and so on).

![Screenshot](img/install-claude-code-on-windows-11-14.webp)

### Step 10: Choose a Login Method

Select how you want to authenticate — a Claude subscription (Pro/Max/Team/Enterprise), an Anthropic Console account (API billing), or a third-party platform (Bedrock, Microsoft Foundry, Vertex AI).

![Screenshot](img/install-claude-code-on-windows-11-15.webp)

### Step 11: Authorize in the Browser

Claude Code opens your browser to an OAuth authorization page. Review the permissions and click **Authorize**.

![Screenshot](img/install-claude-code-on-windows-11-16.webp)

If prompted, sign in again for security before the authorization completes.

![Screenshot](img/install-claude-code-on-windows-11-17.webp)

### Step 12: Confirm Login

Back in the terminal, Claude Code confirms you're logged in.

![Screenshot](img/install-claude-code-on-windows-11-18.webp)

### Step 13: Review the Security Notes

Claude Code shows a short security reminder (review Claude's actions, only use it with code you trust). Press **Enter** to continue.

![Screenshot](img/install-claude-code-on-windows-11-19.webp)

### Step 14: Set Up Recommended Terminal Settings

Choose **Yes, use recommended settings** for the optimal coding experience (for example, Shift+Enter for newlines).

![Screenshot](img/install-claude-code-on-windows-11-20.webp)

### Step 15: Trust Your Project Folder

Claude Code performs a quick safety check on the folder it's about to access. If it's your own project or a trusted one, choose **Yes, I trust this folder**.

![Screenshot](img/install-claude-code-on-windows-11-21.webp)

### Step 16: Confirm Claude Code Is Ready

Claude Code is now running and ready for input in your terminal.

![Screenshot](img/install-claude-code-on-windows-11-22.webp)
