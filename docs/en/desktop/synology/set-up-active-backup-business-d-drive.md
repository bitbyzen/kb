# Set Up Active Backup for Business for D: Drive Backup

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.


## Overview

Active Backup for Business (ABB) is Synology's enterprise-grade agent-based backup solution. It enables you to back up your entire Windows PC — or selected volumes — directly to your NAS, with incremental transfers, global deduplication, and flexible restore options.

This guide covers:

- Installing and configuring ABB on your NAS
- Installing the agent on your Windows 11 machine
- Creating a backup task targeting `D:\` only
- Setting schedule, deduplication, and retention
- Configuring folder exclusions to save NAS space

> **Note:** Your final setup will be professional-grade — Synology Drive handles real-time Obsidian vault sync, while ABB covers full `D:\` drive backup and recovery.

---

## Part 1: Installation and Configuration

### Step 1: Install Active Backup for Business on the NAS

1. Log into DSM (your NAS web interface).
2. Open **Package Center**.
3. Search for **Active Backup for Business** and click Install.
4. Wait for installation to complete.

---

### Step 2: Open ABB and Enable PC Backup

1. Open **Active Backup for Business** from the DSM app menu.
2. Navigate to the **PC** section in the left sidebar.
3. Click **Add Device** — this will prompt you to download the Windows agent.

> **Note:** Keep this browser window open — you will return to it after installing the agent on your PC.

---

### Step 3: Install the ABB Agent on Windows 11

1. Download the **Active Backup for Business Agent** installer from the ABB interface or from Synology's download center.
2. Run the installer on your Windows 11 machine.
3. Accept defaults and complete the installation.
4. Launch the agent — it will open in the system tray.

---

### Step 4: Connect Your PC to the NAS

In the agent application on your Windows PC:

1. Enter your NAS IP address (e.g. `192.168.1.x`).
2. Enter your DSM username and password.
3. Click **Connect**.

> **Note:** Your PC will now appear as a device in Active Backup for Business on the NAS. Return to the NAS browser tab to continue.

---

## Part 2: Creating the Backup Task

### Step 5: Create a Backup Task

In the ABB interface on your NAS:

1. Select your PC from the device list.
2. Click **Create Task**.

---

### Step 6: Select Customized Volume

When prompted to choose what to back up, you will see these options:

- Entire device
- System volume
- **Customized volume**

Select **Customized Volume**, then tick **D: drive only**.

> **Note:** This option backs up only `D:\`, avoiding wasted space on the C: system drive.

---

### Step 7: Set the Backup Schedule

| Option | Description |
|---|---|
| **Recommended** | Daily — scheduled at night (e.g. 2:00 AM) while your PC is on |
| **Advanced** | Event-based: on startup, shutdown, or USB connect |

---

### Step 8: Enable Deduplication and Compression

Both options are typically enabled by default. Verify they are on:

- **Global deduplication** — eliminates duplicate data blocks across backups, saving significant NAS space
- **Compression** — reduces backup size further

> **Note:** Leave both enabled. These are among the most valuable features of ABB and cost little in performance.

---

### Step 9: Configure the Retention Policy

The retention policy determines how many recovery points are kept before old ones are deleted. It protects against accidental deletions and file corruption.

Recommended options:

- **Keep last 30 versions** — simple and predictable
- **Smart Recycle** — intelligent thinning that keeps more recent versions and gradually reduces older ones

> **Note:** Smart Recycle is generally the best choice. It maximises recovery options while automatically managing space over time.

---

### Step 10: Apply and Run the First Backup

1. Review all settings and click **Apply**.
2. The first backup will begin immediately (or at the next scheduled time).

> **Warning:** The first backup will take a long time — it must scan and transfer the entire `D:\` drive. All subsequent backups will be incremental (only changed data), which are much faster.

## Part 3: Folder Exclusions

ABB supports file and folder exclusions to reduce backup size. Exclusions are applied as filters — not precise file selection — but they are effective for removing large, unimportant data.

### How to Access Exclusion Settings

1. Go to **Active Backup for Business** on your NAS.
2. Select your PC backup task.
3. Click **Edit**.
4. Look for **File Filter** or **Exclusion Settings**.

---

### What You Can Exclude

**By folder path** — exclude entire folders using their full path:

```
D:\Games\
D:\Downloads\
D:\Temp\
```

**By file type** — exclude files by extension across the entire drive:

- `*.iso` — disc images
- `*.tmp` — temporary files
- `*.log` — log files

---

### Recommended Exclusions

| Folder / Pattern | Reason |
|---|---|
| `D:\Games\` | Large game installs — easily re-downloadable |
| `D:\Downloads\` | Ephemeral files with no long-term value |
| `D:\Temp\` | Temporary files — not worth backing up |
| `*.iso` | Disc images — very large, easily re-sourced |
| `*.tmp` | Temporary files generated by apps |
| `*.log` | Log files — verbose, low value |

---

### Exclusion Limitations

- ABB is fundamentally image-based — exclusions are filters, not precise file selection.
- Path syntax must be exact — a typo means the folder is still backed up.
- No auto-suggestions — you must know the exact paths.
- Some system data may still be included even with exclusions.

> **Note:** If your goal is to back up only a few specific folders (not exclude a few), use **Synology Drive** instead. ABB is best suited for "back up everything except X" scenarios.

## Part 4: Tips and Best Practices

### Do This

- Keep the NAS powered on during scheduled backup windows.
- Verify sufficient free storage space on the NAS before the first run.
- Use a **wired LAN** connection for the initial backup — significantly faster than Wi-Fi.
- Enable Smart Recycle for automatic retention management.
- Test a restore of a single file after setup to confirm everything works.

### Avoid This

- Do not run multiple backup tools on the same folder — this wastes space and causes conflicts.
- Do not skip retention settings — unlimited versions will eventually fill your NAS.
- Do not interrupt the first backup once started — let it complete fully.
