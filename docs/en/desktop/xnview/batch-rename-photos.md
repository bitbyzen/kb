# Batch Rename Photos in XnView MP

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

XnView MP's Batch Rename feature lets you rename multiple image files at once using a name template with an auto-incrementing counter. This guide shows how to rename a folder of JPG photos to a sequential series such as `photo-series-01.jpg`, `photo-series-02.jpg`, and so on.

## Step 1: Select Your Files

1. Open XnView MP and navigate to the folder containing your photos.
2. Press `Ctrl+A` to select all files, or hold `Ctrl` and click individual files to select a subset.

> **Note:** The Batch Rename command is only available when at least one file is selected.

## Step 2: Open Batch Rename

Go to **Tools** → **Batch rename...**.

The Batch Rename dialog opens and shows a preview table with **Old name** and **New name** columns.

## Step 3: Configure the Name Template

1. Check the **Name template** checkbox at the top of the dialog.
2. In the template field, type your base name followed by `##` for a two-digit counter:

    ```text
    photo-series-##
    ```

    The `##` token is replaced by `01`, `02`, `03`, and so on. Use `###` if you need three digits (`001`, `002`, `003`).

3. Set **Start** to `1` and **Step** to `1`.

## Step 4: Fix the File Extension Case (Optional)

If your files have uppercase extensions (`.JPG`) and you want lowercase (`.jpg`):

1. Check the **Replace** checkbox.
2. Set **Replace** to `JPG` and **With** to `jpg`.
3. Check **Case sensitive** to avoid unintended replacements.

## Step 5: Preview and Confirm

Check the **New name** column in the preview table to verify the output looks correct before applying. The files are numbered in the order they are sorted in the browser.

> **Note:** To control the numbering order, close the dialog, sort your files in the desired order in the browser, and then re-open Batch Rename.

## Step 6: Apply the Rename

Click **OK** to rename all selected files.

> **Warning:** Renaming cannot be undone from within XnView MP. Back up your files before applying bulk renames.
