# Fix the "Exec Format Error" in WSL2

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

## Symptom

Running `explorer.exe .` to open Windows Explorer shows the following error:

```
-bash: /mnt/c/WINDOWS/explorer.exe: cannot execute binary file: Exec format error
```

**Environment:** VS Code, WSL2, Ubuntu terminal

## Solution

This is usually a temporary issue. Restarting WSL2 resolves it in most cases.

1. Close VS Code.
2. Run the following command in PowerShell:
    ```powershell
    wsl --shutdown
    ```
3. Restart VS Code.
