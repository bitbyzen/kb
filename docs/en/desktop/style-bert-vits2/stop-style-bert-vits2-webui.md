# Stop Style-Bert-VITS2 WebUI

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Follow these steps to shut down the Style-Bert-VITS2 WebUI server cleanly. See [Set Up Style-Bert-VITS2 WebUI](set-up-style-bert-vits2-webui.md) for how to launch it.

## Step 1: Stop the Server

In the terminal running the server, press **Ctrl + C** to stop `app.py`.

## Step 2: Exit the Virtual Environment

Run the following command to deactivate the venv:

```bat
deactivate
```

> **Note:** Closing the terminal window also stops the server, but running `deactivate` first leaves your shell in a clean state for the next session.
