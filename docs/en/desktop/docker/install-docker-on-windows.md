# Install Docker on Windows

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Install [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/) to run containers on Windows.

---

## Prerequisites

- Windows 10 64-bit (version 1903 or later) or Windows 11
- WSL2 enabled (recommended) or Hyper-V enabled

## Steps

1. Go to the [Docker Desktop for Windows installation page](https://docs.docker.com/desktop/setup/install/windows-install/).
2. Click **Download Docker Desktop for Windows**.
3. Run the downloaded installer and follow the setup wizard.
4. Restart your computer when prompted.
5. Launch **Docker Desktop** from the Start menu.
6. Wait for Docker to finish starting — the whale icon in the taskbar will stop animating when ready.

---

> **Tip:** Run `docker run hello-world` in a terminal to verify the installation was successful.
