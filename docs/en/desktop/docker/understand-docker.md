# Understand Docker

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

1. Install WSL2 to run Linux on Windows.
2. Install a Linux distribution (e.g. Ubuntu).
3. Install Docker Desktop — the local app for managing Docker.
4. Launch Docker Desktop. A **Sign in** button appears in the top right, but you do not need to sign in to use Docker.
5. Once launched, close the Docker Desktop window. Docker continues running in the background.
