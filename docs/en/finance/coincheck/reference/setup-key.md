# Understand the Setup Key for Two-Factor Authentication

> **Note:** This document was generated by Claude Code and has not been reviewed by a human. Please use it as a reference only.

Official site: [https://coincheck.com/](https://coincheck.com/)

## Definition

- A secret key (alphanumeric string) used for two-factor authentication (2FA)
- The base data registered into an authenticator app
- Can be entered manually as an alternative to scanning a QR code

## Example Apps

- Google Authenticator
- Microsoft Authenticator

## Purpose

- Strengthens security at login
- Required for account recovery when your phone is lost or replaced

## Important Notes

- Never share it with anyone
- Save it securely via screenshot or on paper
- Losing it makes account recovery a hassle

## Quick Summary

| Method | Use |
|---|---|
| QR Code | For scanning |
| Setup Key | For backup (manual entry) |
