# PhotoLibrary のみにバックアップ（集約）する方法

> 注記: Geminiに聞きながら設定した手順。自動で `MobileBackup` や「年/月」のフォルダを作らせず、すべて `PhotoLibrary` 直下にフラットに保存させるための設定。

## 手順
1. スマホの **Synology Photos** アプリを開きます。
2. 画面下部の **その他 (More)** タブをタップします。
3. **「画像バックアップが完了しました」**（または現在のバックアップステータス）と表示されている部分をタップします。
4. 右上の **歯車アイコン（設定）** をタップします。
5. **「バックアップ先」** をタップします。
6. **「対象先パス」** で **「カスタマイズ」** を選択し、保存先を **`PhotoLibrary`** に指定します。
7. その下にある **「年/月のフォルダを自動生成」** のラジオボタン（またはスイッチ）を **オフ** にします。

## 注意点
* **手動整理に最適:** この設定を行うことで、写真はデバイス別や日付別のフォルダに隔離されず、すべて `PhotoLibrary` 直下に保存されます。
* **WD Red SSDの恩恵:** フォルダを細かく分けないことで、PC（エクスプローラー）から大量の写真を一画面で確認し、手動でサッとフォルダ分けして整理していくワークフローに非常に適しています。
