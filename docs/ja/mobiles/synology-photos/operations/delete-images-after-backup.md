# バックアップ後に写真を削除する方法

> 注記: Geminiに聞きながらやったことを最後にGeminiにまとめてもらった。時間がないのでメモの内容精査はしてない。

## 手順
1. スマホの **Synology Photos** アプリを開きます。
2. 画面下部の **その他 (More)** タブをタップします。
3. **「画像バックアップが完了しました」** と表示されている部分をタップします。
4. 画面に表示される **「容量を解放する」** をタップします。
5. **「すべてのバックアップ済みアイテム」** が選択されていることを確認します。
6. 画面下部の **「すべてをクリア」** をタップします。
7. OSの確認ポップアップが表示されたら **「許可」** をタップします。

## 注意点
* この操作で削除されるのは**NASへバックアップが完全に完了しているファイルのみ**です。
* Pixel 8aの場合、削除されたファイルは一度「Google フォト」アプリの **ゴミ箱** に移動することがあります。すぐに空き容量を増やしたい場合は、Google フォトのゴミ箱を手動で空にしてください。
