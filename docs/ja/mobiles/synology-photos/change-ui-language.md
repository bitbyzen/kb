# UI言語を変更する方法

> 注記: Geminiに聞きながら設定を試みた。結論としては、アプリ側では言語変更ができないため、スマホのシステム言語を変更するしかない。

## 結論
**Synology Photosアプリ単体での言語切り替え機能はありません。**
アプリの表示言語は、Android（Pixel 8a）の「システム言語」に連動します。

## 対策（スマホ全体の言語を英語にする場合）
もしアプリを英語表示にしたい場合は、スマホ全体の言語を英語に切り替える必要があります。

1. スマホの **設定**（歯車アイコン）を開きます。
2. **システム** ＞ **言語** をタップします。
3. **システム言語** をタップします。
4. **English** をリストの一番上にドラッグして優先言語にします。

## 注意点
* **生活環境との兼ね合い:** 日本在住の場合、スマホ全体を英語にしてしまうと、日本の銀行アプリや、日本語の通知・マップアプリなどの操作で不便やリスクが生じる可能性があります。
* **個別アプリの言語設定について:** Androidにはアプリごとに言語を変える機能（アプリの言語）がありますが、現在のSynology Photosアプリはこの機能に対応していないため、アプリ一覧に表示されません。
