# 個人スペースへのバックアップとフォルダの仕組み

> 注記: Geminiに聞きながら設定した内容のまとめ。紛らわしい `home` と `homes` の関係や、個人スペースの最適設定について。

## 1. `home` と `homes` の正体（二重バックアップの誤解）
Synology NASの仕組みにおいて、`home` と `homes` は同じデータの実体を異なる窓口から見ているだけです。データが二重に保存されて容量を2倍消費することはありません。

* **`homes` フォルダ:** NAS全体の「全ユーザーの個人フォルダ」をまとめている親フォルダです（管理者だけが見える設定にできます）。
* **`home` フォルダ:** 今ログインしている「自分専用」のショートカットです。

### 写真のバックアップ先
「個人スペース」でバックアップをすると、写真は以下の場所に保存されます。
どちらのフォルダから見ても同じファイルを参照しています。

* **実際の場所:** `/homes/ユーザー名/Photos/MobileBackup/...`
* **あなたのショートカット:** `/home/Photos/MobileBackup/...`

## 2. 「自分だけが管理したい」場合の最適設定
自分だけのプライベートな環境として NAS を運用する場合、バックアップ先を **「個人スペース（Personal Space）」** に指定するのが正解です。以下の設定を確認してください。

1. **ユーザーホームを有効にする:**（必須設定です）
2. **Synology Photosの設定:** アプリでバックアップ先を **「個人スペース」** に指定する。
3. **権限の確認:** 他のユーザーをNASに登録している場合、その人たちが `homes` フォルダにアクセスできない設定（デフォルト）であれば、あなたの写真は誰からも見られません。

## 3. 補足：容量の確認について
「ストレージマネージャー」で使用量が急激に増えているように見えた場合でも、それはデータが重複しているわけではありません。
高解像度な写真のインデックス作成やサムネイル生成、またはファイルのメタデータ管理によるものです。

**WD Red SA500 SSD** と **DS720+** の組み合わせであれば、これらのバックグラウンド処理も非常に高速かつスムーズに行われますので、安心してお使いいただけます。
