# homesフォルダを非表示にする方法

> 注記: Geminiに聞きながら設定した内容のまとめ。エクスプローラー上で `homes` フォルダを非表示にし、視界をスッキリさせるための手順。

## 結論
**`homes` フォルダをPC（エクスプローラー）上で非表示にすることは可能です。**
`homes` は管理者用（Admin権限を持つユーザー用）の共有フォルダなので、管理者としてログインしていると `home` と両方見えてしまいますが、設定でスッキリさせることができます。

## 手順：ネットワークプレビューで非表示にする
この設定を行うと、エクスプローラーでNASを開いた際、`homes` という項目自体が表示されなくなります（直接パスを打ち込まない限り見えません）。

1. DSM（ブラウザの管理画面）にログインします。
2. **[コントロールパネル]** ＞ **[共有フォルダ]** を開きます。
3. リストから **homes** を選択し、**[編集]** をクリックします。
4. **[全般]** タブにある **「ネットワークプレビューでこの共有フォルダを非表示にする」** にチェックを入れます。
5. **[保存]** をクリックします。

これで、PCからNASを覗いたときに `home` だけが表示されるようになります。

## 一般ユーザーの視点と安全な運用
もし、PCでログインしているアカウントが「管理者（administratorsグループ）」ではなく「一般ユーザー」であれば、最初から `homes` は見えず、自分専用の `home` だけが見える状態になります。

* **現在の状況:** 管理者アカウントでPCから接続しているため、メンテナンス用に両方見えている状態です。
* **対策:** 上記の「非表示」設定をするか、普段使い用に「一般ユーザー権限」のアカウントを別途作成してそちらでログインするようにすると、より安全で画面もスッキリします。

## 注意点
* **`home` は消さない:** `home` フォルダは「今ログインしている人専用の入り口」なので、これを非表示にしたり削除しようとしたりすると、スマホ写真のバックアップ先が見失われてしまいます。
* **反映速度:** **WD Red SSD** の構成であれば、フォルダの表示・非表示の設定変更も一瞬で反映されます。
