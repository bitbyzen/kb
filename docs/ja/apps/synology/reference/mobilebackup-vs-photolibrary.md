# MobileBackup と PhotoLibrary の違い

> 注記: Geminiに聞きながら確認した内容のまとめ。`home` ＞ `Photos` の中にある `MobileBackup` と `PhotoLibrary` の役割の違いと運用方法について。

## 各フォルダの役割

Synology Photos が「自動バックアップ」と「手動整理」の場所を明確に分けているため、デフォルトで2つのフォルダが存在します。

### 1. `MobileBackup`（自動バックアップ専用）
スマートフォンから自動でアップロードされた写真が格納される場所です。
アプリの設定でバックアップを有効にすると、この中にデバイス名（iPhoneやPixelなど）のフォルダが作られ、その中に日付ごとのフォルダで写真が保存されます。

* **役割:** 「スマホのデータのコピーをとりあえず取っておく」ための場所。

### 2. `PhotoLibrary`（手動整理・アップロード専用）
PCからブラウザ経由でアップロードした写真や、自分で整理するために作ったフォルダが置かれる場所です。
過去にデジカメで撮った写真をPCからドラッグ＆ドロップで入れたり、自分で「2024年_旅行」といったフォルダを作って管理したりする場合は、ここを使います。

* **役割:** 「自分で見やすく整理・管理する」ためのメインライブラリ。

---

## どちらを使えばいい？（運用のヒント）

### 基本的な運用
「スマホの写真をバックアップしたい」という目的であれば、基本的には `MobileBackup` フォルダが自動的に更新されていくことになります。

### おすすめの運用スタイル
フォルダをそのまま分けておくのが一番トラブルが少ないです。
1. スマホからは `MobileBackup` へ自動保存。
2. 時間がある時に、お気に入りの写真だけを `PhotoLibrary` の中の「アルバム用フォルダ」に移動して整理する。

お使いの **DS720+（SSD構成）** であれば、どちらのフォルダに写真が入っていても、アプリ上では「タイムライン」としてすべての日付順に並べて表示されるため、管理場所が分かれていても閲覧時に困ることはありません。
