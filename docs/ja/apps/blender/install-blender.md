# Blenderをインストールする方法

## 課題

Blenderはアップデートが頻繁で、毎回手動インストールが面倒。

なんかいい方法がないか、Claudeに聞いてみた。

その回答が以下のとおり。

とりあえず、**Steam版**を試すことにした。

## 自動アップデートできる主な方法

| 方法 | 自動アップデート | 最新版への速さ | 備考 |
|------|----------------|--------------|------|
| **Steam** | ✅ | 比較的早い | アカウント作成が必要（無料） |
| **Microsoft Store** | ✅ | やや遅れる場合あり | Microsoftアカウントがあればすぐ使える |
| **Blender Launcher** | 準自動（通知あり） | 早い | 複数バージョン管理が得意 |
| **公式サイト** | ❌（手動） | 最速 | 従来通りの方法 |

## 補足メモ
- Steamアカウントを新規作成すれば、以降は自動でアップデートされる
- Microsoft StoreでもBlenderは入手可能（自動アップデート対応）
- Blenderだけが目的ならMicrosoft Storeの方がアカウント作成不要でシンプル
- Blender Launcher（GitHub: Victor-IX/blender-launcher-v2）は複数バージョンを管理したい上級者向け
