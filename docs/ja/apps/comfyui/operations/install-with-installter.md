# ComfyUIをインストールする方法

ComfyUIのデスクトップ版インストーラが公式リリースされた。

以下の公式サイトからダウンロードできる。

https://www.comfy.org/

画面の指示に従って進めていけば、すぐにインストールできる。

インストール手順は、Gigazineの記事にも載ってる。

https://gigazine.net/news/20260201-comfyui-image-video-generation-ai/

ただし、僕の環境だと、途中でエラーになった。

原因は、NVIDIAのグラボのドライバーが古かったから。

それで、ドライバーを更新するために、NVIDIAのサイトに行った。

以前はドライバーだけインストールしたけど、**NVIDIA App**なるものを発見。

https://www.nvidia.com/en-us/software/nvidia-app/

これをインストールしとけば、ドライバーもインストールできるっぽい。

Epic Games Launcherをインストールしとけば、最新のUEをインストールできるのと似ている。

とりあえず、インストールしてドライバーを更新。

ComfyUIのエラーが消えた。
