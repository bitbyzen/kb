# Discordを導入する方法

Win版のDiscordを導入してComfyUIサーバーをフォローするまでの手順。

## 手順

1. 公式サイトからアプリをインストールして起動する。

2. アカウントにログインする。

3. フォローしたいサーバーを追加する。方法は主に2つ。

    - **招待リンクをクリックする**：公式サイト等のDiscordリンクをクリックすると招待画面に遷移するので、そこで参加を承認する。

        例）ComfyUIの公式Discordに参加する場合、GitHubの公式リポジトリの **README** に **Discord** バナーがあるのでそこからアクセスできる。

        https://github.com/Comfy-Org/ComfyUI

    - **招待リンクを手動で入力する**：画面左側のナビメニューの「+」ボタン（**Add a Server**）をクリックし、次の画面で招待リンクをペーストする。

4. サーバーに参加したら、画面中央の **Customization Questions** に回答する。回答することでより多くのチャンネルが表示されるようになる。

5. 左ナビの **#announcement** を右クリックして **Notification Settings** → **All Messages** をオンにしておく。アップデートなどがあれば通知が届く。

## おすすめチャンネル（最低限）

| チャンネル | 用途 |
|---|---|
| `#announcement` | 新バージョン・重要なお知らせ |
| `#help` | 使い方の質問・トラブル相談 |
| `#general` | 雑談・情報交換 |
